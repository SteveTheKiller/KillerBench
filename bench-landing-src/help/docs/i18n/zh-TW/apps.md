# 應用

應用會檢視已安裝的程式、Store 套件、Office 和 Outlook、瀏覽器擴充套件、啟動應用和搜尋。刪除和重設工具始終會先顯示檢視結果，並且只變更你選擇的內容。

操作指南：[設定新電腦](set-up-new-pc.html)。

## 本區段的工具

檢視已安裝的應用、Store 套件、Office 和 Outlook、瀏覽器擴充套件和搜尋。

### 已安裝的應用程式

讀取所選電腦範圍或執行帳戶範圍內的應用程式解除安裝註冊，然後將該範圍與有範圍限制的 Application 錯誤、可靠性監視器和重新啟動證據相結合。其他帳戶和可攜式應用程式會被排除。註冊和廣泛的歷史記錄並不能準確證明應用程式的執行狀況或所有權。不會選擇任何安裝程式、解除安裝程式、應用程式、處理程序、服務、檔案、註冊、帳戶、原則或重新啟動操作。

### 應用程式套件

清點所選帳戶範圍內已註冊的 Appx/MSIX 套件。預設為執行帳戶；所有使用者範圍需要系統管理員存取權限。報告確切的識別、框架和不可刪除旗標以及相依性數量。不評估佈建套件、Win32 應用程式、受管理的所有權和應用程式資料。不會刪除任何套件。

### 瀏覽器擴充功能

有範圍限制地清點執行帳戶中 Chrome、Edge、Brave 和 Firefox 擴充套件的識別。瀏覽器歷史記錄、認證、擴充套件設定、清單內容、命令和原則值會被排除。擴充套件存在並不能證明它已啟用、可信、有所有者或可以安全刪除。不會變更任何瀏覽器、擴充套件或原則。

### 啟動應用程式

清點電腦和執行帳戶的 Run 和 RunOnce 註冊名稱、啟動資料夾中的檔名、Windows 啟動審批狀態以及啟動或登入時的排程工作名稱和狀態，然後傳回一個啟動環境結論。不會收集命令列、目標路徑、二進位審批時間戳記、工作操作、引數、帳戶和認證。註冊並不能證明某項已執行、導致了延遲、不需要或可以安全停用。審批狀態不能證明存在相應的註冊。不會選擇任何註冊、檔案、應用程式、工作、服務或原則變更。

### Microsoft 應用程式移除

檢視所選的 OneDrive、Outlook、Office/M365、Project 和 Teams 註冊，並提供帳戶範圍和保留選項。會關聯電腦、執行帳戶和已註冊套件的清單；所有使用者範圍的檢視還包括為新使用者佈建的套件。目前帳戶中受支援的套件可以在桌面應用程式或 CLI 中獲得單獨的確切保護計畫。刪除該套件是一項單獨的受保護桌面操作，具有自己的確認步驟。檢視本身不會變更任何處理程序、應用程式、套件、檔案、認證、資料夾位置、登錄值或使用者資料。

### Outlook 重設

檢視新版 Outlook、經典 Outlook 或兩者，並明確選擇快取、設定檔設定、身份驗證、OST 檔案、載入項以及新版 Outlook 的重新安裝。執行帳戶範圍的檢視會檢查有範圍限制的已知位置、確切的註冊以及處理程序關閉後的就緒狀態。單獨確認的僅快取操作會以唯一的復原名稱保留確切的快取目錄，並驗證每次移動。所有使用者範圍的檢視和其他重設區域仍僅供檢視。不會刪除任何保留的快取、設定檔、OST 檔案、認證、載入項、套件或設定。

### Foxit 清單

### Windows Search
