# 更新

更新涵蓋 Windows Update、其背後的服務以及元件存放區。你可以檢視已安裝的內容、待處理的內容以及更新失敗的原因，並可以在選擇安裝任何更新之前檢視可用更新。

操作指南：[修復 Windows Update](fix-windows-update.html) 和 [修復系統檔案](repair-system-files.html)。

## 本區段的工具

監視維護活動、檢視可用更新並修復 Windows Update鏈。

### 維護活動監視器

透過一次或多次快照，有範圍限制地觀察 Windows Update和 Setup 的維護活動。選項控制重新整理間隔，以及是否包括更新事件、更新歷史記錄、Windows Update的確切排程工作、服務的確切狀態、重新啟動指示、目前帳戶的背景傳輸、傳遞最佳化活動以及有隱私範圍限制的 Windows Installer 活動。處理程序 ID、命令列、使用者和路徑會被排除。活動不能證明進度、完成、停滯或故障。不會要求任何更新、安裝、傳輸、工作、服務、處理程序、原則、重新啟動或修復操作。

### 可用更新

使用已設定的來源、Windows Update或已註冊的 Microsoft Update 服務查詢所選的軟體和驅動程式更新。查詢前會檢查來源的就緒狀態。查詢不會安裝任何內容，不接受授權，不註冊來源，也不變更原則。所選更新之後可以單獨安裝，但僅在你勾選確認核取方塊之後。此功能與維護修復分開。

### Windows Update

有範圍限制地清點 Windows 維護套件、選用功能和功能的狀態，檢查重新啟動指示、可用空間和更新服務，在不啟動傳遞最佳化的情況下對其進行觀察，然後掃描元件存放區和受保護的系統檔案。套件、功能或功能處於待處理狀態時需要審閱，但不會授權元件操作。自動修復可以啟動已停止且設定為自動啟動的 Windows Update、BITS、加密服務、Windows 模組安裝程式和 Update Orchestrator 服務。已停止的手動啟動服務只會回報，不會啟動。啟動Update Orchestrator可能會按照目前原則繼續現有的排程更新活動。套件、選用功能、功能、傳遞最佳化快取、對等節點、頻寬、原則、來源註冊、排程和啟動設定保持不變。DISM 或 SFC 需要損壞的即時證據。此工作流程不會選擇或核准任何更新。

### Windows Update 服務

檢查 Windows Update 服務的確切狀態、其註冊的服務 DLL、有範圍限制的目前更新活動以及確切的服務故障歷史記錄。DLL 觀察、更新活動和歷史故障不能授權啟動服務或執行更新操作。選用的復原會在重新檢查相依性和可執行檔案註冊後，僅啟動已停止的自動啟動服務。已停止的按需啟動服務僅作為資訊顯示。現有的更新活動可能會按照目前原則繼續。更新原則、來源註冊、排程、重新啟動設定、套件、BITS 作業、服務權限和啟動類型保持不變。KillerBench 不會選擇、核准或安裝任何更新。驗證僅涵蓋服務的穩定狀態，不包括來源可存取性、適用性、下載、安裝、完成或重新啟動就緒狀態。

### 傳遞最佳化

檢查傳遞最佳化服務的確切狀態。已停止的按需啟動服務僅作為資訊顯示。只有確切的 Paused 狀態才會提供復原。選用的復原會重複狀態檢查，傳送一次有範圍限制的繼續要求，並需要兩次一致的 Running 觀察結果。啟動類型、快取內容、對等節點、頻寬、更新來源和受管理的原則保持不變。傳輸活動、快取執行狀況、更新進度和完成情況仍未驗證。

### BITS 服務

檢查背景智慧傳輸服務的確切狀態、目前帳戶的傳輸作業以及有範圍限制的確切服務故障歷史記錄。歷史故障和傳輸快照不能授權啟動服務。選用的復原會在重新檢查相依性後，僅在確切服務已停止且設定為自動啟動時啟動該服務。已停止的手動啟動服務僅作提示。現有應用程式可能會繼續排隊的背景傳輸。作業、優先順序、所有者、目標、Proxy 設定、原則和啟動類型保持不變。驗證僅涵蓋服務的穩定狀態，不包括傳輸進度、應用程式所有權或完成情況。

### 背景傳輸 (BITS)

讀取所選帳戶範圍內的 BITS 傳輸作業，並檢視確切的作業識別。佇列名稱不能確定應用程式的所有權。不會繼續、完成、取消、刪除或重新分配任何傳輸。

### 加密服務

檢查加密服務的確切狀態、其註冊的服務 DLL 以及有範圍限制的確切服務故障歷史記錄。歷史故障和 DLL 觀察不能授權啟動服務或替換元件。選用的復原會在重新檢查相依性後，僅在確切服務已停止且設定為自動啟動時啟動該服務。已停止的手動啟動服務僅作提示。現有的目錄、憑證和更新操作可能會繼續。憑證、金鑰、目錄、信任設定、原則和啟動類型保持不變。驗證僅涵蓋服務的穩定狀態，不包括憑證、簽名、目錄或信任的驗證。

### Windows 模組安裝程式

檢查 Windows 模組安裝程式的確切狀態、有範圍限制的維護套件轉換以及確切的服務故障歷史記錄。歷史故障和套件狀態不能授權啟動服務或執行套件操作。選用的復原會在重新檢查相依性後，僅在確切服務已停止且設定為自動啟動時啟動該服務。已停止的手動啟動服務僅作提示。現有的維護活動可能會繼續。套件、元件存放區內容、來源、原則和啟動類型保持不變。驗證僅涵蓋服務的穩定狀態，不包括元件存放區執行狀況、套件的適用性、維護完成情況或重新啟動就緒狀態。

### Windows Update Medic 服務

檢查 Windows Update Medic 服務的確切狀態、其註冊的服務 DLL、有範圍限制的目前更新活動以及確切的服務故障歷史記錄。DLL 觀察、更新活動和歷史故障不能授權啟動服務或執行元件操作。已停止的按需啟動服務可能是正常的。僅當選擇此工具時，選用的復原才可以在重新檢查相依性後啟動已停止的已啟用服務。Windows 修正可能會按照目前原則繼續，並可能修復更新元件或觸發更新活動。更新原則、來源註冊、排程、套件、BITS 作業、重新啟動設定、服務權限和啟動類型保持不變。KillerBench 不會選擇任何更新，也不會變更任何更新設定。驗證僅涵蓋服務的穩定狀態，不包括修正、元件執行狀況、適用性、下載、安裝或重新啟動就緒狀態。

### Update Orchestrator 服務

檢查Update Orchestrator 服務的確切狀態、確切的內建 Windows Update工作、有範圍限制的目前活動以及確切的服務故障歷史記錄。工作結果、更新活動和歷史故障不能授權啟動服務或執行更新操作。選用的復原會在重新檢查相依性和可執行檔案註冊後，僅啟動已停止的自動啟動服務。已停止的按需啟動服務僅作為資訊顯示。現有的排程更新活動可能會按照目前原則繼續，並可能下載或安裝已核准的更新。更新原則、來源註冊、排程、重新啟動設定、套件、BITS 作業、服務權限和啟動類型保持不變。KillerBench 不會選擇或核准任何更新。驗證僅涵蓋服務的穩定狀態，不包括適用性、下載、安裝、完成或重新啟動就緒狀態。

### 元件存放區清理

分析 Windows 是否建議清理元件存放區。選用維護會立即刪除被取代的元件，然後再次分析。不使用 ResetBase，也不手動刪除 WinSxS。不會自動撤消；不會測量回收的磁碟空間。
