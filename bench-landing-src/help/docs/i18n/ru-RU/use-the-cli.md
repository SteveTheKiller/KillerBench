# Запуск KillerBench из скриптов

Используйте командную строку, когда доказательства KillerBench нужны в скрипте, задании RMM или удалённой консоли. `killerbench-cli` запускает тот же Engine, что и настольное приложение, и выводит JSON.

## Начало работы

1. Откройте PowerShell в папке, где находится `killerbench-cli.exe`, или добавьте эту папку в путь.
2. Выполните `killerbench-cli help`, чтобы вывести список всех команд с их границами безопасности.
3. Выполните `killerbench-cli diagnostic-scopes`, чтобы увидеть 11 рекомендуемых диагностических групп.

## Запуск проверки и сохранение отчёта

```powershell
killerbench-cli full-scan --report C:\Reports\scan.html --json
```

`full-scan` выполняет только диагностику и отклоняет `--auto-repair`. Если нужно конкретное действие, используйте отдельную процедуру исправления. `--report` записывает тот же тематический отчёт, который экспортирует приложение. Используйте `--scope`, чтобы проверить только некоторые области, и `common-check` для объединённого JSON без журнала процедуры.

## Коды завершения

| Код | Значение |
| --- | --- |
| 0 | Предпросмотр или подтверждённый результат выполнены успешно. |
| 1 | Команду остановила ошибка запуска, ввода или журнала. |
| 2 | Аргументы не распознаны. |
| 3 | Заблокировано, ошибка или не подтверждено. |
| 4 | Процедуре нужна перезагрузка перед проверкой. |
| 130 | Вы остановили выполнение. |

Код 0 у команды только для чтения означает, что она выполнилась, а не что компьютер исправен. Результаты читайте в JSON.

## Внесение изменения

Каждая команда, способная изменить компьютер, по умолчанию выполняет предпросмотр. Прочитайте предпросмотр, затем выполните ту же команду с `--execute`. Если запрос прерван, выполните соответствующую команду `-recover`; она сообщит фактический результат и никогда не повторит изменение.

```powershell
killerbench-cli dhcp-renew
killerbench-cli dhcp-renew --execute
killerbench-cli dhcp-renew-recover
```

## Повторное открытие старых результатов

```powershell
killerbench-cli workflow-journal C:\Users\me\AppData\Local\KillerBench\journal.json
killerbench-cli workflow-report journal.json report.html --include-repairs
```
