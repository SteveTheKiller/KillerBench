# Обслуживание

Обслуживание поддерживает компьютер в порядке: очистка файлов, старые профили пользователей, запланированные задачи и наведение порядка в Windows. Каждый инструмент заранее показывает, что он удалит, прежде чем что-либо будет удалено.

Пошаговые руководства: [Освобождение места на диске](free-disk-space.html) и [Повышение конфиденциальности Windows](make-windows-private.html).

## Инструменты этого раздела

Очищайте файлы, профили и запланированные задачи и наводите порядок в Windows.

### Очистка

Оценивает выбранные цели среди временных файлов, кэшей и сохранённых диагностических доказательств с учётом параметров возраста и лимита файлов на главной панели. Windows Temp и Windows SystemTemp являются независимыми целями. Оптимизация доставки выбирается отдельно как кэш, и удалённое содержимое может потребоваться загрузить снова. Необязательное безвозвратное удаление использует отдельный флажок очистки, повторно проверяет сохранённых кандидатов в пределах выбранного лимита и записывает каждый результат. Удаление минует корзину. Цели, возраст и лимиты файлов также настраиваются командой CLI cleanup.

### Профили

Проверяет профили Windows с учётом выбранного порога возраста, точных регистраций ProfileList и необязательных зависимостей учётных записей служб и запланированных задач, а затем возвращает одно ограниченное заключение. Загруженные, системные профили и профиль текущей учётной записи исключены из проверки. Кандидаты предназначены только для просмотра. Ни один профиль, папка, раздел реестра, учётная запись, служба, задача, учётные данные, политика или файл не изменяются, и удаление не выбирается. Зависимости приложений и возможность восстановления из резервной копии остаются непроверенными.

### Запланированные задачи

Инвентаризирует видимые запланированные задачи, их состояния и указанных субъектов безопасности. Задачи не запускаются, не регистрируются и не изменяются. Действия, триггеры и успешность выполнения не проверяются.

### Наведение порядка в Windows

Проверяет явно выбранные области очистки Windows, например Recall и ИИ, телеметрию, поисковые подсказки, потребительское содержимое, панель задач и меню «Пуск», уведомления, Edge, питание, гибернацию, языки Office и предустановленные программы для текущей учётной записи или всех профилей. Проверка выполняется только для чтения. Схему электропитания «Высокая производительность», таймеры сна и отключения дисплея, а также гибернацию можно изменить по отдельности, если соответствующая область выбрана единственной, при наличии свежих доказательств и явного подтверждения.
