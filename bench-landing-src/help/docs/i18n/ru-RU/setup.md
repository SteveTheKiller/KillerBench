# Загрузка и настройка

KillerBench 1.0.0 ещё не выпущен. Общедоступного пакета или загрузки KillerBench пока нет. На этой странице описаны текущие требования к пакету, чтобы вы могли подготовиться, не загружая неофициальную копию.

## Windows и среда выполнения

- Текущая цель публикации: **Windows x64**. Текущая база нативной проверки: Windows 11 x64. Нативные дистрибутивы для ARM64, x86 и Windows Server не предоставляются.
- KillerBench поставляется в двух видах. Установщик **зависит от платформы** и требует **.NET Desktop Runtime 10 for Windows x64**. Обычные .NET Runtime, ASP.NET Core Runtime и .NET Framework не предоставляют WPF. Переносная версия содержит собственную среду выполнения и не требует отдельной установки. Для инструмента командной строки `killerbench-cli.exe` нужна .NET 10 Runtime for Windows x64. SDK нужен для разработки, а не для обычного использования.
- Используйте версию Windows, которую поддерживает [.NET 10 on Windows](https://learn.microsoft.com/en-us/dotnet/core/install/windows). Поддержка среды выполнения не означает, что исправления KillerBench проверены в каждом поддерживаемом выпуске или сборке. Охват Windows 10 пока не завершён, а её поддерживаемые выпуски ограничены текущими требованиями жизненного цикла Майкрософт.
- Получайте Desktop Runtime только со [страницы загрузки .NET 10 от Майкрософт](https://dotnet.microsoft.com/en-us/download/dotnet/10.0), выбрав **.NET Desktop Runtime**, **Windows**, **x64**. Следуйте правилам установки программ, принятым в вашей организации.

Если доступна команда `dotnet`, команда `dotnet --list-runtimes` должна показать `Microsoft.WindowsDesktop.App 10.0.x` для установки x64. Среда выполнения, установленная только для другой архитектуры, не подходит для пакета установщика x64.

## Когда пакет будет опубликован

1. Используйте официальную загрузку по ссылке с этого сайта. Ссылка на загрузку KillerBench пока не активна.
2. Прочитайте требования этого пакета, [лицензию GPLv3](../license.txt), инструкции по соответствующему исходному коду, приложенные уведомления третьих сторон, а также сведения о подписи и контрольной сумме. Одно лишь имя файла не подтверждает подлинность.
3. Запустите установщик для текущей учётной записи или, после запроса на повышение прав, для всех пользователей. Он добавляет ярлык в меню «Пуск», необязательный ярлык на рабочем столе и запись в списке установки и удаления программ. Переносная версия работает без установки.
4. Запустите KillerBench под своей обычной учётной записью и выполните шаги со страницы [Первая диагностика](first-run.html). Ошибки доступа при диагностике остаются видимыми; повышение прав остаётся отдельным осознанным выбором.

Не обходите предупреждения безопасности Windows, чтобы запустить непроверенную копию. Прежде чем выбрать любое действие, изменяющее компьютер, создайте актуальную резервную копию.

При запуске KillerBench проверяет на GitHub наличие более нового стабильного выпуска и спрашивает разрешения перед установкой. Загрузка должна совпадать с опубликованной контрольной суммой SHA-256. Отключить проверку можно параметром **Проверять обновления при запуске** в разделе «О программе».

## Текущие ограничения

В текущей сборке двенадцать разделов, диагностика только для чтения, отчёты и отдельно выбираемые исправления. Нативная проверка исправлений ещё продолжается. Работающий интерфейс, успешная сборка или результат тестового набора не подтверждают поведение исправления на реальном компьютере. См. [Как изменения остаются безопасными](safety.html#development-status).

Иллюстративная консоль на главной странице показывает синтетический вывод. Первый общедоступный пакет ещё не готов.

KillerBench распространяется по лицензии GPLv3. Инструкции по предоставлению исходного кода и разрешения на шрифты третьих сторон для первого общедоступного пакета ещё не готовы. Сведения о доступности исходного кода, уведомлениях о распространении, конфиденциальности доказательств и поддержке приведены на странице [О программе KillerBench](about.html). [Руководство по Engine](../engine/) предназначено для разработчиков с авторизованной копией исходного кода; оно не означает, что общедоступный пакет Engine существует.
