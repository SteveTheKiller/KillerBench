# Шифрование диска с помощью BitLocker

Используйте этот порядок, чтобы включить BitLocker, сохранить ключ восстановления и убедиться, что диск защищён. KillerBench сохраняет и проверяет пароль восстановления до начала шифрования и никогда не показывает и не записывает пароль восстановления в журнал.

## Перед началом

- Запустите KillerBench от имени администратора.
- Диску Windows нужны предохранитель TPM и предохранитель с паролем восстановления. Диску с данными нужен только пароль восстановления.
- Решите, куда будет сохранён ключ восстановления: в файл вне шифруемого диска и, при желании, в Active Directory или Microsoft Entra ID.

## Проверка диска

1. Откройте **BitLocker** и выберите диск в поле **Том**.
2. Оставьте операцию **Проверить** и нажмите **Запустить диагностику**. Отчёт показывает состояние шифрования, состояние защиты и идентификаторы предохранителей.
3. Если TPM присутствует, но не готов, сначала подготовьте его в разделе **Безопасность**. KillerBench никогда не очищает TPM.

## Добавление нужных предохранителей

1. Откройте **Другие действия BitLocker**.
2. Выберите **Добавить предохранитель TPM** или **Добавить пароль восстановления**, нажмите **Предпросмотр**, отметьте **Внести это изменение на выбранном диске, когда я нажму «Выполнить действие»** и нажмите **Выполнить действие**.
3. Сразу сохраните новый пароль восстановления. KillerBench его не показывает.

## Сохранение ключа восстановления и шифрование

1. Нажмите **Найти предохранители восстановления** и выберите предохранитель с паролем восстановления.
2. Введите полный путь к файлу резервной копии вне шифруемого диска.
3. Выберите **Зашифровать**, укажите метод шифрования и отметьте **Сохранить выбранный ключ восстановления, затем начать шифрование, когда я выберу «Запустить диагностику»**.
4. Нажмите **Запустить диагностику**. KillerBench записывает резервную копию, проверяет её и один раз запускает шифрование.
5. Шифрование продолжается в фоновом режиме. Позже запустите **Проверить**, чтобы убедиться, что диск полностью зашифрован и защита включена.

## Сохранение в Active Directory или Entra ID

В разделе **Другие действия BitLocker** выберите сохранение в каталог для выбранного предохранителя. KillerBench сообщает, что Windows приняла запрос, но не может прочитать копию в каталоге, поэтому проверьте её в Active Directory или в центре администрирования Entra.

## Диски с данными и автоматическая разблокировка

После шифрования диска с данными параметр **Включить автоматическую разблокировку** обеспечивает его разблокировку при запуске Windows. Диск Windows должен быть уже полностью зашифрован с включённой защитой.

## Из командной строки

```powershell
killerbench-cli bitlocker-protectors C:
killerbench-cli bitlocker-protector-add C: recovery --execute
killerbench-cli bitlocker-encrypt C: RECOVERY_PROTECTOR_GUID D:\Keys\C-recovery.txt --execute
killerbench-cli bitlocker-escrow C: RECOVERY_PROTECTOR_GUID entra --execute
```

См. [bitlocker-protectors](cli.html#cmd-bitlocker-protectors), [bitlocker-protector-add](cli.html#cmd-bitlocker-protector-add), [bitlocker-encrypt](cli.html#cmd-bitlocker-encrypt) и [bitlocker-escrow](cli.html#cmd-bitlocker-escrow). Для каждой из них есть соответствующая команда `-recover` для прерванного запроса.
