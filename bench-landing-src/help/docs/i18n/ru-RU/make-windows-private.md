# Повышение конфиденциальности Windows

Используйте этот порядок, чтобы проверить и усилить конфиденциальность на ноутбуке. KillerBench читает текущие параметры, показывает, какими из них уже владеет политика или система управления устройствами, и изменяет только выбранные вами параметры, по одному, с точной отменой.

## Просмотр текущих параметров

1. Откройте **Конфиденциальность**.
2. Отметьте области, которые хотите проверить. Изначально ни одна область не отмечена.
3. Нажмите **Запустить диагностику**. Отчёт показывает текущее значение для этого компьютера и учётной записи, под которой запущен KillerBench, и отмечает параметры, которыми владеет политика.

## Изменение параметра

1. Выберите параметр в поле **Настройка конфиденциальности**, например камеру, микрофон, расположение, диагностические данные, рекламу, журнал буфера обмена, облачный поиск содержимого или выделение в поиске.
2. Выберите новое значение и отметьте **Применить, когда я выберу «Запустить диагностику»**.
3. Нажмите **Запустить диагностику**. KillerBench проверяет владельца политики, записывает текущее значение, вносит одно изменение и считывает его повторно.

Параметры, которыми владеет групповая политика или система управления устройствами, остаются без изменений. Изменяйте их там, где они управляются.

## Отмена изменения

Для каждого подтверждённого изменения сохраняется журнал. Соответствующая отмена восстанавливает точное прежнее значение, снова после проверки политики.

## Наведение порядка в Windows

Для рекомендаций, потребительского содержимого, Recall и функций ИИ, загромождения панели задач и меню «Пуск», Edge и предустановленных программ откройте **Обслуживание** и выберите **Наведение порядка в Windows**. Проверка выполняется только для чтения, и ничего не выбирается автоматически.

## Из командной строки

```powershell
killerbench-cli privacy-plan --select Camera --select ClipboardSync
killerbench-cli privacy-setting camera-access off --execute
killerbench-cli privacy-setting-undo camera-access VERIFIED_JOURNAL --execute
killerbench-cli debloat-review --area TelemetryAndReporting
```

См. [privacy-plan](cli.html#cmd-privacy-plan), [privacy-setting](cli.html#cmd-privacy-setting), [privacy-setting-undo](cli.html#cmd-privacy-setting-undo) и [debloat-review](cli.html#cmd-debloat-review). Для неподдерживаемого ключа выводится список поддерживаемых вариантов.
