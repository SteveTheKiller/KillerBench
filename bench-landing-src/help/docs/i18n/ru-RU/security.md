# Безопасность

Безопасность проверяет Microsoft Defender, брандмауэр, сертификаты и службы входа. Раздел также показывает состояние TPM и безопасности платформы, от которых зависят BitLocker и Windows Hello.

Пошаговые руководства: [Шифрование диска с помощью BitLocker](encrypt-with-bitlocker.html) и [Повышение конфиденциальности Windows](make-windows-private.html).

## Инструменты этого раздела

Проверяйте защиту, брандмауэр, сертификаты и службы входа.

### Microsoft Defender

Проверяет защиту Defender и состояние сигнатур. Автоматическое исправление обновляет сигнатуры, только если Defender сообщает об активной защите и устаревших сигнатурах. Используются настроенные источники сигнатур. Без изменения защиты, исключений и политики; без проверки на вредоносные программы.

### Центр обеспечения безопасности Windows

Проверяет ограниченный набор регистраций антивирусов с необработанным состоянием поставщика, точную историю сбоев службы и текущую готовность центра обеспечения безопасности Windows, не интерпретируя состояние защиты. Пустой список не является заключением о состоянии защиты, а количество регистраций, необработанное состояние или исторические сбои не дают права на восстановление или изменение безопасности. Необязательное восстановление запускает только точную включённую и остановленную службу после свежих проверок зависимостей. Существующий мониторинг состояния безопасности и уведомления могут возобновиться. Конфигурация антивируса, регистрации поставщиков, параметры защиты, исключения, уведомления, политика и тип запуска сохраняются. Проверка, обновление или изменение защиты не запрашиваются. Проверка охватывает только стабильное состояние службы, а не наличие антивируса, состояние защиты, актуальность сигнатур, доставку уведомлений, принадлежность регистраций или действующую политику.

### Службы брандмауэра

Считывает из ActiveStore параметры включения профилей домена, частного и общего, затем проверяет службы базового модуля фильтрации и брандмауэра Защитника Windows. Необязательное восстановление запускает только включённые и остановленные службы после свежих проверок зависимостей. Существующая политика фильтрации может вступить в силу и прервать сетевой или удалённый доступ. Типы запуска, разрешения служб, правила брандмауэра, профили и параметры IPsec сохраняются. Без сброса, изменения правил и остановки служб. Проверка подтверждает только то, что службы работают; фактическая защита и подключение остаются непроверенными.

### Срок действия сертификатов

Проверяет даты сертификатов и строит локальные цепочки доверия только по кэшу для личных хранилищ компьютера и текущего пользователя, а затем возвращает одно ограниченное рабочее заключение. Отзыв, предъявление сервером, привязки, регистрация, принадлежность политике, удалённое доверие и пригодность закрытых ключей остаются непроверенными. Ни один сертификат, параметр доверия, регистрация, привязка, закрытый ключ, приложение, служба или политика не изменяются.

### Диспетчер учётных данных

Проверяет доступность службы диспетчера учётных данных. Необязательное восстановление запускает только точную включённую и остановленную службу после свежих проверок зависимостей. Существующие приложения могут возобновить запросы сохранённых учётных данных. Содержимое хранилища, пароли, ключи доступа, сертификаты, маркеры, регистрации учётных данных, разрешения, политика, разрешения службы и тип запуска сохраняются. Содержимое учётных данных и операции с ними не запрашиваются. Проверка охватывает только стабильное состояние службы, а не получение учётных данных, проверку подлинности или доступ приложений.

### Диспетчер веб-учётных записей

Проверяет историю посредника учётных записей с очищенными полезными данными и точную доступность диспетчера веб-учётных записей. Необязательное восстановление запускает только точную включённую и остановленную службу после свежих проверок зависимостей. Существующие приложения могут возобновить запросы учётных записей и маркеров в соответствии с текущей политикой. Исторические события не дают права на восстановление и не определяют текущее состояние учётной записи. Учётные записи, учётные данные, маркеры, файлы cookie, регистрации приложений, разрешения, состояние входа, политика, разрешения службы и тип запуска сохраняются. KillerBench не выбирает никаких операций с учётными записями, учётными данными, маркерами, файлами cookie, разрешениями или входом. Проверка охватывает только стабильное состояние службы, а не проверку подлинности, выдачу маркеров или доступ приложений.

### Помощник по входу в учётную запись Майкрософт

Проверяет историю посредника учётных записей с очищенными полезными данными и точную доступность помощника по входу в учётную запись Майкрософт. Необязательное восстановление запускает только точную включённую и остановленную службу после свежих проверок зависимостей. Существующие запросы на вход в учётную запись Майкрософт могут возобновиться в соответствии с текущей политикой. Исторические события не дают права на восстановление и не определяют текущее состояние учётной записи. Учётные записи, учётные данные, маркеры, регистрация устройства, данные приложений, разрешения, состояние входа, политика, разрешения службы и тип запуска сохраняются. KillerBench не выбирает никаких операций с учётными записями, учётными данными, маркерами, регистрацией, разрешениями или входом. Проверка охватывает только стабильное состояние службы, а не проверку подлинности, подключение учётной записи или доступ приложений.
