# Дискіні тексеру және жөндеу

Мұны том қателерді хабарлағанда, Windows дискіні сканерлеуді сұрағанда немесе файлдар ашылмағанда пайдаланыңыз. KillerBench әуелі томды тек оқу режимінде тексереді және сақтық көшірмені растағаннан кейін ғана файл жүйесін жөндеуді жоспарлайды немесе іске қосады.

## Бастамас бұрын

- Томдағы маңызды деректердің сақтық көшірмесін жасаңыз. Файл жүйесін жөндеу зақымдалған файлдарды өзгертуі немесе жоюы мүмкін.
- KillerBench-ті әкімші ретінде іске қосыңыз.

## Томды тексеру

1. **Сақтау орны** бөлімін ашып, **Сақтау орны** таңдаңыз.
2. **Тексерілетін том** ішінен дискіні таңдап, **Диагнозды іске қосу** түймесін басыңыз.
3. Есепті оқыңыз. Ол диск пен томның күйін, dirty битін, NTFS-тің желідегі өзін-өзі қалпына келтіруін, контроллер мен диск құрылғыларының қателерін, сенімділік есептегіштерін және бастапқы күйге қайтарулар, қайталаулар мен күтпеген ажыратулар сияқты сақтау құрылғыларының соңғы оқиғаларын көрсетеді.

Таза тексеру жөндеу ұсынылмайтынын білдіреді. Диск температурасы, тозуы және түзетілмеген енгізу-шығару есептегіштері қарап шығуға арналған дәлелдер болып табылады және өздігінен жөндеуді іске қоспайды.

## Файл жүйесін жөндеу

1. **Файл жүйесі жөндеуін қарап шығу** түймесін басып, **Нүктелік жөндеу** немесе **Офлайн сканерлеу және жөндеу** таңдаңыз.
2. Деректер томы үшін оны пайдаланатын барлық нәрсені жаба алсаңыз, **Жүйелік емес томды офлайн етуге рұқсат беру** белгілеңіз. Windows томы офлайн бола алмайды, сондықтан оның жөндеуі келесі қайта іске қосуға жоспарланады.
3. **Осы томдағы маңызды деректердің сақтық көшірмесі жасалған** белгілеңіз.
4. Жөндеуді растаңыз. KillerBench әрекет етер алдында нақты томды дереу қайта тексереді және әуелі күтудегі жазбаны жазады.
5. Жоспарланған жөндеу үшін ыңғайлы уақытта қайта іске қосыңыз. KillerBench қайта іске қосудан кейін жөндеуді қайта іске қоспай нәтижені растайды.

## Оңтайландыру немесе retrim

Сол құрал томды талдап, Windows ұсынған оңтайландыруды, **Қатты күйлі сақтау құрылғысын retrim ету** немесе қатты дискіні дефрагментациялауды іске қоса алады. Әрқайсысы бір нақты сау томдағы бөлек расталатын әрекет.

## Пәрмен жолынан

```powershell
killerbench-cli storage-check C
killerbench-cli storage-repair-plan D: OfflineScanAndFix --allow-dismount
killerbench-cli storage-repair D: OfflineScanAndFix --allow-dismount --backup-confirmed --execute
killerbench-cli storage-repair-recover
```

[storage-check](cli.html#cmd-storage-check), [storage-repair-plan](cli.html#cmd-storage-repair-plan), [storage-repair](cli.html#cmd-storage-repair) және [volume-optimize](cli.html#cmd-volume-optimize) қараңыз.
