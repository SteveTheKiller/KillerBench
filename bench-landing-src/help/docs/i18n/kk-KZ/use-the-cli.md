# KillerBench-ті скрипттерден іске қосу

KillerBench дәлелдері скриптте, RMM тапсырмасында немесе қашықтағы консольде қажет болғанда пәрмен жолын пайдаланыңыз. `killerbench-cli` жұмыс үстелі қолданбасымен бірдей Engine-ді іске қосады және JSON шығарады.

## Бастау

1. PowerShell-ді `killerbench-cli.exe` орналасқан жерде ашыңыз немесе оның қалтасын жолға қосыңыз.
2. Әр пәрменді оның қауіпсіздік шекарасымен тізімдеу үшін `killerbench-cli help` іске қосыңыз.
3. 11 ұсынылған диагностика тобын көру үшін `killerbench-cli diagnostic-scopes` іске қосыңыз.

## Сканерлеуді іске қосу және есепті сақтау

```powershell
killerbench-cli full-scan --report C:\Reports\scan.html --json
```

`full-scan` тек диагностика жасайды және `--auto-repair` параметрін қабылдамайды. Нақты әрекет қажет болса, мақсатты жөндеу жұмыс ағынын пайдаланыңыз. `--report` қолданба экспорттайтын тақырыпқа сай есепті жазады. Тек кейбір аймақтарды тексеру үшін `--scope`, ал жұмыс ағыны журналынсыз біріктірілген JSON үшін `common-check` пайдаланыңыз.

## Шығу кодтарын оқу

| Код | Мағынасы |
| --- | --- |
| 0 | Алдын ала қарау немесе расталған нәтиже сәтті болды. |
| 1 | Іске қосу, енгізу немесе журнал қатесі пәрменді тоқтатты. |
| 2 | Аргументтер танылмады. |
| 3 | Бұғатталды, сәтсіз болды немесе расталмады. |
| 4 | Жұмыс ағыны растау алдында қайта іске қосуды қажет етеді. |
| 130 | Сіз оны тоқтаттыңыз. |

Тек оқуға арналған пәрменнің 0 кодымен шығуы оның орындалғанын білдіреді, компьютердің сау екенін емес. Қорытындылар үшін JSON оқыңыз.

## Өзгеріс жасау

Компьютерді өзгерте алатын әр пәрмен әдепкі бойынша алдын ала қарау көрсетеді. Алдын ала қарауды оқып, сол пәрменді `--execute` арқылы іске қосыңыз. Сұрау үзілсе, сәйкес `-recover` пәрменін іске қосыңыз; ол нақты нәтижені хабарлайды және өзгерісті ешқашан қайталамайды.

```powershell
killerbench-cli dhcp-renew
killerbench-cli dhcp-renew --execute
killerbench-cli dhcp-renew-recover
```

## Ескі нәтижелерді қайта ашу

```powershell
killerbench-cli workflow-journal C:\Users\me\AppData\Local\KillerBench\journal.json
killerbench-cli workflow-report journal.json report.html --include-repairs
```
