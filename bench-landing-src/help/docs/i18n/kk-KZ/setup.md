# Жүктеу және орнату

KillerBench 1.0.0 әлі шығарылмаған. Жалпыға қолжетімді KillerBench пакеті немесе жүктеуі әлі жоқ. Бұл бет ресми емес көшірмені жүктемей-ақ дайындала алуыңыз үшін ағымдағы пакет талаптарын сипаттайды.

## Windows және орындау ортасы

- Ағымдағы жариялау мақсаты **Windows x64**. Windows 11 x64 ағымдағы жергілікті тексерудің негізгі нұсқасы. Жергілікті ARM64, x86 және Windows Server таратылымдары берілмейді.
- KillerBench екі түрде пакетталады. Орнатушы **платформаға тәуелді** және **.NET Desktop Runtime 10 for Windows x64** қажет етеді. Қарапайым .NET Runtime, ASP.NET Core Runtime және .NET Framework WPF бермейді. Тасымалы нұсқа өз орындау ортасын қамтиды және бөлек орнатуды қажет етпейді. `killerbench-cli.exe` пәрмен жолы құралы .NET 10 Runtime for Windows x64 қажет етеді. SDK қарапайым пайдалану үшін емес, әзірлеу үшін керек.
- [.NET 10 on Windows](https://learn.microsoft.com/en-us/dotnet/core/install/windows) қолдайтын Windows нұсқасын пайдаланыңыз. Орындау ортасының қолдауы KillerBench жөндеулері қолдау көрсетілетін әр басылымда немесе құрастырмада тексерілген дегенді білдірмейді. Windows 10 қамтуы әлі күтілуде және оның қолдау көрсетілетін басылымдары Microsoft-тың ағымдағы өмірлік цикл талаптарымен шектеледі.
- Desktop Runtime-ды тек [Microsoft-тың .NET 10 жүктеу бетінен](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) алыңыз және **.NET Desktop Runtime**, **Windows**, **x64** таңдаңыз. Ұйымыңыздың бағдарламалық жасақтаманы орнату ережелерін сақтаңыз.

Егер `dotnet` қолжетімді болса, `dotnet --list-runtimes` x64 орнатылымы үшін `Microsoft.WindowsDesktop.App 10.0.x` көрсетуі керек. Тек басқа архитектура үшін орнатылған орындау ортасы x64 орнатушы пакетіне сай келмейді.

## Пакет жарияланғанда

1. Осы веб-сайттағы ресми жүктеу сілтемесін пайдаланыңыз. KillerBench жүктеу сілтемесі әлі белсенді емес.
2. Сол пакеттің талаптарын, [GPLv3 лицензиясын](../license.txt), Сәйкес бастапқы код нұсқауларын, қоса берілген үшінші тарап хабарламаларын, қолтаңба мен бақылау сомасы туралы ақпаратты оқыңыз. Файл атауының өзі түпнұсқалықты дәлелдемейді.
3. Орнатушыны ағымдағы тіркелгі үшін немесе құқықтарды көтеру сұрауынан кейін барлық пайдаланушылар үшін іске қосыңыз. Ол Бастау мәзіріне таңбаша, қосымша жұмыс үстелі таңбашасын және Бағдарламаларды қосу немесе жою тізіміне жазба қосады. Тасымалы нұсқа орнатусыз жұмыс істейді.
4. KillerBench-ті әдеттегі тіркелгіңізбен бастап, [Алғашқы диагностика](first-run.html) бетін орындаңыз. Диагностикалық қатынас қателері көрінетін болып қалады; құқықтарды көтеру бөлек әдейі таңдау болып табылады.

Тексерілмеген көшірмені іске қосу үшін Windows қауіпсіздік ескертулерін айналып өтпеңіз. Компьютерді өзгертетін кез келген әрекетті таңдамас бұрын ағымдағы сақтық көшірмені сақтаңыз.

Іске қосылғанда KillerBench GitHub-тан жаңарақ тұрақты шығарылымды тексереді және оны орнатпас бұрын сұрайды. Жүктелген файл жарияланған SHA-256 бақылау сомасына сәйкес келуі керек. Тексеруді «Бағдарлама туралы» ішіндегі **Іске қосылғанда жаңартуларды тексеру** арқылы өшіріңіз.

## Ағымдағы шектеулер

Ағымдағы құрастырмада он екі бөлім, тек оқуға арналған диагностика, есептер және жеке таңдалатын жөндеу беттері бар. Жергілікті жөндеуді тексеру әлі жүріп жатыр. Жұмыс істейтін интерфейс, сәтті құрастыру немесе тест деректерінің нәтижесі нақты компьютердегі жөндеу мінез-құлқын дәлелдемейді. [Өзгерістер қалай қауіпсіз болады](safety.html#development-status) бетін қараңыз.

Бастапқы беттегі иллюстрациялық консоль синтетикалық шығыс болып табылады. Алғашқы жалпыға қолжетімді пакет әлі күтілуде.

## Бастапқы код, лицензия және қолдау

KillerBench GPLv3 бойынша лицензияланған. Бастапқы кодты жеткізу нұсқаулары мен үшінші тарап қаріптерінің рұқсаттары алғашқы жалпыға қолжетімді пакет үшін әлі күтілуде. Бастапқы кодтың қолжетімділігі, тарату хабарламалары, дәлелдердің құпиялылығы және қолдау туралы ақпарат үшін [KillerBench туралы](about.html) бетін оқыңыз. [Engine нұсқаулығы](../engine/) рұқсат етілген бастапқы код көшірмесі бар әзірлеушілерге арналған; ол жалпыға қолжетімді Engine пакеті бар дегенді білдірмейді.
