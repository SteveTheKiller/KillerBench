# 修复

修复汇集了能够解决问题的工具。每个工具都会先进行诊断。只有当新证据显示出它所修复的确切问题时，才会提供修复，并且只有在你开启 **自动修复已确认的问题** 或亲自确认单项修复后才会运行。每项修复都会记录到日志中，并在之后进行验证。

操作指南：[修复系统文件](repair-system-files.html) 和 [修复 Windows 更新](fix-windows-update.html)。

## 自动修复和手动修复

**自动修复已确认的问题** 允许诊断工具在扫描后运行它证明需要的修复。此选项默认关闭。

如需单项维护修复，请打开 **高级：日志和手动修复** 并选择 **修复**。选择 **组件存储（DISM）** 或 **系统文件（SFC）**，阅读预览，勾选 **在此 PC 上运行此修复**，然后按 **运行修复**。有关任何更改前后会发生什么，请参阅 [如何保证更改安全](safety.html)。

## 本分区的工具

在诊断发现问题后使用这些工具。修复需要已确认的证据和明确的批准。

### Windows 核心服务

同时检查 Power、Plug and Play、User Manager、Group Policy Client、Network Store Interface、RPC Endpoint Mapper、Remote Procedure Call、DCOM Server Process Launcher、Background Tasks Infrastructure 和 CoreMessaging 服务。可选恢复仅启动在启动窗口和完整依赖项检查之后，经新证据确认已停止的确切已启用自动启动服务。按需启动的服务在空闲时保持不变。电源计划、设备、驱动程序、账户、凭据、配置文件、策略、适配器、地址、路由、DNS、防火墙配置、注册、终结点、任务注册、应用程序数据、服务权限和启动类型保持不变。不会请求策略刷新、设备扫描、账户操作、网络更改、电源设置更改、注册更改或任务启动。验证仅涵盖服务的稳定状态，不包括端到端的功能行为。

### 系统文件

有范围限制地清点 Windows 维护包、可选功能和功能的状态，检查前提条件，扫描受保护的系统文件，并且仅在实时检查确认损坏时才自动选择 SFC。包、功能或功能处于待处理状态时需要审阅，但不会授权安装、删除、清理、回滚、启用或禁用。

### WMI 存储库

先检查 WMI 服务的可用性，再检查存储库的一致性。自动修复可以启动符合条件的已停止服务并抢救已确认的损坏，然后验证每个结果。已禁用服务的设置保持不变。可读的注册会被合并；不可读的内容可能需要重新安装提供程序。管理客户端可能会被中断。不进行重置、删除或自动回滚。

### Windows 系统通知

读取最近的服务控制管理器历史记录，然后同时检查 COM+ Event System 和 System Event Notification Service。可选恢复会在启动 SENS 之前验证 COM+ Event System 的就绪状态。现有的登录、网络、电源和 COM+ 通知可能会在当前配置下恢复。COM+ 目录、订阅、通知注册、使用者、账户、权限、恢复设置、策略和启动类型保持不变。不会更改任何订阅、注册、使用者、账户、权限或策略。验证仅涵盖服务的稳定状态，不包括端到端的通知传递。

### 诊断策略服务

有范围限制地查看诊断策略的操作历史记录、确切的服务故障历史记录以及服务的当前就绪状态。不完整的证据优先。历史记录不能授权服务恢复或疑难解答操作。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有的诊断场景可能会恢复。策略、疑难解答数据和启动类型保持不变。不会运行任何疑难解答程序或建议的修复。验证仅涵盖服务的稳定状态，不包括故障检测、诊断完成或修复结果。

### Windows 错误报告

查看崩溃转储配置、有范围限制的转储文件元数据、最近的系统崩溃报告、Windows 错误报告服务的确切故障历史记录以及服务的当前就绪状态。历史报告不能确定当前故障或根本原因，也不能授权恢复。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有的排队报告可能会按照当前策略恢复。报告存档、转储、同意设置、上传策略和启动类型保持不变。不会请求上传或删除。验证仅涵盖服务的稳定状态，不包括报告的创建、上传、传递、问题解决或崩溃诊断。

### Windows 事件收集器

有范围限制地查看 Windows 事件收集器的订阅清单、确切的服务故障历史记录以及服务的当前就绪状态。清单为空可能是有意为之，订阅数量或历史故障不能授权恢复。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有订阅可能会恢复远程事件收集。订阅、转发的事件、凭据、通道设置、策略和启动类型保持不变。验证仅涵盖服务的稳定状态，不包括来源可访问性、身份验证、远程传递、事件的新旧或订阅运行状况。

### Windows 事件日志

检查四个诊断通道的启用状态、保留模式、当前大小、配置的限制、记录数和饱和度，然后检查 Windows 事件日志服务的可用性。自动修复可以在检查依赖项后启动已停止的已启用服务，并验证运行状态。单独确认的专用操作可以启用一个确切的、已禁用且不受管理的诊断通道，同时保留报告的所有其他设置。日志、通道权限、保留、大小限制、启动类型和受管理的设置保持不变。事件传递是否成功和存档容量仍未验证。

### Windows 时间服务

检查 Windows 时间的配置、服务和同步。当当前状态报告确切的服务已停止错误，并且新的策略、模式和依赖项检查均通过时，自动修复可以启动 W32Time，然后请求重新同步并验证新状态。这可能会使用现有的已配置来源调整时钟。启动类型、来源配置和受管理的设置保持不变。

### 任务计划程序服务

有范围限制地清点计划任务的状态、运行结果和错过的运行次数，然后在检查服务当前可用性之前，将其与任务计划程序服务的确切故障历史记录结合起来。任务发现和服务的历史故障不能授权启动服务。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有的已启用任务可能会在其配置的账户下开始运行，包括错过的触发器。不会更改任何任务定义、主体、凭据引用、策略或启动类型，也不会直接启动或删除任何任务。验证仅涵盖服务的稳定状态，不包括操作是否成功、凭据是否有效或未来的任务结果。

### 用户配置文件服务

检查用户配置文件服务的可用性。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有的登录和配置文件请求可能会恢复。配置文件文件夹、注册表配置单元、权限、配置文件列表注册、凭据、用户数据、策略、服务权限和启动类型保持不变。不会请求任何配置文件操作。验证仅涵盖服务的稳定状态，不包括登录、配置文件加载或用户数据访问。

### 备份服务

检查 Volume Shadow Copy、Microsoft Software Shadow Copy Provider、Windows Backup 和 Block Level Backup Engine 服务，然后读取 VSS 写入器状态、已注册的提供程序类型、当前快照和卷影存储分配。已停止的按需启动服务在空闲时可能是正常的。可选恢复会在检查依赖项后，仅启动已停止的自动启动服务，然后验证运行状态。现有的计划或中断的备份工作可能会恢复。已禁用和按需启动的启动设置、快照、卷影存储、提供程序注册、备份计划、目录、计划、目标、凭据和保留期限保持不变。不会选择或重新配置任何备份，不会重启任何服务，也不会删除任何快照或目录。提供程序注册、写入器状态、存储分配和服务的稳定状态不能验证备份完成、目标访问或还原成功。
