# 应用

应用会查看已安装的程序、Store 包、Office 和 Outlook、浏览器扩展、启动应用和搜索。删除和重置工具始终会先显示查看结果，并且只更改你选择的内容。

操作指南：[设置新计算机](set-up-new-pc.html)。

## 本分区的工具

查看已安装的应用、Store 包、Office 和 Outlook、浏览器扩展和搜索。

### 已安装的应用

读取所选计算机范围或运行账户范围内的应用程序卸载注册，然后将该范围与有范围限制的 Application 错误、可靠性监视器和重启证据相结合。其他账户和便携式应用会被排除。注册和广泛的历史记录并不能准确证明应用程序的运行状况或所有权。不会选择任何安装程序、卸载程序、应用程序、进程、服务、文件、注册、账户、策略或重启操作。

### 应用包

清点所选账户范围内已注册的 Appx/MSIX 包。默认为运行账户；所有用户范围需要管理员访问权限。报告确切的标识、框架和不可删除标志以及依赖项数量。不评估预配包、Win32 应用程序、受管理的所有权和应用程序数据。不会删除任何包。

### 浏览器扩展

有范围限制地清点运行账户中 Chrome、Edge、Brave 和 Firefox 扩展的标识。浏览器历史记录、凭据、扩展设置、清单内容、命令和策略值会被排除。扩展存在并不能证明它已启用、可信、有所有者或可以安全删除。不会更改任何浏览器、扩展或策略。

### 启动应用程序

清点计算机和运行账户的 Run 和 RunOnce 注册名称、启动文件夹中的文件名、Windows 启动审批状态以及启动或登录时的计划任务名称和状态，然后返回一个启动环境结论。不会收集命令行、目标路径、二进制审批时间戳、任务操作、参数、账户和凭据。注册并不能证明某项已运行、导致了延迟、不需要或可以安全禁用。审批状态不能证明存在相应的注册。不会选择任何注册、文件、应用程序、任务、服务或策略更改。

### Microsoft 应用移除

查看所选的 OneDrive、Outlook、Office/M365、Project 和 Teams 注册，并提供账户范围和保留选项。会关联计算机、运行账户和已注册包的清单；所有用户范围的查看还包括为新用户预配的包。当前账户中受支持的包可以在桌面应用或 CLI 中获得单独的确切保护计划。删除该包是一项单独的受保护桌面操作，具有自己的确认步骤。查看本身不会更改任何进程、应用程序、包、文件、凭据、文件夹位置、注册表值或用户数据。

### Outlook 重置

查看新版 Outlook、经典 Outlook 或两者，并明确选择缓存、配置文件设置、身份验证、OST 文件、加载项以及新版 Outlook 的重新安装。运行账户范围的查看会检查有范围限制的已知位置、确切的注册以及进程关闭后的就绪状态。单独确认的仅缓存操作会以唯一的恢复名称保留确切的缓存目录，并验证每次移动。所有用户范围的查看和其他重置区域仍仅供查看。不会删除任何保留的缓存、配置文件、OST 文件、凭据、加载项、包或设置。

### Foxit 清单

在两个视图中清点计算机上安装的 Foxit 产品和更新程序注册表值。不验证用户安装、有效策略和产品所有权。不会更改任何应用程序或设置。

### Windows Installer 服务

在恢复服务之前，检查 Installer 的限制、回滚、权限提升、日志记录和调试策略、进行中的标记、引擎二进制文件以及已注册的缓存包的可见性。仅针对报告的确切产品标识关联最近的失败和成功结果。如果满足前提条件，自动修复可以启动已启用的服务并验证 Running 状态。历史结果、日志记录、缓存可见性和调试发现不能授权更改包或策略。策略、日志、事务标记、启动类型和缓存的包保持不变。不测试特定包的安装。

### Windows 搜索

检查 Windows 搜索服务的可用性、当前 SystemIndex 活动以及最近的搜索事件历史记录。自动修复可以启动已停止的已启用服务并验证运行状态。单独的显式索引重建选项会保留之前的索引，开始新的索引，并验证服务和目录的确切状态。已编入索引的位置、策略、启动类型和保留的数据保持不变。启动服务或重建索引可能会恢复后台索引。搜索结果的完整性仍未测试。

### 应用准备

检查应用准备服务的可用性。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有的首次登录和应用程序预配可能会按照当前策略恢复。包、注册、许可证、用户配置文件、应用程序数据、策略和启动类型保持不变。KillerBench 不会选择任何包操作。验证仅涵盖服务的稳定状态，不包括登录、预配或应用程序启动。

### 状态存储库服务

检查状态存储库服务的可用性。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有的应用程序模型状态请求可能会恢复。注册、包、许可证、配置文件、浏览器和应用程序数据、存储库内容、策略和启动类型保持不变。不会请求重置、重新注册或删除。验证仅涵盖服务的稳定状态，不包括存储库一致性或应用程序运行情况。
