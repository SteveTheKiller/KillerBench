# 机器准备

机器准备用于准备新计算机。它会查看你选择的应用程序和配置，并为计算机命名。它本身不会下载或安装任何内容。

操作指南：[设置新计算机](set-up-new-pc.html)。

## 运行前检查安装程序

命令行可以在你运行供应商的安装程序之前对其进行验证：

```powershell
killerbench-cli depot-verify-installer chrome C:\Installers\ChromeSetup.exe
```

只有当安装程序带有该供应商确切组织名称的有效 Authenticode 签名时，KillerBench 才会信任它。它绝不会运行安装程序。

## 本分区的工具

准备新计算机：应用程序、名称和配置。

### 机器准备

查看明确选择的预配应用程序和配置组。会在不下载或执行安装程序的情况下，对当前的卸载、应用包和 Office 即点即用注册进行关联。配置选项会说明后果，并在实现后转到单独的受保护工作流程。不会执行任何下载、安装、账户、更新、清理、策略、注册表、服务、配置文件或重启操作。

### 计算机名称

根据当前标识和域角色查看建议的计算机名称。不会重命名、收集凭据或重启。名称是否可用、权限和应用程序依赖项仍未验证。
