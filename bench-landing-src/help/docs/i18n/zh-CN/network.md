# 网络

网络会检查连接、DNS、路由、无线和有线登录、文件共享和远程访问。访问其他主机的工具会使用你设置的目标和超时，除非你确认修复，否则不会更改任何内容。

操作指南：[解决网络和 Internet 问题](fix-network.html)。

## 本分区的工具

检查连接、DNS、路由、无线、共享和远程访问。

### 网络

检查适配器、地址状态和来源、网关、DNS 配置、有效的 DNS 命名空间策略、TCP 设置、原生 Winsock 协议和命名空间提供程序目录结构、IP 路由表以及 Hosts 文件映射。自动修复可以启动已启用的 DNS Client、DHCP Client、SMB 客户端、Network Location Awareness、Network List 和 IP Helper 服务，并为缺少可用 IPv4 地址的已连接物理 DHCP 适配器续订租约。启动网络标识服务可能会重新计算网络标识，并应用另一个现有的防火墙配置文件。IP Helper 可能会激活现有的 IPv6 过渡、端口代理和网络通知功能。服务恢复只验证运行状态，不验证名称解析成功、路由选择、网络标识或隧道运行。路由、Hosts 条目、DNS 服务器、配置文件、防火墙规则、Winsock 提供程序、过渡配置、启动类型和策略保持不变。续订可能会更改租用的地址并中断连接。静态设置和虚拟适配器保持不变。网关的确切 ICMP 响应不能验证 Internet 可访问性。

### 无线网络

检查网络设备和 WLAN AutoConfig 的可用性。可选恢复会在检查依赖项后，仅启动已启用且已停止的服务；已保存的配置文件可能会自动重新连接。配置文件、凭据、策略、无线电设置和启动类型保持不变。不重置适配器，也不安装驱动程序。验证涵盖运行状态，不包括无线身份验证或连接。

### 有线身份验证 (802.1X)

针对需要 802.1X 的网络，检查网络设备和 Wired AutoConfig。可选恢复会在检查依赖项后，仅启动已启用且已停止的服务。现有的身份验证配置文件可能会激活并更改网络访问。证书、凭据、配置文件、策略和启动设置保持不变。验证仅涵盖运行状态，不包括身份验证或连接。

### 网络连接

有范围限制地查看当前网络配置文件的分配、确切的服务故障历史记录以及网络连接服务的当前就绪状态。不完整的证据优先。公用配置文件和历史故障仅作为背景信息，不能授权恢复或网络更改。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有的网络管理界面可能会恢复。适配器、地址、路由、DNS 设置、连接配置文件、凭据、防火墙配置、策略和启动类型保持不变。不会更改任何连接或网络设置。验证仅涵盖服务的稳定状态，不包括适配器运行、地址分配、路由、名称解析或连接。

### WinHTTP 自动代理

查看已保存的 WinHTTP 默认值、当前账户的 Internet 设置、确切的服务故障历史记录以及 WinHTTP 自动代理的当前就绪状态。不完整的证据优先。代理配置和历史故障不能授权服务恢复或发现。已停止的按需启动服务可能是正常的。仅当选择此工具时，可选恢复才可以在重新检查依赖项后启动已停止的已启用服务。现有应用程序可能会在当前设置下恢复 WPAD 或 PAC 发现。代理定义、PAC URL、凭据、网络设置、防火墙配置、策略、服务权限和启动类型保持不变。不会获取任何 URL，也不会更改任何代理或网络设置。验证仅涵盖服务的稳定状态，不包括发现、可访问性、身份验证、策略所有权或应用程序使用。

### Windows 连接管理器

有范围限制地查看当前网络配置文件的分配、确切的服务故障历史记录以及 Windows 连接管理器的当前就绪状态。不完整的证据优先。公用配置文件和历史故障仅作为背景信息，不能授权恢复或连接决策。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。Windows 可能会在现有配置文件和策略下恢复自动连接决策。适配器、配置文件、凭据、按流量计费、成本、漫游、防火墙、VPN 和身份验证设置以及启动类型保持不变。不会更改任何配置文件、适配器或设置。验证仅涵盖服务的稳定状态，不包括配置文件适用性、连接选择、身份验证、路由、名称解析或连接。

### 网络设置服务

有范围限制地查看当前适配器的协议绑定、确切的服务故障历史记录以及网络设置服务的当前就绪状态。不完整的证据优先。绑定状态和历史故障不能授权服务恢复或设置更改。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有的待处理网络设置可能会按照 Windows 策略恢复。适配器、驱动程序、驱动程序包、绑定、地址、路由、DNS 设置、配置文件、凭据、防火墙配置、策略和启动类型保持不变。KillerBench 不会选择任何驱动程序或配置更改。验证仅涵盖服务的稳定状态，不包括适配器可用性、驱动程序适用性、设置完成、地址分配、路由、名称解析或连接。

### 文件共享 (SMB)

检查 Windows SMB 服务器的可用性。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的 Server 服务。现有的文件和打印机共享可能会在当前权限和防火墙策略下变得可访问。不会更改任何共享、权限、SMB 设置、防火墙规则、凭据、策略或启动类型。验证仅涵盖服务的稳定状态，不包括客户端访问或文件传输。

### 远程访问连接管理器

在不收集机密信息的情况下，有范围限制地查看当前账户的 VPN 配置文件配置、确切的服务故障历史记录以及远程访问连接管理器的当前就绪状态。清单为空可能是有意为之，配置文件的存在、连接标签或历史故障不能授权恢复或连接尝试。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有的拨号和 VPN 请求可能会恢复。连接配置文件、凭据、路由、适配器、身份验证设置、策略和启动类型保持不变。不会发起任何连接。验证仅涵盖服务的稳定状态，不包括配置文件适用性、服务器可访问性、身份验证、隧道协商、路由安装、名称解析或连接。

### 远程桌面服务

查看本地远程桌面的启用状态、网络级别身份验证和侦听器端口、有范围限制的连接和会话历史记录、确切的服务故障历史记录以及服务的当前就绪状态。不完整的证据优先。历史记录不能授权服务恢复或配置更改。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有的侦听器可能会在当前策略、NLA、防火墙规则和权限下变得可访问。远程桌面启用状态、侦听器、证书、端口、防火墙规则、NLA、权限、会话、策略、服务权限和启动类型保持不变。不会创建或更改任何侦听器、防火墙规则、账户访问、证书或会话。验证仅涵盖服务的稳定状态，不包括有效策略、侦听器绑定、防火墙访问、证书标识、权限、身份验证、网络可访问性、连接成功或会话创建。

### Windows 远程管理

有范围限制地查看 WinRM 侦听器配置、操作历史记录、确切的服务故障历史记录以及服务的当前就绪状态。不完整的证据优先。已禁用的侦听器或当前的服务问题需要审阅，而历史记录不能授权恢复或配置更改。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有的 WS-Management 侦听器可能会在当前的身份验证、证书、防火墙、TrustedHosts 和策略设置下变得可访问。侦听器、地址、端口、证书、身份验证、加密、TrustedHosts、防火墙规则、权限、配额、策略、服务权限和启动类型保持不变。不会创建或更改任何侦听器、防火墙规则、信任条目、证书、凭据或远程会话。验证仅涵盖服务的稳定状态，不包括有效策略、侦听器绑定、防火墙访问、证书有效性、身份验证、权限、客户端可访问性或远程命令执行。
