# Перевірка й виправлення диска

Користуйтеся цим порядком, коли том повідомляє про помилки, Windows пропонує перевірити диск або файли не відкриваються. KillerBench спершу перевіряє том лише для читання й планує або запускає виправлення файлової системи лише після того, як ви підтвердите наявність резервної копії.

## Перед початком

- Створіть резервну копію важливих даних на томі. Виправлення файлової системи може змінити чи видалити пошкоджені файли.
- Запустіть KillerBench від імені адміністратора.

## Перевірка тому

1. Відкрийте **Сховище** й виберіть **Сховище**.
2. Виберіть диск у полі **Том для перевірки** й натисніть **Запустити діагностику**.
3. Прочитайте звіт. Він показує стан диска й тому, біт забруднення, оперативне самовідновлення NTFS, помилки контролерів і дискових пристроїв, лічильники надійності та нещодавні події сховища, як-от скидання, повтори та неочікуване від'єднання.

Чиста перевірка означає, що виправлення не пропонується. Температура диска, знос і лічильники невиправлених помилок введення-виведення є даними для огляду й самі по собі не запускають виправлення.

## Виправлення файлової системи

1. Натисніть **Переглянути виправлення файлової системи** й виберіть **Точкове виправлення** або **Автономне сканування та виправлення**.
2. Для тому з даними позначте **Дозволити відключення несистемного тому**, якщо можете закрити все, що його використовує. Том Windows не можна відключити, тож його виправлення планується на наступне перезавантаження.
3. Позначте **Важливі дані на цьому томі збережено в резервній копії**.
4. Підтвердьте виправлення. KillerBench повторно перевіряє точний том безпосередньо перед дією та спершу записує очікувальний запис.
5. Для запланованого виправлення перезавантажте комп'ютер, коли буде зручно. KillerBench перевірить результат після перезавантаження, не запускаючи виправлення повторно.

## Оптимізація або повторний Trim

Той самий інструмент може проаналізувати том і виконати рекомендовану Windows оптимізацію, **Повторний Trim твердотільного сховища** або дефрагментацію жорсткого диска. Кожна з них є окремою підтверджуваною дією над одним точним справним томом.

## З командного рядка

```powershell
killerbench-cli storage-check C
killerbench-cli storage-repair-plan D: OfflineScanAndFix --allow-dismount
killerbench-cli storage-repair D: OfflineScanAndFix --allow-dismount --backup-confirmed --execute
killerbench-cli storage-repair-recover
```

Див. [storage-check](cli.html#cmd-storage-check), [storage-repair-plan](cli.html#cmd-storage-repair-plan), [storage-repair](cli.html#cmd-storage-repair) і [volume-optimize](cli.html#cmd-volume-optimize).
