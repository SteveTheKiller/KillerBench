# マシンの準備

マシンの準備では、新しいコンピューターを使える状態に整えます。選択したアプリケーションと構成を確認し、コンピューターに名前を付けます。それ自体が何かをダウンロードしたりインストールしたりすることはありません。

手順ガイド: [新しいコンピューターをセットアップする](set-up-new-pc.html)。

## 実行前にインストーラーを確認する

コマンド ラインでは、実行する前にベンダーのインストーラーを検証できます。

```powershell
killerbench-cli depot-verify-installer chrome C:\Installers\ChromeSetup.exe
```

KillerBench は、ベンダーの正確な組織名による有効な Authenticode 署名がある場合にのみインストーラーを信頼します。インストーラーを実行することはありません。

## このセクションのツール

新しいコンピューターを準備します。アプリケーション、名前、構成が対象です。

### マシンの準備

明示的に選択したプロビジョニング用アプリケーションと構成グループを確認します。現在のアンインストール登録、アプリ パッケージ登録、Office クイック実行の登録は、インストーラーをダウンロードや実行することなく照合されます。構成の選択では影響を説明し、実装されている場合は個別に保護されたワークフローに誘導します。ダウンロード、インストール、アカウント、更新、クリーンアップ、ポリシー、レジストリ、サービス、プロファイル、再起動の操作は一切行われません。

### コンピューター名

提案されたコンピューター名を、現在の識別情報とドメインでの役割に照らして確認します。名前の変更、資格情報の収集、再起動は行いません。名前が使用可能かどうか、アクセス許可、アプリケーションの依存関係は未検証のままです。
