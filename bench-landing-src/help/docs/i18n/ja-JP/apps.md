# アプリ

アプリでは、インストール済みのプログラム、Store パッケージ、Office と Outlook、ブラウザー拡張機能、スタートアップ アプリ、検索を確認します。削除とリセットのツールは常に先に確認内容を表示し、選択したものだけを変更します。

手順ガイド: [新しいコンピューターをセットアップする](set-up-new-pc.html)。

## このセクションのツール

インストール済みアプリ、Store パッケージ、Office と Outlook、ブラウザー拡張機能、検索を確認します。

### インストール済みアプリ

選択したコンピューター範囲または実行中のアカウント範囲でアプリケーションのアンインストール登録を読み取り、その範囲を、範囲を限定した Application のエラー、信頼性モニター、再起動の証拠と組み合わせます。ほかのアカウントとポータブル アプリは除外されます。登録や大まかな履歴は、アプリケーションの正常性や所有の正確な証明にはなりません。インストーラー、アンインストーラー、アプリケーション、プロセス、サービス、ファイル、登録、アカウント、ポリシー、再起動の操作は選択されません。

### アプリ パッケージ

選択したアカウント範囲について、登録済みの Appx/MSIX パッケージを一覧にします。既定は実行中のアカウントで、すべてのユーザーを対象にするには管理者アクセスが必要です。正確な識別情報、フレームワークと削除不可のフラグ、依存関係の数を報告します。プロビジョニングされたパッケージ、Win32 アプリケーション、管理された所有、アプリケーション データは評価されません。パッケージは削除されません。

### ブラウザー拡張機能

実行中のアカウントの Chrome、Edge、Brave、Firefox の拡張機能の識別情報を、範囲を限定して一覧にします。ブラウザーの履歴、資格情報、拡張機能の設定、マニフェストの内容、コマンド、ポリシーの値は除外されます。存在していても、有効であること、信頼できること、所有者、安全に削除できることは証明されません。ブラウザー、拡張機能、ポリシーは変更されません。

### スタートアップ アプリケーション

コンピューターと実行中のアカウントの Run と RunOnce の登録名、スタートアップ フォルダーのファイル名、Windows のスタートアップ承認の状態、起動時またはログオン時のスケジュールされたタスクの名前と状態を一覧にし、スタートアップ環境に関する 1 つの結論を返します。コマンド ライン、ターゲットのパス、承認のバイナリ タイムスタンプ、タスクのアクション、引数、アカウント、資格情報は収集されません。登録があっても、項目が実行されたこと、遅延の原因になったこと、不要であること、安全に無効化できることは証明されません。承認の状態があっても、対応する登録が存在することは証明されません。登録、ファイル、アプリケーション、タスク、サービス、ポリシーの変更は選択されません。

### Microsoft アプリの削除

選択した OneDrive、Outlook、Office/M365、Project、Teams の登録を、アカウント範囲と保持の選択とともに確認します。コンピューター、実行中のアカウント、登録済みパッケージの一覧が照合され、すべてのユーザーを対象とした確認では、新しいユーザー向けにプロビジョニングされたパッケージも含まれます。現在のアカウントの対応パッケージには、デスクトップまたは CLI で個別の正確な保護プランを作成できます。その 1 つのパッケージの削除は、独自の確認を伴う個別の保護付きデスクトップ操作です。確認そのものによって、プロセス、アプリケーション、パッケージ、ファイル、資格情報、フォルダーの場所、レジストリ値、ユーザー データが変更されることはありません。

### Outlook のリセット

新しい Outlook、従来の Outlook、またはその両方について、キャッシュ、プロファイル設定、認証、OST ファイル、アドイン、新しい Outlook の再インストールを明示的に選んで確認します。実行中のアカウントの確認では、範囲を限定した既知の場所、正確な登録、プロセス終了の準備状態を確認します。個別に確認するキャッシュ専用の操作では、正確なキャッシュ ディレクトリを一意の回復用の名前で保持し、それぞれの移動を検証します。すべてのユーザーを対象とした確認とその他のリセット領域は、確認のみにとどまります。保持されたキャッシュ、プロファイル、OST ファイル、資格情報、アドイン、パッケージ、設定は削除されません。

### Foxit のインベントリ

コンピューターにインストールされた Foxit 製品と、アップデーターのレジストリ値を両方のビューで一覧にします。ユーザーごとのインストール、有効なポリシー、製品の所有は検証されません。アプリケーションと設定は変更されません。

### Windows Installer サービス

サービスの回復の前に、Installer の制限、ロールバック、昇格、ログ記録、デバッグのポリシー、進行中のマーカー、エンジンのバイナリ、登録済みのキャッシュ パッケージの可視性を確認します。最近の失敗と成功の結果は、報告された正確な製品の識別情報についてのみ照合します。前提条件を満たしていれば、自動修復で有効なサービスを開始し、Running を検証できます。過去の結果、ログ記録、キャッシュの可視性、デバッグの所見によって、パッケージやポリシーの変更が許可されることはありません。ポリシー、ログ、トランザクション マーカー、スタートアップの種類、キャッシュ パッケージは保持されます。特定のパッケージのインストールはテストされません。

### Windows Search

Windows Search サービスの可用性、現在の SystemIndex の活動、最近の Search イベントの履歴を確認します。自動修復では、停止している有効なサービスを開始し、実行中の状態を検証できます。個別に明示するインデックスの再構築では、以前のインデックスを保持し、新しいインデックスを開始して、サービスとディレクトリの正確な状態を検証します。インデックス対象の場所、ポリシー、スタートアップの種類、保持されたデータは保持されます。サービスの開始やインデックスの再構築によって、バックグラウンドのインデックス作成が再開する場合があります。検索結果の完全性はテストされていません。

### App Readiness

App Readiness サービスの可用性を確認します。オプションの回復では、新たな依存関係チェックの後で、有効かつ停止している対象のサービスのみを開始します。既存の初回サインインとアプリケーションのプロビジョニングが、現在のポリシーに従って再開する場合があります。パッケージ、登録、ライセンス、ユーザー プロファイル、アプリケーション データ、ポリシー、スタートアップの種類は保持されます。KillerBench はパッケージの操作を選択しません。検証の対象はサービスの安定した状態のみで、サインイン、プロビジョニング、アプリケーションの起動は含まれません。

### 状態リポジトリ サービス

状態リポジトリ サービスの可用性を確認します。オプションの回復では、新たな依存関係チェックの後で、有効かつ停止している対象のサービスのみを開始します。既存のアプリケーション モデルの状態要求が再開する場合があります。登録、パッケージ、ライセンス、プロファイル、ブラウザーとアプリケーションのデータ、リポジトリの内容、ポリシー、スタートアップの種類は保持されます。リセット、再登録、削除は要求されません。検証の対象はサービスの安定した状態のみで、リポジトリの整合性やアプリケーションの動作は含まれません。

### AppX 展開サービス

AppX 展開サービスの可用性を確認します。オプションの回復では、新たな依存関係チェックの後で、有効かつ停止している対象のサービスのみを開始します。既存の展開、登録、サービシングの要求が、現在のポリシーに従って再開する場合があります。パッケージ、登録、ライセンス、プロファイル、アプリケーション データ、リポジトリの内容、ポリシー、サービスのアクセス許可、スタートアップの種類は保持されます。KillerBench はパッケージの操作を選択しません。検証の対象はサービスの安定した状態のみで、展開、登録、アプリケーションの起動は含まれません。

### クライアント ライセンス サービス

クライアント ライセンス サービスの可用性を確認します。オプションの回復では、新たな依存関係チェックの後で、有効かつ停止している対象のサービスのみを開始します。既存の Store アプリケーションのライセンス要求が、現在のポリシーに従って再開する場合があります。パッケージ、登録、ライセンス、トークン、アカウント、プロファイル、アプリケーション データ、ポリシー、サービスのアクセス許可、スタートアップの種類は保持されます。KillerBench は、パッケージ、ライセンス、トークン、アカウントの操作を選択しません。検証の対象はサービスの安定した状態のみで、ライセンスの検証やアプリケーションの起動は含まれません。

### Microsoft Store インストール サービス

最近の Microsoft Store のインストール履歴と、Store インストール サービスの正確な可用性を確認します。オプションの回復では、新たな依存関係チェックの後で、有効かつ停止している対象のサービスのみを開始します。既存の Store のダウンロードとインストールの要求が、現在のポリシーに従って再開する場合があります。パッケージ、登録、ライセンス、アカウント、アプリケーション データ、ダウンロードの状態、ソース、ポリシー、サービスのアクセス許可、スタートアップの種類は保持されます。KillerBench は、パッケージ、ダウンロード、ライセンス、アカウント、ソース、インストールの操作を選択しません。検証の対象はサービスの安定した状態のみで、ダウンロード、インストール、ライセンス、アプリケーションの結果は含まれません。

### Windows ライセンス マネージャー サービス

### Windows PushToInstall サービス

Windows PushToInstall サービスの可用性を確認します。オプションの回復では、新たな依存関係チェックの後で、有効かつ停止している対象のサービスのみを開始します。以前に承認された既存のリモート インストール要求が、現在のポリシーに従って再開する場合があります。パッケージ、登録、ライセンス、アカウント、アプリケーション データ、キューにある要求、ソース、ポリシー、サービスのアクセス許可、スタートアップの種類は保持されます。KillerBench は、要求、パッケージ、ソース、アカウント、インストールを作成、承認、選択しません。検証の対象はサービスの安定した状態のみで、要求の処理、ダウンロード、インストール、アプリケーションの結果は含まれません。
