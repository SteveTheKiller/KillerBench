# セキュリティ

セキュリティでは、Microsoft Defender、ファイアウォール、証明書、サインイン サービスを確認します。また、BitLocker と Windows Hello が依存する TPM とプラットフォーム セキュリティの状態も示します。

手順ガイド: [BitLocker でドライブを暗号化する](encrypt-with-bitlocker.html) と [Windows のプライバシーを強化する](make-windows-private.html)。

## このセクションのツール

保護、ファイアウォール、証明書、サインイン サービスを確認します。

### Microsoft Defender

Defender の保護と署名の状態を確認します。自動修復は、Defender が保護が有効で署名が古いと報告した場合にのみ署名を更新します。構成済みの署名ソースを使用します。保護、除外、ポリシーは変更せず、マルウェアのスキャンも行いません。

### Windows セキュリティ センター

保護の正常性を解釈することなく、プロバイダーの生の状態を含むウイルス対策の登録、サービスの正確な障害履歴、Windows セキュリティ センターの現在の準備状態を、範囲を限定して確認します。一覧が空でも保護の正常性に関する結論にはならず、登録数、生の状態、過去の障害によって回復やセキュリティの変更が許可されることはありません。オプションの回復では、新たな依存関係チェックの後で、有効かつ停止している対象のサービスのみを開始します。既存のセキュリティ状態の監視と通知が再開する場合があります。ウイルス対策の構成、プロバイダーの登録、保護の設定、除外、通知、ポリシー、スタートアップの種類は保持されます。スキャン、更新、保護の変更は要求されません。検証の対象はサービスの安定した状態のみで、ウイルス対策の有無、保護の状態、署名の新しさ、通知の配信、登録の所有者、有効なポリシーは含まれません。

### ファイアウォール サービス

ActiveStore からドメイン、プライベート、パブリックの各プロファイルの有効化設定を読み取り、Base Filtering Engine と Windows Defender ファイアウォールのサービスを確認します。オプションの回復では、新たな依存関係チェックの後で、有効かつ停止しているサービスのみを開始します。既存のフィルター ポリシーが有効になり、ネットワークやリモート アクセスが中断される場合があります。スタートアップの種類、サービスのアクセス許可、ファイアウォール規則、プロファイル、IPsec の設定は保持されます。リセット、規則の変更、サービスの停止は行いません。検証で確認されるのはサービスが実行中であることだけで、実際の保護と接続は未検証のままです。

### 証明書の有効期限

コンピューターと現在のユーザーの個人ストアについて、証明書の日付を確認し、キャッシュのみを使ったローカルの信頼チェーンを構築して、範囲を限定した 1 つの動作に関する結論を返します。失効、サーバーでの提示、バインド、登録、ポリシーの所有、リモートの信頼、秘密キーの使用可否は未検証のままです。証明書、信頼の設定、登録、バインド、秘密キー、アプリケーション、サービス、ポリシーは一切変更されません。

### 資格情報マネージャー

資格情報マネージャー サービスの可用性を確認します。オプションの回復では、新たな依存関係チェックの後で、有効かつ停止している対象のサービスのみを開始します。既存のアプリケーションが、保存された資格情報の要求を再開する場合があります。資格情報コンテナーの内容、パスワード、パスキー、証明書、トークン、資格情報の登録、アクセス許可、ポリシー、サービスのアクセス許可、スタートアップの種類は保持されます。資格情報の内容や操作は要求されません。検証の対象はサービスの安定した状態のみで、資格情報の取得、認証、アプリケーションのアクセスは含まれません。

### Web アカウント マネージャー

内容を除去したアカウント ブローカーの履歴と、Web アカウント マネージャーの正確な可用性を確認します。オプションの回復では、新たな依存関係チェックの後で、有効かつ停止している対象のサービスのみを開始します。既存のアプリケーションが、現在のポリシーに従ってアカウントとトークンの要求を再開する場合があります。過去のイベントによって回復が許可されたり、現在のアカウントの状態が確定したりすることはありません。アカウント、資格情報、トークン、Cookie、アプリケーションの登録、アクセス許可、サインインの状態、ポリシー、サービスのアクセス許可、スタートアップの種類は保持されます。KillerBench は、アカウント、資格情報、トークン、Cookie、アクセス許可、サインインの操作を選択しません。検証の対象はサービスの安定した状態のみで、認証、トークンの発行、アプリケーションのアクセスは含まれません。

### Microsoft アカウント サインイン アシスタント

内容を除去したアカウント ブローカーの履歴と、Microsoft アカウント サインイン アシスタントの正確な可用性を確認します。オプションの回復では、新たな依存関係チェックの後で、有効かつ停止している対象のサービスのみを開始します。既存の Microsoft アカウントのサインイン要求が、現在のポリシーに従って再開する場合があります。過去のイベントによって回復が許可されたり、現在のアカウントの状態が確定したりすることはありません。アカウント、資格情報、トークン、デバイスの登録、アプリケーション データ、アクセス許可、サインインの状態、ポリシー、サービスのアクセス許可、スタートアップの種類は保持されます。KillerBench は、アカウント、資格情報、トークン、登録、アクセス許可、サインインの操作を選択しません。検証の対象はサービスの安定した状態のみで、認証、アカウントの接続、アプリケーションのアクセスは含まれません。
