KillerBench availability

These reference tools require a supported KillerBench CLI installed on your computer. Installing KillerMCP does not supply KillerBench. No public KillerBench package is available yet; review Download and setup before configuring this integration.

What it can do

The current KillerBench integration exposes two deterministic reference tools.

Device Manager problem codesReturn the exact code identity, a short explanation, a bounded next evidence step, and whether a restart may help.
Windows system error codesReturn the installed Windows message for an unsigned decimal or hexadecimal Win32 code.
Read-only by designThese lookups do not scan, repair, restart, install, remove, or change anything on the computer.
Evidence stays explicitA reference result explains a code. It does not prove root cause, machine health, or permission to run a repair.

Data safety and permissions

KillerBench code lookups run locally through its command line interface. They receive only the requested numeric code and do not read logs, files, devices, or machine state.

How it works

KillerMCP is a small program that lets your AI assistant use supported Killer apps installed on your computer. You install and connect it once, and it automatically finds the apps and tools available on your computer. When you ask your assistant to explain a Device Manager or Windows error code, KillerMCP checks the number, asks KillerBench to look it up without changing anything on your computer, and gives the explanation back to your assistant. The lookup is performed by the installed KillerBench app, not by this webpage.

Current limits

  • The current integration accepts unsigned values up to 32 bits.
  • Device Manager lookups use KillerBench's curated problem-code catalog.
  • Win32 results use the installed Windows system message table and do not load vendor message modules.
  • Broader KillerBench diagnostic workflows are not exposed through MCP yet.

Why KillerMCP runs twice

Claude Desktop starts each local MCP server twice. One copy serves the app's own chats, and the other serves Claude sessions that use this computer remotely. Seeing two KillerMCP.exe processes under Claude in Task Manager is normal. KillerMCP is not installed twice, and nothing needs to be fixed.

One connection for the family

Install KillerMCP once. It adds all KillerTools utilities and detects supported Killer apps on the computer. Each app contributes its tools through the same agent connection.
