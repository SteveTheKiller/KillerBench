# Maintenance

Maintenance keeps a machine tidy: file cleanup, old user profiles, scheduled tasks and decluttering Windows. Every tool previews what it would remove before anything is deleted.

Step-by-step guides: [Free up disk space](free-disk-space.html) and [Make Windows more private](make-windows-private.html).

## Tools in this section

Clean up files, profiles and scheduled tasks, and declutter Windows.

### Cleanup

Estimate selected temporary-file, cache and retained diagnostic-evidence targets using the age and file-limit settings in the main panel. Windows Temp and Windows SystemTemp are independent targets. Delivery Optimization is a separate cache choice and removed content may need to be downloaded again. Optional permanent removal uses the separate cleanup checkbox, rechecks retained candidates within the selected limit and records each outcome. Deletion bypasses the Recycle Bin. Targets, age and file limits are also configurable through the cleanup CLI command.

### Profiles

Review Windows profiles using the selected age threshold, exact ProfileList registrations and optional service and scheduled-task account dependencies, then return one bounded review conclusion. Loaded, system and current-account profiles are excluded from review eligibility. Candidates remain review-only. No profile, folder, registry key, account, service, task, credential, policy or file is changed, and no removal is selected. Application dependencies and backup recoverability remain unverified.

### Scheduled tasks

Inventory visible scheduled tasks, states and reported principals. No tasks are started, registered or changed. Actions, triggers and execution success are not verified.

### Declutter Windows

Review explicit Windows cleanup areas such as Recall and AI, telemetry, search suggestions, consumer content, taskbar and Start, notifications, Edge, power, hibernation, Office languages and preinstalled software for the running account or all profiles. Review is read-only. High performance power, sleep and display timers, and hibernation can each be changed when that area is the only selection, with fresh evidence and explicit confirmation.
