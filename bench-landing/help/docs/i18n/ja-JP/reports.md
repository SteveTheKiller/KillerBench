# レポートと証拠

実行のたびに、読む、フィルターする、エクスポートすることができるレポートが作成されます。レポートでは、証明されたことと観察されただけのことが常に区別されます。

## 表示される状態

| 状態 | 意味 |
| --- | --- |
| 要確認 | 証拠が、注意すべき問題を裏付けています。 |
| 情報 | 証拠が収集され、参考情報として表示されています。 |
| 未完了または不明 | チェックを完了できなかったか、証拠を取得できませんでした。正常とみなされることはありません。 |
| 履歴 | 過去のイベントです。経緯の説明にはなりますが、現在の障害を証明するものではありません。 |
| 検証済み | 修復や変更が、結果を読み直すことで確認されました。 |

## 生の出力と読みやすいレポート

**生の出力** は、技術的な証拠を元の行番号とともに保持するため、どの結論もそのソースまでたどることができます。**読みやすいレポート** は、同じ実行をわかりやすい言葉で要約し、安全な次の手順を最初に示します。

## 保存されたログ

KillerBench は、コンピューターで何も実行せずに、CBS や Setup のログなど保存済みの Windows ログを読み取ることもできます。結論は、それを生み出した行に正確にリンクします。セッションソースの **サンプルを読み込む** を使うと、安全に試せる合成の例が開きます。

## エクスポート

**レポートをエクスポート** は、ソースのパス、解析済みのエントリ、証拠の抜粋を含めてレポートを保存するため、チケットに添付する前に確認できます。生のログや証拠の抜粋には、コンピューター名、アカウント、パス、機密性のあるソース テキストが含まれる可能性があります。保護付きのコレクターは保持する内容を制限しますが、インポートした証拠が編集済みである保証はありません。共有する前に機密情報を確認して削除してください。
