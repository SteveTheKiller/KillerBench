# ダウンロードとセットアップ

KillerBench 1.0.0 は未リリースです。公開されている KillerBench のパッケージやダウンロードはまだありません。このページでは、非公式のコピーをダウンロードせずに準備できるよう、現在のパッケージ要件を説明します。

## Windows とランタイム

- 現在の公開対象は **Windows x64** です。Windows 11 x64 が現在の実機検証の基準です。ネイティブの ARM64、x86、Windows Server 向けの配布は提供されません。
- KillerBench は 2 種類の形でパッケージ化されています。インストーラーは **フレームワーク依存** で、**.NET Desktop Runtime 10 for Windows x64** が必要です。通常の .NET Runtime、ASP.NET Core Runtime、.NET Framework には WPF が含まれません。ポータブル版は独自のランタイムを含み、別途インストールする必要はありません。コマンド ライン ツール `killerbench-cli.exe` には .NET 10 Runtime for Windows x64 が必要です。SDK は開発に必要なもので、通常の使用には必要ありません。
- [.NET 10 on Windows](https://learn.microsoft.com/en-us/dotnet/core/install/windows) がサポートする Windows バージョンを使用してください。ランタイムがサポートされていても、KillerBench の修復がサポート対象のすべてのエディションやビルドで検証済みであることを意味するわけではありません。Windows 10 への対応は保留中で、サポートされるエディションは Microsoft の現在のライフサイクル要件によって制限されます。
- Desktop Runtime は [Microsoft の .NET 10 ダウンロード ページ](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) からのみ入手し、**.NET Desktop Runtime**、**Windows**、**x64** を選択してください。組織のソフトウェア インストール規則に従ってください。

`dotnet` が使用できる場合、`dotnet --list-runtimes` を実行すると x64 インストールの `Microsoft.WindowsDesktop.App 10.0.x` が表示されるはずです。別のアーキテクチャ用にのみインストールされたランタイムでは、x64 のインストーラー パッケージの要件を満たしません。

## パッケージが公開されたら

1. この Web サイトからリンクされている公式ダウンロードを使用してください。KillerBench のダウンロード リンクはまだ有効になっていません。
2. そのパッケージの要件、[GPLv3 ライセンス](../license.txt)、対応するソースの入手方法、同梱のサードパーティ通知、署名とチェックサムの情報をお読みください。ファイル名だけでは真正性は証明されません。
3. 現在のアカウント用に、または昇格のプロンプトの後にすべてのユーザー用に、インストーラーを実行します。スタート メニューのショートカット、任意のデスクトップ ショートカット、プログラムの追加と削除のエントリが追加されます。ポータブル版はインストールせずに実行できます。
4. 通常のアカウントで KillerBench を起動し、[初めての診断](first-run.html) に従ってください。診断時のアクセス エラーは表示されたままになります。昇格は別の意図的な選択です。

未検証のコピーを実行するために Windows のセキュリティ警告を回避しないでください。コンピューターを変更する操作を選ぶ前に、最新のバックアップを保持してください。

起動時に KillerBench は GitHub で新しい安定版リリースを確認し、インストールする前に確認を求めます。ダウンロードは公開されている SHA-256 チェックサムと一致する必要があります。この確認は、このアプリについての **起動時に更新を確認する** でオフにできます。

## 現在の制限

現在のビルドには、12 のセクション、読み取り専用の診断、レポート、個別に選択する修復機能があります。実機での修復の検証はまだ進行中です。動作する UI、ビルドの成功、テスト データでの結果は、実際のコンピューターでの修復の動作を証明するものではありません。[変更の安全性を保つ仕組み](safety.html#development-status) を参照してください。

ランディング ページの説明用コンソールは合成された出力です。アプリの最終的なスクリーンショットと最初の公開パッケージはまだ準備中です。

## ソース、ライセンス、サポート

KillerBench は GPLv3 でライセンスされています。最初の公開パッケージに向けたソースの提供方法とサードパーティ フォントの使用許可は、まだ保留中です。ソースの入手可能性、配布に関する通知、証拠のプライバシー、サポート情報については [KillerBench について](about.html) をお読みください。[Engine ガイド](../engine/) は、許可されたソースのチェックアウトを持つ開発者向けです。公開された Engine パッケージがあることを意味するものではありません。
