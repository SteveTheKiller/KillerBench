# 初めての診断

[ダウンロードとセットアップ](setup.html) から始めて、システム全体のスキャンを実行します。スキャンは診断の証拠を収集してローカルのジャーナルを保存しますが、修復は実行しません。結論は確認した範囲を説明するもので、コンピューターで起こりうるすべての障害を示すものではありません。

## スキャンを実行する

1. KillerBench を開きます。**診断** セクションが開き、**システム全体のスキャン** が選択されています。
2. 初回の実行では、**確認された問題を自動修復** をオフのままにします。
3. **診断を実行** を押します。各チェックの実行中は、右側の **生の出力** に進行状況が表示されます。
4. 完了すると、出力ペインが **読みやすいレポート** に切り替わります。

まずは昇格せずに始めてください。BitLocker の保護機能や保護されたサービスなど、一部の Windows の証拠には管理者権限が必要です。標準アカウントでは、これらのチェックは証拠を取得できなかったと報告します。その証拠が必要な場合は、現在の実行を完了してレポートを保存してから、**管理者として実行** で意図的に KillerBench を開き直してください。昇格によって修復が選択されたり承認されたりすることはありません。

## レポートを読む

レポートの冒頭には **要確認**、**検証済みの修復**、**未完了**、**確認済み** の件数が表示され、その後に推奨される次の手順が続きます。

- **注意が必要な点** には、証拠が裏付ける問題が重要なものから順に表示されます。
- **収集した情報** には、不完全だった証拠や取得できなかった証拠を含め、読み取った内容が表示されます。
- 過去のイベントは履歴としてラベル付けされます。先月のエラーは現在の障害として扱われません。

証拠が欠けている場合に正常とみなされることはありません。チェックを実行できなかった場合は、レポートにそう記載されます。

## チェックを自分で選ぶ

システム全体のスキャンではなく個別のチェックを選ぶには、**チェックを選択（上級者向け）** を開きます。アプリの各セクションにも専用のツールがあり、このガイドの **セクション** のページで説明しています。

## 見つかった問題を修正する

レポートが修正を推奨する場合は、開くべきセクションとツールが示されます。最初の修復の前に [変更の安全性を保つ仕組み](safety.html) をお読みください。実機での検証はまだ進行中です。診断が成功しても、提示されたすべての修復がお使いの Windows ビルドでテスト済みであることにはなりません。変更の前には必ずバックアップを保持し、対象と影響を正確に確認してください。
