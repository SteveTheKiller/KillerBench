# デバイス

デバイスでは、プリンター、オーディオ、カメラ、Bluetooth、入力デバイス、接続されたハードウェアが依存する Windows サービスを扱います。

手順ガイド: [印刷の問題を解決する](fix-printing.html) と [クラッシュとブルー スクリーンを調査する](investigate-crashes.html)。

## このセクションのツール

印刷、オーディオ、カメラ、Bluetooth、入力、接続されたハードウェアを支えるサービスを扱います。

### 印刷

Print Spooler、ローカル キューの一時停止、表示されている印刷ジョブ、オフラインの設定、ドライバーが報告する状態を確認した後、キュー、ドライバー、ポート、Standard TCP/IP エンドポイント、印刷プロセッサ、印刷モニターの登録を一覧にします。最近の PrintService の問題は、現在のキューの正確な識別情報が 1 つだけある場合にのみ照合します。割り当てられた Standard TCP/IP エンドポイントには、アプリケーション データ、SNMP、印刷ジョブを使わずに、範囲を限定した接続試行を 1 回行います。自動修復では、有効なスプーラーの開始、待機中のジョブについて新しい証拠がある特定の一時停止キューの再開、オフライン モードの解除ができます。待機中のものがない意図的な一時停止は、確認のみにとどまります。リモート接続、SNMP コミュニティ文字列、拡張機能の登録、ジョブの内容は保持されます。状態コードや接続の成功は、プリンターの識別、消耗品、機構、キューによる受け付け、レンダリングの成功、物理的な印刷を確定するものではありません。

### オーディオ

既定のマルチメディア入出力デバイスの識別情報と共有形式、オーディオ デバイスとドライバーの状態、Audio Endpoint Builder と Windows Audio を確認します。自動修復では、停止している有効なサービスを開始し、実行中の状態を検証します。スタートアップの設定、ドライバー、選択されたデバイス、排他モード、音量レベルは保持されます。音声の再生、録音、アプリケーションのオーディオのルーティングはテストされていません。

### カメラ サポート

カメラとイメージング デバイスのエラー、ハードウェア ID、インストールされているドライバーの証拠、Windows Camera Frame Server の可用性を確認します。オプションの回復では、依存関係を確認した後で、有効かつ停止しているサービスのみを開始します。すでにカメラへのアクセスを要求しているアプリケーションが、既存のアクセス許可のもとで再開する場合があります。カメラのプライバシー設定、アクセス許可、デバイスの構成、ポリシー、ドライバー、スタートアップの種類は保持されます。リセット、アクセス許可の変更、ドライバーのインストールは行いません。検証の対象は報告されたデバイスの構成とサービスの実行中の状態のみで、画像の取り込み、プライバシー上のアクセス、物理的な動作は含まれません。

### Bluetooth サポート

Bluetooth デバイスのエラー、ハードウェア ID、インストールされているドライバーの証拠、Bluetooth サポート サービスの可用性を確認します。オプションの回復では、依存関係を確認した後で、有効かつ停止しているサービスのみを開始します。ペアリング済みのデバイスが再接続する場合があります。ペアリング、無線の設定、デバイスの構成、ポリシー、スタートアップの種類は保持されます。リセット、デバイスの削除、ドライバーのインストールは行いません。検証の対象は報告されたデバイスの構成とサービスの実行中の状態のみで、検出、ペアリング、オーディオ、データ転送は含まれません。

### スマート カード サポート

スマート カード リーダーのエラー、ハードウェア ID、インストールされているドライバーの証拠、スマート カード サービスの可用性を確認します。オプションの回復では、依存関係を確認した後で、有効かつ停止しているサービスのみを開始します。アプリケーションが、既存のポリシーのもとで挿入されたカードの検出を再開する場合があります。証明書、PIN、資格情報、リーダーとカードの構成、ポリシー、ドライバー、スタートアップの種類は保持されます。初期化、登録、PIN の操作、リーダーのリセット、ドライバーのインストールは行いません。検証の対象は報告されたリーダーの構成とサービスの実行中の状態のみで、カードの検出、認証、アプリケーションのアクセスは含まれません。

### 生体認証サポート

生体認証デバイスのエラー、ハードウェア ID、インストールされているドライバーの証拠、Windows Biometric Service の可用性を確認します。オプションの回復では、依存関係を確認した後で、有効かつ停止しているサービスのみを開始します。既存の Windows Hello とアプリケーションの要求が、現在のポリシーに従って再開する場合があります。生体認証テンプレート、Windows Hello のデータ、資格情報、デバイスの構成、アクセス許可、ポリシー、ドライバー、スタートアップの種類は保持されます。登録、テンプレートの削除、センサーのリセット、アクセス許可の変更、ドライバーのインストールは行いません。検証の対象は報告されたセンサーの構成とサービスの実行中の状態のみで、取り込み、照合、サインイン、アプリケーションのアクセスは含まれません。

### ヒューマン インターフェイス デバイス サービス

ヒューマン インターフェイス デバイス サービスの可用性を確認します。オプションの回復では、新たな依存関係チェックの後で、有効かつ停止している対象のサービスのみを開始します。既存のホット ボタン、メディア コントロール、その他の HID 機能が再開する場合があります。デバイス、ドライバー、ボタンの割り当て、アクセシビリティの設定、入力の設定、ポリシー、サービスのアクセス許可、スタートアップの種類は保持されます。KillerBench は、デバイス、ドライバー、割り当て、入力の設定の操作を選択しません。検証の対象はサービスの安定した状態のみで、ボタン、コントロール、アプリケーションの動作は含まれません。

### ポータブル デバイス列挙サービス

ポータブル デバイス列挙サービスの可用性を確認します。オプションの回復では、新たな依存関係チェックの後で、有効かつ停止している対象のサービスのみを開始します。既存のアプリケーションが、接続されたポータブル デバイスの検出とアクセスを再開する場合があります。デバイス、ドライバー、ファイル、ライブラリ、同期の設定、アクセス許可、ポリシー、サービスのアクセス許可、スタートアップの種類は保持されます。KillerBench は、デバイス、ファイル、ライブラリ、同期、転送の操作を選択しません。検証の対象はサービスの安定した状態のみで、列挙、アクセス、同期、転送は含まれません。

### Windows Image Acquisition (WIA)

Windows Image Acquisition サービスの可用性を確認します。オプションの回復では、新たな依存関係チェックの後で、有効かつ停止している対象のサービスのみを開始します。既存のスキャナーと静止画の取り込みの要求が、現在のアプリケーションのアクセス許可のもとで再開する場合があります。デバイス、ドライバー、画像データ、アプリケーションのアクセス許可、プライバシーの設定、転送の設定、ポリシー、サービスのアクセス許可、スタートアップの種類は保持されます。KillerBench は、デバイス、ドライバー、画像、アクセス許可、転送、取り込みの操作を選択しません。検証の対象はサービスの安定した状態のみで、スキャナー、カメラ、転送、アプリケーションの動作は含まれません。

### シェル ハードウェア検出

範囲を限定したストレージ コントローラー、ディスク、ポータブル デバイスのプラグ アンド プレイの証拠と、インストールされているドライバーの参照を確認した後、シェル ハードウェア検出サービスの可用性を確認します。オプションの回復では、新たな依存関係チェックの後で、有効かつ停止している対象のサービスのみを開始します。既存の自動再生とハードウェア接続の通知が、現在のポリシーに従って再開する場合があります。デバイスの観察や保持された履歴によって、回復が許可されることはありません。デバイス、ドライバー、ボリューム、マウント ポイント、自動再生の設定、ハンドラー、ポリシー、サービスのアクセス許可、スタートアップの種類は保持されます。デバイスや設定の操作は要求されません。検証の対象はサービスの安定した状態のみで、通知の配信、メディアの準備状態、ボリュームへのアクセス、デバイスの物理的な動作は含まれません。

### デバイス インストール サービス

デバイス インストール サービスの可用性を確認します。オプションの回復では、新たな依存関係チェックの後で、有効かつ停止している対象のサービスのみを開始します。Windows が要求した既存のデバイス インストール作業が、現在のポリシーに従って再開する場合があります。デバイス、ドライバー、パッケージ、構成、バインド、クラスの設定、ポリシー、サービスのアクセス許可、スタートアップの種類は保持されます。KillerBench は何も選択せず、何もインストールしません。検証の対象はサービスの安定した状態のみで、デバイスのインストールや動作は含まれません。

### デバイス関連付けサービス

最近のデバイス セットアップとプラグ アンド プレイの履歴を確認した後、デバイス関連付けサービスの可用性を確認します。オプションの回復では、新たな依存関係チェックの後で、有効かつ停止している対象のサービスのみを開始します。Windows が要求した既存のデバイス関連付けの作業が再開する場合があります。ペアリング済みおよび関連付け済みのデバイス、ドライバー、資格情報、メタデータ、アクセス許可、ポリシー、サービスのアクセス許可、スタートアップの種類は保持されます。KillerBench は、デバイス、ペアリング、削除、リセット、ドライバーの操作を選択しません。検証の対象はサービスの安定した状態のみで、検出、ペアリング、関連付け、デバイスの動作は含まれません。

### ディスプレイ拡張サービス

グラフィックス アダプターとモニターの証拠を確認した後、ディスプレイ拡張サービスの可用性を確認します。オプションの回復では、新たな依存関係チェックの後で、有効かつ停止している対象のサービスのみを開始します。既存の明るさ、色、拡張の要求が再開する場合があります。ディスプレイの構成、明るさ、カラー プロファイル、HDR の設定、デバイス、ドライバー、電源の設定、ポリシー、サービスのアクセス許可、スタートアップの種類は保持されます。ディスプレイの設定は変更されません。検証の対象はサービスの安定した状態のみで、拡張の動作、画質、ディスプレイの物理的な動作は含まれません。

### テキスト入力管理サービス

キーボード、マウス、HID デバイスの証拠を確認した後、テキスト入力管理サービスの可用性を確認します。オプションの回復では、新たな依存関係チェックの後で、有効かつ停止している対象のサービスのみを開始します。既存のタッチ キーボード、手書き、絵文字、高度なテキスト入力の要求が再開する場合があります。辞書、手書きのデータ、言語とキーボードの設定、アクセシビリティとプライバシーの設定、デバイス、ドライバー、ポリシー、サービスのアクセス許可、スタートアップの種類は保持されます。入力したテキスト、キー入力、手書きの内容は収集されません。検証の対象はサービスの安定した状態のみで、テキストの入力、認識、デバイスの動作は含まれません。

### Windows フォント キャッシュ サービス

Windows フォント キャッシュ サービスの可用性を確認します。オプションの回復では、新たな依存関係チェックの後で、有効かつ停止している対象のサービスのみを開始します。既存のアプリケーションが、現在のフォント キャッシュの使用を再開する場合があります。インストールされているフォント、フォント ファイル、アプリケーション データ、キャッシュ ファイル、ポリシー、サービスのアクセス許可、スタートアップの種類は保持されます。KillerBench はフォントのインストールや削除を行わず、キャッシュの削除や再構築も行いません。検証の対象はサービスの安定した状態のみで、テキストの描画やアプリケーションの動作は含まれません。

### Function Discovery Provider Host

Function Discovery Provider Host の可用性を確認します。オプションの回復では、新たな依存関係チェックの後で、有効かつ停止している対象のサービスのみを開始します。既存のアプリケーションが、インストールされたプロバイダーを通じてネットワーク デバイスの検出を再開する場合があります。ネットワーク プロファイル、共有、デバイス、プロバイダー、ファイアウォール規則、検出の設定、資格情報、ポリシー、サービスのアクセス許可、スタートアップの種類は保持されます。KillerBench は、デバイス、共有、プロバイダー、ファイアウォール規則、検出の設定の操作を選択しません。検証の対象はサービスの安定した状態のみで、プロバイダーの正常性、デバイスの検出、接続は含まれません。

### Function Discovery Resource Publication

Function Discovery Resource Publication の可用性を確認します。オプションの回復では、新たな依存関係チェックの後で、有効かつ停止している対象のサービスのみを開始します。既存のネットワーク探索とファイアウォールの設定によって、この PC が検出可能になる場合があります。ネットワーク プロファイル、共有、公開されたリソース、ファイアウォール規則、検出の設定、資格情報、ポリシー、サービスのアクセス許可、スタートアップの種類は保持されます。KillerBench は、共有、リソース、ファイアウォール規則、検出の設定の操作を選択しません。検証の対象はサービスの安定した状態のみで、公開、可視性、アクセス、接続は含まれません。
