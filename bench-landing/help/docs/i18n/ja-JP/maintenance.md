# メンテナンス

メンテナンスでは、ファイルのクリーンアップ、古いユーザー プロファイル、スケジュールされたタスク、Windows の軽量化によってコンピューターを整理します。どのツールも、何かを削除する前に削除対象をプレビューします。

手順ガイド: [ディスク領域を解放する](free-disk-space.html) と [Windows のプライバシーを強化する](make-windows-private.html)。

## このセクションのツール

ファイル、プロファイル、スケジュールされたタスクをクリーンアップし、Windows を軽量化します。

### クリーンアップ

メイン パネルの経過日数とファイル数の上限の設定を使って、選択した一時ファイル、キャッシュ、保持された診断の証拠の対象を見積もります。Windows Temp と Windows SystemTemp は独立した対象です。配信の最適化は別のキャッシュの選択肢で、削除した内容は再度ダウンロードが必要になる場合があります。オプションの完全な削除は別のクリーンアップ用チェック ボックスを使い、選択した上限の範囲で保持された候補を再確認して、各結果を記録します。削除はごみ箱を経由しません。対象、経過日数、ファイル数の上限は、CLI の cleanup コマンドでも構成できます。

### プロファイル

選択した経過日数のしきい値、正確な ProfileList の登録、オプションのサービスとスケジュールされたタスクのアカウント依存関係を使って Windows プロファイルを確認し、範囲を限定した 1 つの確認結果を返します。読み込まれているプロファイル、システム プロファイル、現在のアカウントのプロファイルは確認の対象から除外されます。候補は確認のみにとどまります。プロファイル、フォルダー、レジストリ キー、アカウント、サービス、タスク、資格情報、ポリシー、ファイルは一切変更されず、削除が選択されることもありません。アプリケーションの依存関係とバックアップからの回復可能性は未検証のままです。

### スケジュールされたタスク

表示されているスケジュールされたタスク、その状態、報告されたプリンシパルを一覧にします。タスクの開始、登録、変更は行いません。アクション、トリガー、実行の成否は検証されません。

### Windows の軽量化

実行中のアカウントまたはすべてのプロファイルについて、Recall と AI、テレメトリ、検索のおすすめ、コンシューマー向けコンテンツ、タスク バーとスタート、通知、Edge、電源、休止状態、Office の言語、プリインストール ソフトウェアなど、明示的な Windows のクリーンアップ領域を確認します。確認は読み取り専用です。高パフォーマンスの電源、スリープとディスプレイのタイマー、休止状態は、その領域だけを選択した場合に、新しい証拠と明示的な確認のうえでそれぞれ変更できます。
