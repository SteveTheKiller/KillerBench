# 隐私

隐私会读取此计算机和运行 KillerBench 的账户的隐私设置，然后让你更改所选的设置。它的范围超出 Windows 设置应用，涵盖应用权限、云搜索和搜索要点。

操作指南：[增强 Windows 隐私](make-windows-private.html)。

## 查看和更改设置

选择要检查的隐私区域，然后按 **运行诊断**。所有区域最初都未选中，且查看是只读的。

要更改某项设置，请使用 **隐私设置** 控件。KillerBench 会检查该设置是否已由策略或设备管理拥有，记录当前值，只进行你所请求的一项更改，并读回以确认。由策略拥有的设置保持不变。

这些设置包括广告选项、剪贴板历史记录、19 项应用权限设置（例如相机、麦克风和位置）、个人和工作账户的云内容搜索以及搜索要点。

## 本分区的工具

查看并更改应用权限、建议、搜索和广告设置。

### 隐私

读取此计算机和运行 KillerBench 的账户中所选的隐私注册表设置。单独的显式控件可以在重新检查策略、持久准备和精确验证之后，更改剪贴板历史记录或受支持的账户设置。其他隐私选项仍为只读。注册表快照不能证明有效权限或策略所有权。
