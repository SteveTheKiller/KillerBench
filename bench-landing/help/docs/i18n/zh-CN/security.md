# 安全

安全会检查 Microsoft Defender、防火墙、证书和登录服务。它还会显示 BitLocker 和 Windows Hello 所依赖的 TPM 和平台安全状态。

操作指南：[使用 BitLocker 加密驱动器](encrypt-with-bitlocker.html) 和 [增强 Windows 隐私](make-windows-private.html)。

## 本分区的工具

检查保护、防火墙、证书和登录服务。

### Microsoft Defender

检查 Defender 保护和签名状态。只有当 Defender 报告保护处于活动状态且签名已过期时，自动修复才会更新签名。使用已配置的签名来源。不更改保护、排除项或策略；不进行恶意软件扫描。

### Windows 安全中心

在不解释保护运行状况的情况下，有范围限制地查看带有提供程序原始状态的防病毒注册、确切的服务故障历史记录以及 Windows 安全中心的当前就绪状态。列表为空并不代表对保护运行状况的结论，注册数量、原始状态或历史故障也不能授权恢复或安全更改。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有的安全状态监视和通知可能会恢复。防病毒配置、提供程序注册、保护设置、排除项、通知、策略和启动类型保持不变。不会请求扫描、更新或更改保护。验证仅涵盖服务的稳定状态，不包括防病毒软件是否存在、保护状态、签名的新旧、通知传递、注册所有权或有效策略。

### 防火墙服务

从 ActiveStore 读取域、专用和公用配置文件的启用设置，然后检查 Base Filtering Engine 和 Windows Defender 防火墙服务。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的服务。现有的筛选策略可能会生效，并中断网络或远程访问。启动类型、服务权限、防火墙规则、配置文件和 IPsec 设置保持不变。不进行重置、规则更改或服务停止。验证只能确认服务正在运行；实际保护和连接性仍未验证。

### 证书到期

检查证书日期，并为计算机和当前用户的个人存储构建仅使用缓存的本地信任链，然后返回一个有范围限制的运行结论。吊销、服务器出示、绑定、注册、策略所有权、远程信任和私钥可用性仍未验证。不会更改任何证书、信任设置、注册、绑定、私钥、应用程序、服务或策略。

### 凭据管理器

检查凭据管理器服务的可用性。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有应用程序可能会恢复对已存储凭据的请求。保管库内容、密码、通行密钥、证书、令牌、凭据注册、权限、策略、服务权限和启动类型保持不变。不会请求凭据内容或凭据操作。验证仅涵盖服务的稳定状态，不包括凭据检索、身份验证或应用程序访问。

### Web 帐户管理器

查看已清除负载内容的账户代理历史记录以及 Web 帐户管理器的确切可用性。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有应用程序可能会按照当前策略恢复账户和令牌请求。历史事件不能授权恢复，也不能确定当前的账户状态。账户、凭据、令牌、Cookie、应用程序注册、权限、登录状态、策略、服务权限和启动类型保持不变。KillerBench 不会选择任何账户、凭据、令牌、Cookie、权限或登录操作。验证仅涵盖服务的稳定状态，不包括身份验证、令牌颁发或应用程序访问。

### Microsoft 账户登录助手

查看已清除负载内容的账户代理历史记录以及 Microsoft 账户登录助手的确切可用性。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有的 Microsoft 账户登录请求可能会按照当前策略恢复。历史事件不能授权恢复，也不能确定当前的账户状态。账户、凭据、令牌、设备注册、应用程序数据、权限、登录状态、策略、服务权限和启动类型保持不变。KillerBench 不会选择任何账户、凭据、令牌、注册、权限或登录操作。验证仅涵盖服务的稳定状态，不包括身份验证、账户连接或应用程序访问。
