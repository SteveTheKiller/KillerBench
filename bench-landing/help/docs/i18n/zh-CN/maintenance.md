# 维护

维护让计算机保持整洁：文件清理、旧用户配置文件、计划任务和 Windows 精简。每个工具都会在删除任何内容之前预览将删除的内容。

操作指南：[释放磁盘空间](free-disk-space.html) 和 [增强 Windows 隐私](make-windows-private.html)。

## 本分区的工具

清理文件、配置文件和计划任务，并精简 Windows。

### 清理

使用主面板中的天数和文件数限制设置，估算所选的临时文件、缓存和保留的诊断证据目标。Windows Temp 和 Windows SystemTemp 是独立的目标。传递优化是单独的缓存选项，删除的内容可能需要重新下载。可选的永久删除使用单独的清理复选框，在所选限制范围内重新检查保留的候选项，并记录每个结果。删除会绕过回收站。目标、天数和文件数限制也可以通过 cleanup CLI 命令进行配置。

### 配置文件

使用所选的天数阈值、确切的 ProfileList 注册以及可选的服务和计划任务账户依赖项来查看 Windows 配置文件，然后返回一个有范围限制的查看结论。已加载的配置文件、系统配置文件和当前账户的配置文件不在查看范围内。候选项仅供查看。不会更改任何配置文件、文件夹、注册表项、账户、服务、任务、凭据、策略或文件，也不会选择任何删除操作。应用程序依赖项和备份的可恢复性仍未验证。

### 计划任务

清点可见的计划任务、其状态和报告的主体。不会启动、注册或更改任何任务。不会验证操作、触发器和执行是否成功。

### Windows 精简

针对正在运行的账户或所有配置文件，查看明确的 Windows 清理区域，例如 Recall 和 AI、遥测、搜索建议、消费者内容、任务栏和开始菜单、通知、Edge、电源、休眠、Office 语言以及预装软件。查看是只读的。当高性能电源、睡眠和显示器计时器以及休眠所在的区域是唯一的选择时，可以在有新证据并经过明确确认后分别更改。
