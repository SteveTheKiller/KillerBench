# 设备

设备涵盖打印机、音频、相机、蓝牙、输入设备以及所连接硬件依赖的 Windows 服务。

操作指南：[解决打印问题](fix-printing.html) 和 [调查崩溃和蓝屏](investigate-crashes.html)。

## 本分区的工具

打印、音频、相机、蓝牙、输入以及所连接硬件背后的服务。

### 打印

检查 Print Spooler、本地队列暂停、可见的打印作业、脱机设置和驱动程序报告的状况，然后清点队列、驱动程序、端口、Standard TCP/IP 终结点、打印处理器和打印监视器的注册。仅当存在一个确切的当前队列标识时，才关联最近的 PrintService 问题。已分配的 Standard TCP/IP 终结点会接受一次有范围限制的连接尝试，不包含应用程序数据、SNMP 或打印作业。自动修复可以启动已启用的后台打印程序，仅恢复具有新的等待作业证据的确切已暂停队列，并清除脱机模式。没有作业等待的有意暂停仅供查看。远程连接、SNMP 团体字符串、扩展注册和作业内容保持不变。状况代码或连接成功不能确定打印机标识、耗材、机械、队列接受、渲染成功或实际打印。

### 音频

检查默认多媒体输入和输出设备的标识及共享格式、音频设备和驱动程序状态、Audio Endpoint Builder 和 Windows Audio。自动修复会启动已停止的已启用服务并验证运行状态。启动设置、驱动程序、所选设备、独占模式和音量级别保持不变。声音播放、录音和应用程序音频路由仍未测试。

### 相机支持

检查相机和图像设备错误、硬件 ID、已安装的驱动程序证据以及 Windows Camera Frame Server 的可用性。可选恢复会在检查依赖项后，仅启动已启用且已停止的服务。已在请求相机访问的应用程序可能会在现有权限下恢复。相机隐私设置、权限、设备配置、策略、驱动程序和启动类型保持不变。不进行重置、权限更改或驱动程序安装。验证仅涵盖报告的设备配置和服务运行状态，不包括图像捕获、隐私访问或物理运行。

### 蓝牙支持

检查蓝牙设备错误、硬件 ID、已安装的驱动程序证据以及蓝牙支持服务的可用性。可选恢复会在检查依赖项后，仅启动已启用且已停止的服务；已配对的设备可能会重新连接。配对、无线电设置、设备配置、策略和启动类型保持不变。不进行重置、设备删除或驱动程序安装。验证仅涵盖报告的设备配置和服务运行状态，不包括发现、配对、音频或数据传输。

### 智能卡支持

检查智能卡读卡器错误、硬件 ID、已安装的驱动程序证据以及智能卡服务的可用性。可选恢复会在检查依赖项后，仅启动已启用且已停止的服务。应用程序可能会在现有策略下恢复检测插入的卡。证书、PIN、凭据、读卡器和卡配置、策略、驱动程序和启动类型保持不变。不进行初始化、注册、PIN 操作、读卡器重置或驱动程序安装。验证仅涵盖报告的读卡器配置和服务运行状态，不包括卡检测、身份验证或应用程序访问。

### 生物识别支持

检查生物识别设备错误、硬件 ID、已安装的驱动程序证据以及 Windows 生物识别服务的可用性。可选恢复会在检查依赖项后，仅启动已启用且已停止的服务。现有的 Windows Hello 和应用程序请求可能会按照当前策略恢复。生物识别模板、Windows Hello 数据、凭据、设备配置、权限、策略、驱动程序和启动类型保持不变。不进行注册、模板删除、传感器重置、权限更改或驱动程序安装。验证仅涵盖报告的传感器配置和服务运行状态，不包括捕获、匹配、登录或应用程序访问。

### 人体学接口设备服务

检查人体学接口设备服务的可用性。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有的快捷按钮、媒体控件和其他 HID 功能可能会恢复。设备、驱动程序、按钮映射、辅助功能设置、输入设置、策略、服务权限和启动类型保持不变。KillerBench 不会选择任何设备、驱动程序、映射或输入设置操作。验证仅涵盖服务的稳定状态，不包括按钮、控件或应用程序的行为。

### 便携设备枚举器服务

检查便携设备枚举器服务的可用性。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有应用程序可能会恢复检测和访问已连接的便携设备。设备、驱动程序、文件、库、同步设置、权限、策略、服务权限和启动类型保持不变。KillerBench 不会选择任何设备、文件、库、同步或传输操作。验证仅涵盖服务的稳定状态，不包括枚举、访问、同步或传输。

### Windows 图像采集 (WIA)

检查 Windows 图像采集服务的可用性。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有的扫描仪和静态图像采集请求可能会在当前应用程序权限下恢复。设备、驱动程序、图像数据、应用程序权限、隐私设置、传输设置、策略、服务权限和启动类型保持不变。KillerBench 不会选择任何设备、驱动程序、图像、权限、传输或采集操作。验证仅涵盖服务的稳定状态，不包括扫描仪、相机、传输或应用程序的运行情况。

### Shell 硬件检测

检查有范围限制的存储控制器、磁盘和便携设备的即插即用证据以及已安装的驱动程序引用，然后检查 Shell 硬件检测服务的可用性。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有的自动播放和硬件接入通知可能会按照当前策略恢复。设备观察和保留的历史记录不能授权恢复。设备、驱动程序、卷、装载点、自动播放设置、处理程序、策略、服务权限和启动类型保持不变。不会请求任何设备或设置操作。验证仅涵盖服务的稳定状态，不包括通知传递、媒体就绪状态、卷访问或设备的物理运行。

### 设备安装服务

检查设备安装服务的可用性。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。Windows 请求的现有设备安装工作可能会按照当前策略恢复。设备、驱动程序、包、配置、绑定、类设置、策略、服务权限和启动类型保持不变。KillerBench 不会选择或安装任何内容。验证仅涵盖服务的稳定状态，不包括设备安装或运行情况。

### 设备关联服务

检查最近的设备设置和即插即用历史记录，然后检查设备关联服务的可用性。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。Windows 请求的现有设备关联工作可能会恢复。已配对和已关联的设备、驱动程序、凭据、元数据、权限、策略、服务权限和启动类型保持不变。KillerBench 不会选择任何设备、配对、删除、重置或驱动程序操作。验证仅涵盖服务的稳定状态，不包括发现、配对、关联或设备运行情况。

### 显示增强服务

检查图形适配器和显示器的证据，然后检查显示增强服务的可用性。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有的亮度、颜色和增强请求可能会恢复。显示配置、亮度、颜色配置文件、HDR 设置、设备、驱动程序、电源设置、策略、服务权限和启动类型保持不变。不会更改任何显示设置。验证仅涵盖服务的稳定状态，不包括增强行为、图像质量或显示器的物理运行。

### 文本输入管理服务

检查键盘、鼠标和 HID 设备的证据，然后检查文本输入管理服务的可用性。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有的触摸键盘、手写、表情符号和高级文本输入请求可能会恢复。词典、手写数据、语言和键盘设置、辅助功能和隐私设置、设备、驱动程序、策略、服务权限和启动类型保持不变。不会收集任何输入的文本、按键或手写内容。验证仅涵盖服务的稳定状态，不包括文本输入、识别或设备运行情况。

### Windows 字体缓存服务
