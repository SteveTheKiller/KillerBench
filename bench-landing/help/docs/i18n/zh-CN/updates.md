# 更新

更新涵盖 Windows 更新、其背后的服务以及组件存储。你可以查看已安装的内容、待处理的内容以及更新失败的原因，并可以在选择安装任何更新之前查看可用更新。

操作指南：[修复 Windows 更新](fix-windows-update.html) 和 [修复系统文件](repair-system-files.html)。

## 本分区的工具

监视维护活动、查看可用更新并修复 Windows 更新链。

### 维护活动监视器

通过一次或多次快照，有范围限制地观察 Windows 更新和 Setup 的维护活动。选项控制刷新间隔，以及是否包括更新事件、更新历史记录、Windows 更新的确切计划任务、服务的确切状态、重启指示、当前账户的后台传输、传递优化活动以及有隐私范围限制的 Windows Installer 活动。进程 ID、命令行、用户和路径会被排除。活动不能证明进度、完成、停滞或故障。不会请求任何更新、安装、传输、任务、服务、进程、策略、重启或修复操作。

### 可用更新

使用已配置的来源、Windows 更新或已注册的 Microsoft Update 服务查找所选的软件和驱动程序更新。查找前会检查来源的就绪状态。不进行安装、许可证接受、来源注册或策略更改。此功能与维护修复分开。

### Windows 更新

有范围限制地清点 Windows 维护包、可选功能和功能的状态，检查重启指示、可用空间和更新服务，在不启动传递优化的情况下对其进行观察，然后扫描组件存储和受保护的系统文件。包、功能或功能处于待处理状态时需要审阅，但不会授权组件操作。自动修复可以启动已启用的 Windows 更新、BITS、加密服务、Windows 模块安装程序和更新协调器服务。启动更新协调器可能会按照当前策略恢复现有的计划更新活动。包、可选功能、功能、传递优化缓存、对等节点、带宽、策略、来源注册、计划和启动设置保持不变。DISM 或 SFC 需要损坏的实时证据。此工作流程不会选择或批准任何更新。

### Windows 更新服务

检查 Windows 更新服务的确切状态、其注册的服务 DLL、有范围限制的当前更新活动以及确切的服务故障历史记录。DLL 观察、更新活动和历史故障不能授权启动服务或执行更新操作。可选恢复会在重新检查依赖项和可执行文件注册后，仅启动已停止的自动启动服务。已停止的按需启动服务仅作为信息显示。现有的更新活动可能会按照当前策略恢复。更新策略、来源注册、计划、重启设置、包、BITS 作业、服务权限和启动类型保持不变。KillerBench 不会选择、批准或安装任何更新。验证仅涵盖服务的稳定状态，不包括来源可访问性、适用性、下载、安装、完成或重启就绪状态。

### 传递优化

检查传递优化服务的确切状态。已停止的按需启动服务仅作为信息显示。只有确切的 Paused 状态才会提供恢复。可选恢复会重复状态检查，发送一次有范围限制的继续请求，并需要两次一致的 Running 观察结果。启动类型、缓存内容、对等节点、带宽、更新来源和受管理的策略保持不变。传输活动、缓存运行状况、更新进度和完成情况仍未验证。

### BITS 服务

检查后台智能传输服务的确切状态、当前账户的传输作业以及有范围限制的确切服务故障历史记录。历史故障和传输快照不能授权启动服务。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有应用程序可能会恢复排队的后台传输。作业、优先级、所有者、目标、代理设置、策略和启动类型保持不变。验证仅涵盖服务的稳定状态，不包括传输进度、应用程序所有权或完成情况。

### 后台传输 (BITS)

读取所选账户范围内的 BITS 传输作业，并查看确切的作业标识。队列名称不能确定应用程序的所有权。不会恢复、完成、取消、删除或重新分配任何传输。

### 加密服务

检查加密服务的确切状态、其注册的服务 DLL 以及有范围限制的确切服务故障历史记录。历史故障和 DLL 观察不能授权启动服务或替换组件。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有的目录、证书和更新操作可能会恢复。证书、密钥、目录、信任设置、策略和启动类型保持不变。验证仅涵盖服务的稳定状态，不包括证书、签名、目录或信任的验证。

### Windows 模块安装程序

检查 Windows 模块安装程序的确切状态、有范围限制的维护包转换以及确切的服务故障历史记录。历史故障和包状态不能授权启动服务或执行包操作。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有的维护活动可能会恢复。包、组件存储内容、来源、策略和启动类型保持不变。验证仅涵盖服务的稳定状态，不包括组件存储运行状况、包的适用性、维护完成情况或重启就绪状态。

### Windows 更新医生服务

检查 Windows 更新医生服务的确切状态、其注册的服务 DLL、有范围限制的当前更新活动以及确切的服务故障历史记录。DLL 观察、更新活动和历史故障不能授权启动服务或执行组件操作。已停止的按需启动服务可能是正常的。仅当选择此工具时，可选恢复才可以在重新检查依赖项后启动已停止的已启用服务。Windows 修正可能会按照当前策略恢复，并可能修复更新组件或触发更新活动。更新策略、来源注册、计划、包、BITS 作业、重启设置、服务权限和启动类型保持不变。KillerBench 不会选择任何更新，也不会更改任何更新设置。验证仅涵盖服务的稳定状态，不包括修正、组件运行状况、适用性、下载、安装或重启就绪状态。

### 更新协调器服务

检查更新协调器服务的确切状态、确切的内置 Windows 更新任务、有范围限制的当前活动以及确切的服务故障历史记录。任务结果、更新活动和历史故障不能授权启动服务或执行更新操作。可选恢复会在重新检查依赖项和可执行文件注册后，仅启动已停止的自动启动服务。已停止的按需启动服务仅作为信息显示。现有的计划更新活动可能会按照当前策略恢复，并可能下载或安装已批准的更新。更新策略、来源注册、计划、重启设置、包、BITS 作业、服务权限和启动类型保持不变。KillerBench 不会选择或批准任何更新。验证仅涵盖服务的稳定状态，不包括适用性、下载、安装、完成或重启就绪状态。

### 组件存储清理

分析 Windows 是否建议清理组件存储。可选维护会立即删除被取代的组件，然后再次分析。不使用 ResetBase，也不手动删除 WinSxS。不会自动撤消；不会测量回收的磁盘空间。
