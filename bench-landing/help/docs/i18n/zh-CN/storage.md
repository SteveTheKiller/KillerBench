# 存储

检查磁盘、卷、存储空间和驱动器维护服务。诊断不会选择磁盘操作；任何受支持的、会更改计算机的操作都需要其确切的目标、前提条件和确认。

操作指南：[检查和修复驱动器](check-a-drive.html) 和 [释放磁盘空间](free-disk-space.html)。

## 本分区的工具

### 存储

在有范围限制的情况下映射磁盘、分区和带驱动器号的卷的标识，评估每个带驱动器号的卷是否低于 10% 可用空间，检查 VSS 卷影存储分配和每个卷的配额默认值，汇总 Storage 模块作业的当前进度，检查所选 NTFS 卷及其联机自我修复状态，并检查此电脑上的磁盘和控制器设备。容量阈值、配额设置和作业状态是需要审阅的证据，不会选择清理、调整大小、更改配额或控制作业。驱动器号映射反映的是某一时刻的情况，不涵盖所有装载路径。设备结论不会映射到所选卷。默认选择 Windows 卷。不会更改任何文件、快照、作业或驱动程序，不会更改任何设置，不会卸载任何卷，也不会安排重启。

### 存储空间

清点非原始的存储空间池和虚拟磁盘，包括运行状况、操作状态、容量、分配和复原能力，然后返回一个有范围限制的运行结论。在响应此只读查询时，Windows 可能会按需启动其存储空间管理提供程序。池、虚拟磁盘、物理磁盘、卷、复原能力、分配、维护设置、策略和启动类型保持不变。不会请求任何池、磁盘、卷、分配、附加、修复、优化或设置操作。提供程序的结果不能验证池的可访问性、冗余、数据完整性、备份的可恢复性或应用程序 I/O。

### 存储服务

在有范围限制的情况下查看 Storage 模块的当前作业、确切的服务故障历史记录以及存储服务的当前就绪状态。不完整的证据优先。作业状态和历史故障不能授权服务恢复或存储更改。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。现有的存储通知和由策略管理的存储活动可能会恢复。卷、分区、文件系统、装载点、设备、驱动程序、存储感知设置、维护策略、服务权限和启动类型保持不变。KillerBench 不会选择任何作业、卷、分区、装载点、文件、设备、驱动程序或存储设置操作。验证仅涵盖服务的稳定状态，不包括作业结果或设备、卷、存储策略的运行情况。

### 优化驱动器服务

检查优化驱动器服务的可用性。可选恢复会在重新检查依赖项后，仅启动已启用且已停止的确切服务。Windows 已计划的现有优化活动可能会按照当前维护策略恢复。卷、文件系统、数据、优化计划、维护策略、服务权限和启动类型保持不变。KillerBench 不会选择卷，也不会对任何驱动器进行分析、修整、碎片整理、优化或计划。验证仅涵盖服务的稳定状态，不包括分析、优化或设备运行状况。
