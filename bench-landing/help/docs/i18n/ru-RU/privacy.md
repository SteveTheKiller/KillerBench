# Конфиденциальность

Конфиденциальность считывает параметры конфиденциальности этого компьютера и учётной записи, под которой запущен KillerBench, а затем позволяет изменить выбранные вами. Раздел выходит за рамки приложения «Параметры Windows» и охватывает разрешения приложений, облачный поиск и выделение в поиске.

Пошаговые руководства: [Повышение конфиденциальности Windows](make-windows-private.html).

## Просмотр и изменение параметров

Выберите области конфиденциальности для проверки и нажмите **Запустить диагностику**. Изначально ни одна область не отмечена, а проверка выполняется только для чтения.

Чтобы изменить параметр, используйте элемент **Настройка конфиденциальности**. KillerBench проверяет, не владеет ли параметром уже политика или система управления устройствами, записывает текущее значение, вносит единственное запрошенное изменение и считывает его для подтверждения. Параметры, которыми владеет политика, остаются без изменений.

Параметры включают выбор диагностических данных и рекламы, журнал буфера обмена, 17 параметров разрешений приложений, например камеры, микрофона и расположения, облачный поиск содержимого для личных и рабочих учётных записей и выделение в поиске.

## Инструменты этого раздела

Просматривайте и изменяйте разрешения приложений, рекомендации, параметры поиска и рекламы.

### Конфиденциальность

Считывает выбранные параметры конфиденциальности в реестре для этого компьютера и учётной записи, под которой запущен KillerBench. Отдельные явные элементы управления могут изменить журнал буфера обмена или поддерживаемый параметр учётной записи после свежих проверок политики, надёжной подготовки и точной проверки. Остальные варианты конфиденциальности остаются только для чтения. Снимки реестра не доказывают фактические разрешения или принадлежность политике.
