# Командная строка

`killerbench-cli` запускает тот же Engine, что и настольное приложение, из PowerShell или удалённой консоли. Каждая команда, которая может изменить компьютер, по умолчанию выполняет предпросмотр и перед действием требует явного флага, например `--execute`. Команды выводят доказательства JSON в стандартный вывод, а ход выполнения в стандартный поток ошибок.

Пошаговые руководства: [Запуск KillerBench из скриптов](use-the-cli.html).

Код завершения 0 означает, что предпросмотр или подтверждённый результат выполнены успешно, 1 означает ошибку запуска, ввода или журнала, 2 означает, что аргументы не распознаны, 3 означает «заблокировано», «ошибка» или «не подтверждено», 4 означает, что процедуре нужна перезагрузка перед проверкой, а 130 означает, что вы её остановили.

Запустите `killerbench-cli` без аргументов, чтобы вывести этот список на своём компьютере.

## Обновления и обслуживание

- `bits-job-review JOB_GUID [--all-users] [--observe]`: Точный обзор передачи или наблюдение по двум снимкам; без повторов.
- `bits-jobs [--all-users]`: Состояния, владельцы и количество байтов заданий BITS; без изменения передач.
- `bits-retry JOB_GUID [--execute]`: По умолчанию предпросмотр; явный повтор точного задания без утверждения о завершении приложения.
- `bits-retry-recover JOB_GUID`: Два снимка только для чтения; архивирует устойчивые результаты без нового повтора.
- `component-repair-source`: Управляемая политика источника исправлений DISM и конфликты; без изменений.
- `delivery-optimization`: Состояние службы оптимизации доставки только для чтения; доказательства JSON.
- `delivery-optimization-activity`: Ограниченные по конфиденциальности текущие количества заданий и суммы байтов; без идентификаторов передач и без изменений.
- `delivery-optimization-policy`: Классические параметры и Policy CSP только для чтения; конфиденциальные значения и идентификаторы поставщиков исключены.
- `feature-service-events`: Чтение точной истории сбоев служб времени, Search, WMI, журнала событий и звука.
- `feature-update-policy`: Политика целевого выпуска, отсрочки, приостановки и защитных мер только для чтения; доказательства JSON.
- `pending-file-operations`: Ограниченная по конфиденциальности сводка ожидающих файловых операций только для чтения; доказательства JSON.
- `restart-check`: Источники ожидающей перезагрузки только для чтения; доказательства JSON.
- `servicing-logs`: Ограниченный анализ новейших журналов CBS, текстовых и сжатых архивов CBS, журналов DISM и программы установки Windows; без исправления.
- `servicing-monitor [--refresh 1..60] [--samples 1..120] [--skip-events] [--skip-history] [--skip-services] [--skip-restart] [--skip-setup] [--skip-compatibility] [--skip-readiness] [--skip-transfers] [--skip-delivery-optimization] [--skip-installer] [--skip-scheduled-task]`: Снимки активности обслуживания только для чтения.
- `servicing-service-events`: Точная история сбоев цепочки обслуживания Windows Update только для чтения.
- `servicing-service-states`: Текущее состояние шести служб цепочки обслуживания Windows Update только для чтения.
- `setup-code DECIMAL_OR_0xHEX`: Документированный справочник кодов результата программы установки Windows; без проверки компьютера и исправления.
- `update-applicability`: Доказательства выпуска, сборки и архитектуры Windows только для чтения.
- `update-cache`: Ограниченные суммы кэша SoftwareDistribution только для чтения; без имён файлов.
- `update-code DECIMAL_OR_0xHEX`: Документированный справочник кодов результата Windows Update; без проверки компьютера и исправления.
- `update-context`: Доказательства текущего повышения прав и сеанса рабочего стола только для чтения; без идентификаторов учётных записей.
- `update-engine-files`: Доказательства наличия, версии и подписи нативного модуля Windows Update только для чтения.
- `update-events`: Журнал клиента Windows Update за последние семь дней только для чтения; JSON с необработанными доказательствами.
- `update-followup DECIMAL_OR_0xHEX`: Свежая диагностика только для чтения, выбранная по документированному коду результата Windows Update.
- `update-history`: 100 новейших результатов операций Windows Update только для чтения; доказательства JSON.
- `update-plan --select GUID:REVISION [--drivers] [--no-software] [--allow-restart-required] [--json] [--execute]`: Повторяйте `--select`; по умолчанию предпросмотр.
- `update-policy`: Управляемая политика Windows Update только для чтения; доказательства JSON.
- `update-policy-surfaces`: Доказательства области конфигурации классических параметров и Policy CSP только для чтения; значения и идентификаторы поставщиков исключены.
- `update-recover`: Проверяет ожидающее обновление; никогда не устанавливает и не повторяет его.
- `update-restart-policy`: Сроки соответствия, льготные периоды, подавление перезагрузки и поведение уведомлений только для чтения.
- `update-search [--drivers] [--no-software] [--filter TITLE] [--downloaded-only] [--classification GUID] [--product GUID]`: Обнаружение и совпадения в JSON; без установки.
- `update-service-events`: Точная история сбоев службы Windows Update только для чтения.
- `update-service-files`: Точные доказательства регистрации и подписи библиотеки DLL службы Windows Update только для чтения.
- `update-services`: Регистрации служб Windows Update только для чтения; доказательства JSON.
- `update-store-reset [--source Configured|WindowsUpdate|MicrosoftUpdate] [--drivers] [--no-software] [--execute]`: Требует свежего поиска; по умолчанию предпросмотр; сохраняет старое хранилище.
- `update-store-reset-recover`: Согласует подготовленный сброс хранилища, не повторяя его.
- `windows-capabilities`: Состояния возможностей работающей Windows только для чтения; результат JSON.
- `windows-update-task`: Точное состояние и история запусков задачи Scheduled Start только для чтения; без выполнения задачи и операций обновления.

## BitLocker и TPM

- `bitlocker-auto-unlock DRIVE: [--execute]`: По умолчанию предпросмотр; включает автоматическую разблокировку зашифрованного тома с данными.
- `bitlocker-auto-unlock-recover`: Проверяет прерванный запрос автоматической разблокировки, не повторяя его.
- `bitlocker-backup DRIVE: PROTECTOR_GUID FILE_PATH [--execute]`: По умолчанию предпросмотр; только новый файл резервной копии для восстановления.
- `bitlocker-backup-recover DRIVE: PROTECTOR_GUID FILE_PATH`: Проверяет прерванное резервное копирование без повторной записи.
- `bitlocker-decrypt DRIVE: [--execute --confirm-unprotected]`: По умолчанию предпросмотр; запускает расшифровку, например перед повторным шифрованием требуемым методом.
- `bitlocker-decrypt-recover`: Проверяет прерванный запрос расшифровки, не повторяя его.
- `bitlocker-encrypt DRIVE: RECOVERY_PROTECTOR_GUID NEW_BACKUP_FILE [--encryption XtsAes128] [--used-space-only] [--execute]`: По умолчанию предпросмотр; требует существующих предохранителей TPM и восстановления.
- `bitlocker-encrypt-recover`: Проверяет ожидающее состояние преобразования, не повторяя запрос.
- `bitlocker-escrow DRIVE: RECOVERY_PROTECTOR_GUID ad|entra [--execute]`: По умолчанию предпросмотр; сохраняет существующий пароль восстановления в Active Directory или Microsoft Entra ID.
- `bitlocker-plan --volume C: --operation Encrypt --encryption XtsAes256 --backup EntraId`: Только предпросмотр параметров.
- `bitlocker-protector-add DRIVE: tpm|recovery [--execute]`: По умолчанию предпросмотр; добавляет один предохранитель TPM или с паролем восстановления; пароль никогда не выводится.
- `bitlocker-protector-recover`: Проверяет прерванный запрос предохранителя, не повторяя его.
- `bitlocker-protectors DRIVE:`: Только идентификаторы и типы предохранителей; без паролей восстановления.
- `bitlocker-resume DRIVE: [--execute]`: По умолчанию предпросмотр; только точный полностью зашифрованный приостановленный том.
- `bitlocker-resume-recover`: Проверяет ожидающее состояние защиты, не повторяя запрос.

## Безопасность и конфиденциальность

- `certificate-chains`: Доверие цепочки личных сертификатов только по локальному кэшу, только для чтения; без проверки отзыва и загрузок.
- `defender-overview [--report]`: Защита, время проверок и сводный обзор угроз только для чтения; без действий.
- `defender-protection [--report]`: Настройки защиты и распознанные области политики только для чтения; конфиденциальные сведения исключены; без изменений.
- `defender-scan Quick|Full [--execute] [--report]`: По умолчанию предпросмотр; одна явная защищённая проверка Microsoft Defender.
- `defender-scan-history [--report]`: Время быстрой и полной проверки и признак просрочки только для чтения; конфиденциальные сведения исключены; без проверки.
- `defender-scan-recover [--report]`: Согласование только для чтения без запуска новой проверки.
- `defender-threats [--report]`: Сводная история угроз, текущие флаги активности и идентификаторы серьёзности; конфиденциальные сведения исключены; без действий.
- `firewall-enable --profile Domain|Private|Public [--profile ...] [--execute]`: По умолчанию предпросмотр; только неуправляемые локальные профили.
- `firewall-enable-recover`: Проверяет ожидающее изменение, не повторяя его.
- `firewall-events`: Чтение ограниченной рабочей истории предупреждений, ошибок и критических событий брандмауэра Windows.
- `firewall-logging`: Чтение конфигурации журналирования трафика профилей домена, частного и общего без открытия журналов.
- `firewall-rules`: Чтение ограниченных по конфиденциальности количеств действующих правил и источников политики.
- `firewall-service-events`: Чтение точной истории сбоев BFE и брандмауэра Защитника Windows в диспетчере управления службами.
- `privacy-clipboard-history on|off [--execute]`: По умолчанию предпросмотр; точное значение текущего пользователя с сохранением политики.
- `privacy-clipboard-history-recover`: Повторно проверяет прерванное изменение, не повторяя его.
- `privacy-clipboard-history-undo VERIFIED_JOURNAL [--execute]`: Защищённое восстановление прежнего значения.
- `privacy-plan --select Camera --select ClipboardSync`: Только обзор выбора; параметры не изменяются.
- `privacy-setting KEY on|off [--execute]`: По умолчанию предпросмотр; изменение для текущего пользователя с сохранением политики; для недопустимых ключей выводятся поддерживаемые варианты.
- `privacy-setting-recover KEY`: Повторно проверяет прерванное изменение, не повторяя его.
- `privacy-setting-undo KEY VERIFIED_JOURNAL [--execute]`: Защищённое восстановление точного значения.
- `security-check`: TPM, безопасная загрузка, защита виртуализации и политика UAC только для чтения; доказательства JSON.

## Службы

- `service-binaries`: Наличие локальных двоичных файлов служб и состояние Authenticode только для чтения; пути исключены, нелокальные пути не опрашиваются.
- `service-check NAME [NAME ...] | service-check --all`: Состояния поддерживаемых служб и доказательства зависимостей только для чтения.
- `service-dependencies`: Проверка целостности прямых зависимостей только для чтения; без изменения служб.
- `service-dlls`: Наличие зарегистрированных библиотек DLL служб и состояние Authenticode только для чтения; пути исключены, нелокальные пути не опрашиваются.
- `service-events`: История сбоев служб только для чтения; JSON с необработанными доказательствами.
- `time-events`: Недавняя история событий службы времени Windows только для чтения с доказательствами JSON.
- `service-logons`: Проверка классов учётных записей служб и взаимодействия с рабочим столом только для чтения; идентификаторы учётных записей исключены.
- `service-path-quoting`: Проверка кавычек в путях к исполняемым файлам служб только для чтения; полные пути и аргументы исключены.
- `service-recovery-policy`: Сводка действий восстановления установленных служб только для чтения; команды и сообщения о перезагрузке исключены.
- `service-startup-config`: Проверка согласованности режимов запуска только для чтения; без изменения служб.
- `service-transitions`: Повторное наблюдение за ожидающими состояниями служб только для чтения; без действий со службами.
- `service-triggers`: Сводка триггеров установленных служб только для чтения; данные триггеров исключены; без изменений.

- `disk-cleanup-task`: Точное состояние и история запусков задачи только для чтения; без выполнения задачи и очистки.

- `disk-diagnostic-tasks`: Точная история задач сборщика и сопоставителя только для чтения; без действий с задачами и дисками.

- `search-index-rebuild [--execute]`: По умолчанию предпросмотр; сохраняет прежний индекс и проверяет свежее состояние.
- `search-index-rebuild-recover`: Согласование только для чтения без повтора команд исправления.
- `storage-check DRIVE_LETTER`: Фиксированная проверка NTFS только для чтения; результаты JSON и ход выполнения в реальном времени.
- `storage-events`: История хранилища только для чтения; JSON с необработанными доказательствами.
- `storage-jobs`: Сводное состояние и ход заданий модуля Storage только для чтения; JSON; без изменений.
- `storage-reliability`: Счётчики температуры, износа и ввода-вывода только для чтения; JSON; без исправления.
- `storage-repair DRIVE: SpotFix|OfflineScanAndFix [--allow-dismount] [--backup-confirmed] [--execute]`: По умолчанию предпросмотр; для выполнения требуется подтверждение резервной копии; системные тома планируются на перезагрузку.
- `storage-repair-plan DRIVE: SpotFix|OfflineScanAndFix [--allow-dismount]`: Только предпросмотр; без исправления и планирования.
- `storage-repair-recover`: Проверяет завершённое или запланированное исправление файловой системы, не повторяя его.
- `storage-repair-review DRIVE: SpotFix|OfflineScanAndFix [--allow-dismount]`: Собирает и привязывает текущие доказательства; без исправления и планирования.
- `storage-sense-policy`: Распознанная политика очистки компьютера только для чтения; пользовательские параметры и идентификаторы файлов исключены.
- `storage-sense-task`: Точное состояние и история запусков задачи только для чтения; без выполнения задачи и очистки.

- `common-check [--scope NAME ...]`: По умолчанию все диагностические области; при указании только выбранные; JSON только для чтения.
- `delete-notifications`: Конфигурация уведомлений об удалении NTFS и ReFS только для чтения; JSON; без оптимизации и изменения параметров.
- `diagnostic-scopes [--all]`: Перечисляет 11 рекомендуемых групп результатов или все 49 областей только для чтения; без сбора.
- `full-scan --scope NAME [--scope NAME ...] [--report OUTPUT.html|OUTPUT.txt] [--json]`: Журнал целевой диагностики; без исправлений.
- `full-scan [--recipes ID[,ID]] [--auto-repair] [--report OUTPUT.html|OUTPUT.txt] [--json]`: Все диагностические области; без исправления, если явно не указан `--auto-repair`.
- `gateway-check`: Ограниченные проверки ICMP точно настроенных следующих переходов по умолчанию; без сканирования адресов.
- `infrastructure-service-events`: Читает один ограниченный точный снимок сбоев служб подключения, удалённого управления, уведомлений и основных служб.
- `investigate-batch FILE [FILE ...]`: До 12 файлов; JSON Lines; код 3 для неудачного или частичного импорта.
- `licensing-check`: Состояние активации Windows без ключей продукта только для чтения; доказательства JSON.
- `mac-vendor PACK_PATH MAC_ADDRESS`: Локальный поиск в пакете по самому длинному префиксу; без сетевого запроса.
- `ncsi-policy`: Политика классификации подключения Windows только для чтения; адреса проб исключены.
- `neighbor-cache`: Ограниченные по конфиденциальности доказательства доступности соседей только для чтения; результат JSON.
- `ntfs-self-healing DRIVE:`: Конфигурация оперативного исправления NTFS выбранного тома только для чтения; без исправления и изменения параметров.
- `pagefile-check`: Сводка управления, выделения и использования файла подкачки только для чтения; полные пути исключены.
- `pci-vendor PACK_PATH PCI_HARDWARE_ID`: Точный локальный поиск в пакете; без сетевого запроса и выбора драйвера.
- `physical-disks`: Текущее состояние работоспособности, работы, носителя, шины и использования только для чтения; JSON; без исправления.
- `platform-service-events`: Читает один ограниченный точный снимок сбоев служб приложений, удостоверений, профилей и поддержки устройств.
- `previous-windows [--execute --backup-confirmed]`: По умолчанию предпросмотр; с помощью DISM безвозвратно удаляет возможность отката Windows.
- `previous-windows-recover`: Согласование только для чтения без повтора удаления возможности отката.
- `provisioned-packages`: Пакеты, подготовленные для новых пользователей в локальной Windows; без удаления.
- `recipes [WORKFLOW]`: Перечисляет установленные определения или зависимости и пределы конкретной процедуры; без выполнения.
- `repair <dism|sfc> [--execute]`: По умолчанию предпросмотр.
- `reserved-storage`: Состояние зарезервированного хранилища работающей Windows только для чтения; доказательства JSON.
- `restore-point DESCRIPTION [ModifySettings|ApplicationInstall|DeviceDriverInstall] [--execute]`: По умолчанию предпросмотр; после свежих проверок создаёт одну точку.
- `restore-point-recover`: Проверяет ожидающий запрос, не создавая новую точку.
- `schedule-preview daily|weekly|monthly YYYY-MM-DD HH:mm TIME_ZONE_ID [Mon,Tue|1,15|last]`: Только предпросмотр.
- `shadow-copies`: Текущие состояния и атрибуты снимков VSS только для чтения; идентификаторы исключены; без изменения снимков.
- `shadow-storage`: Выделение и нагрузка разностной области VSS только для чтения; JSON; без изменения размера и действий со снимками.
- `uac-policy`: Включение UAC и политика запроса на повышение прав только для чтения; без данных учётных записей и учётных данных.
- `uefi-vendor PACK_PATH PNP|ACPI VENDOR_ID`: Точный локальный поиск в реестре UEFI; без сетевого запроса и выбора драйвера.
- `usb-vendor PACK_PATH USB_HARDWARE_ID`: Точный локальный поиск в пакете; без сетевого запроса и выбора драйвера.
- `vitals-check`: Снимки Windows, оборудования, учётной записи, ресурсов, батареи и физических дисков только для чтения; доказательства JSON.
- `win32-code DECIMAL_OR_0xHEX`: Автономный поиск сообщений установленной Windows.
- `workflows`: Перечисляет установленные ключи и названия процедур; без проверки и исправления.
