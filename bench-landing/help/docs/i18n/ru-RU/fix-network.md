# Устранение проблем с сетью и интернетом

Используйте этот порядок, когда на компьютере нет интернета, он не может связаться с сервером или разрешить имя либо постоянно теряет подключение. KillerBench по порядку проверяет адаптер, адрес, шлюз, DNS и брандмауэр и продлевает аренду или запускает службу только тогда, когда свежие доказательства подтверждают необходимость.

## Проверка подключения

1. Откройте **Сеть** и выберите **Сеть**.
2. Чтобы проверить что-то конкретное, заполните **Поиск имени хоста (необязательно)** или **TCP-адрес назначения (необязательно)** и **TCP-порт**. Оставьте поля пустыми, чтобы проверить только локальную конфигурацию. Данные приложений не отправляются.
3. Если сеть медленная, задайте **Тайм-аут на запрос или соединение (в секундах)**.
4. Оставьте **Автоматически исправлять подтверждённые проблемы** выключенным и нажмите **Запустить диагностику**.
5. Прочитайте отчёт. Он различает отсутствие адреса, отсутствующий или недоступный шлюз, проблемы конфигурации DNS, параметры прокси, несоответствие профилей брандмауэра и неудачный запрос или подключение и для каждого случая указывает следующий шаг.

Ответ шлюза не доказывает доступ в интернет, а неудачный запрос через настроенный сопоставитель не означает, что сайт не работает.

## Исправление найденного в отчёте

1. Снова запустите **Сеть** с включённым параметром **Автоматически исправлять подтверждённые проблемы**. Инструмент может запустить включённые службы DNS-клиент, DHCP-клиент, клиент SMB, Служба сведений о подключенных сетях, Служба списка сетей и Вспомогательная служба IP, а также продлить аренду для подключённых физических адаптеров DHCP без пригодного адреса IPv4.
2. Во время продления подключение ненадолго прервётся. Статические адреса и виртуальные адаптеры никогда не изменяются.
3. Для одного неверного имени в кэше используйте очистку кэша DNS для этого конкретного хоста вместо полной очистки.

Маршруты, записи Hosts, DNS-серверы, правила брандмауэра, поставщики Winsock и сетевые профили всегда сохраняются.

## Беспроводная сеть, проводной вход и прокси

- **Беспроводная сеть** проверяет адаптер и службу автонастройки WLAN и может запустить службу, если она остановлена.
- **Проводная проверка подлинности (802.1X)** делает то же самое для службы автонастройки проводной сети в сетях, где требуется вход на порту.
- **Автоматический прокси WinHTTP** показывает сохранённые параметры прокси для компьютера и текущей учётной записи. Во время диагностики KillerBench никогда не загружает URL файла PAC и не изменяет параметры прокси.

## Из командной строки

```powershell
killerbench-cli workflow network --host example.com --tcp example.com 443
killerbench-cli dns-check example.com --timeout-seconds 5
killerbench-cli tcp-check fileserver 445
killerbench-cli dhcp-renew
killerbench-cli dns-cache example.com --execute
```

См. [workflow](cli.html#cmd-workflow), [dns-check](cli.html#cmd-dns-check), [tcp-check](cli.html#cmd-tcp-check), [dhcp-renew](cli.html#cmd-dhcp-renew) и [dns-cache](cli.html#cmd-dns-cache).
