# Настройка нового компьютера

Используйте этот порядок при подготовке нового или только что сброшенного компьютера. KillerBench проверяет компьютер, приложения, которые вы планируете установить, и имя, которое вы хотите ему дать, а затем указывает на защищённые инструменты, которые вносят каждое изменение.

## Начните с исходного состояния

1. Запустите **Полная проверка системы** в разделе **Диагностика** и сохраните отчёт как запись исходного состояния компьютера.
2. Установите ожидающие обновления. Если какие-то не устанавливаются, см. [Исправление Windows Update](fix-windows-update.html).

## Проверка приложений и конфигурации

1. Откройте **Подготовка** и выберите **Подготовка**.
2. Выберите приложения и группы конфигурации, которые планируете настроить, и нажмите **Запустить диагностику**. Проверка сравнивает их с уже установленным. KillerBench не загружает и не запускает установщики.
3. Перед запуском установщика поставщика проверьте его из командной строки. KillerBench доверяет установщику, только если он имеет действительную подпись с точным названием организации этого поставщика.

## Имя компьютера

1. Выберите **Имя компьютера**, введите имя и нажмите **Запустить диагностику**, чтобы сверить его с текущими идентификационными данными и ролью в домене.
2. На компьютере в рабочей группе отметьте **Переименовать этот компьютер рабочей группы после новых проверок**, чтобы переименовать его. Для завершения нужна перезагрузка.

## Защита и порядок

- [Зашифруйте диск с помощью BitLocker](encrypt-with-bitlocker.html) и сохраните ключ восстановления.
- [Повысьте конфиденциальность Windows](make-windows-private.html) и изучите **Наведение порядка в Windows** в разделе **Обслуживание**.
- Когда всё будет готово, создайте точку восстановления с помощью **Подготовить одну точку восстановления**.

## Из командной строки

```powershell
killerbench-cli depot-verify-installer chrome C:\Installers\ChromeSetup.exe
killerbench-cli workflow computer-name --name FRONTDESK-01
killerbench-cli restore-point "Baseline after setup" --execute
```

См. [workflow](cli.html#cmd-workflow) и [restore-point](cli.html#cmd-restore-point).
