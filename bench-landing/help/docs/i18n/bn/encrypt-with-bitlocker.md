# BitLocker দিয়ে ড্রাইভ এনক্রিপ্ট করুন

BitLocker চালু করতে, পুনরুদ্ধার কী ব্যাকআপ করতে এবং ড্রাইভটি সুরক্ষিত কি না নিশ্চিত করতে এটি ব্যবহার করুন। এনক্রিপশন শুরু করার আগে KillerBench পুনরুদ্ধার পাসওয়ার্ড ব্যাকআপ করে যাচাই করে, এবং কখনো পুনরুদ্ধার পাসওয়ার্ড দেখায় না বা লগে রাখে না।

## শুরু করার আগে

- KillerBench প্রশাসক হিসেবে চালান।
- Windows ড্রাইভের জন্য একটি TPM সুরক্ষক ও একটি পুনরুদ্ধার পাসওয়ার্ড সুরক্ষক দরকার। একটি ডেটা ড্রাইভের জন্য কেবল পুনরুদ্ধার পাসওয়ার্ড দরকার।
- পুনরুদ্ধার কী-এর ব্যাকআপ কোথায় যাবে তা ঠিক করুন: আপনি যে ড্রাইভ এনক্রিপ্ট করছেন তার বাইরের একটি ফাইলে, এবং ঐচ্ছিকভাবে Active Directory বা Microsoft Entra ID-তে।

## ড্রাইভ পরীক্ষা করুন

1. **BitLocker** খুলে **ভলিউম**-এ ড্রাইভটি বেছে নিন।
2. কাজটি **পরীক্ষা**-তে রেখে **ডায়াগনসিস চালান** চাপুন। রিপোর্ট এনক্রিপশনের অবস্থা, সুরক্ষার অবস্থা ও সুরক্ষকের পরিচয় দেখায়।
3. TPM উপস্থিত কিন্তু প্রস্তুত না থাকলে প্রথমে **নিরাপত্তা** থেকে এটি প্রস্তুত করুন। KillerBench কখনো TPM মুছে ফেলে না।

## প্রয়োজনীয় সুরক্ষক যোগ করুন

1. **আরও BitLocker কাজ** খুলুন।
2. **একটি TPM সুরক্ষক যোগ করুন** বা **একটি পুনরুদ্ধার পাসওয়ার্ড যোগ করুন** বেছে নিয়ে **প্রিভিউ** চাপুন, **আমি 'কাজ চালান' চাপলে নির্বাচিত ড্রাইভে এই পরিবর্তন করুন** চিহ্নিত করুন, তারপর **কাজ চালান** চাপুন।
3. নতুন পুনরুদ্ধার পাসওয়ার্ড সঙ্গে সঙ্গে ব্যাকআপ করুন। KillerBench এটি দেখায় না।

## পুনরুদ্ধার কী ব্যাকআপ করে এনক্রিপ্ট করুন

1. **রিকভারি প্রোটেক্টরগুলো খুঁজুন** চেপে পুনরুদ্ধার পাসওয়ার্ড সুরক্ষকটি বেছে নিন।
2. আপনি যে ড্রাইভ এনক্রিপ্ট করছেন তার বাইরের একটি ব্যাকআপ ফাইলের পূর্ণ পাথ লিখুন।
3. **এনক্রিপ্ট** বেছে নিন, এনক্রিপশন পদ্ধতি বেছে নিন, এবং **আমি ডায়াগনসিস চালান নির্বাচন করলে নির্বাচিত পুনরুদ্ধার কী ব্যাকআপ করুন, তারপর এনক্রিপশন শুরু করুন** চিহ্নিত করুন।
4. **ডায়াগনসিস চালান** চাপুন। KillerBench ব্যাকআপ লেখে, তা যাচাই করে, তারপর একবার এনক্রিপশন শুরু করে।
5. এনক্রিপশন পটভূমিতে চলতে থাকে। ড্রাইভটি সম্পূর্ণ এনক্রিপ্ট হয়েছে এবং সুরক্ষা চালু আছে কি না নিশ্চিত করতে পরে **পরীক্ষা** চালান।

## Active Directory বা Entra ID-তে ব্যাকআপ করুন

**আরও BitLocker কাজ**-এ নির্বাচিত সুরক্ষকের জন্য ডিরেক্টরি ব্যাকআপ বেছে নিন। KillerBench জানায় যে Windows অনুরোধটি গ্রহণ করেছে, কিন্তু ডিরেক্টরির কপিটি পড়তে পারে না, তাই Active Directory বা Entra অ্যাডমিন সেন্টারে এটি নিশ্চিত করুন।

## ডেটা ড্রাইভ ও স্বয়ংক্রিয় আনলক

একটি ডেটা ড্রাইভ এনক্রিপ্ট হওয়ার পরে **স্বয়ংক্রিয় আনলক চালু করুন** Windows চালু হলে এটিকে আনলক করে। Windows ড্রাইভটি আগে থেকেই সুরক্ষা চালু অবস্থায় সম্পূর্ণ এনক্রিপ্ট থাকতে হবে।

## কমান্ড লাইন থেকে

```powershell
killerbench-cli bitlocker-protectors C:
killerbench-cli bitlocker-protector-add C: recovery --execute
killerbench-cli bitlocker-encrypt C: RECOVERY_PROTECTOR_GUID D:\Keys\C-recovery.txt --execute
killerbench-cli bitlocker-escrow C: RECOVERY_PROTECTOR_GUID entra --execute
```

[bitlocker-protectors](cli.html#cmd-bitlocker-protectors), [bitlocker-protector-add](cli.html#cmd-bitlocker-protector-add), [bitlocker-encrypt](cli.html#cmd-bitlocker-encrypt) ও [bitlocker-escrow](cli.html#cmd-bitlocker-escrow) দেখুন। প্রতিটির বাধাপ্রাপ্ত অনুরোধের জন্য একটি সংশ্লিষ্ট `-recover` কমান্ড আছে।
