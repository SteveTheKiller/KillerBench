# ডাউনলোড ও সেটআপ

KillerBench 0.1.0 এখনো প্রকাশিত হয়নি। এখনো কোনো সর্বজনীন KillerBench প্যাকেজ বা ডাউনলোড নেই। এই পৃষ্ঠা বর্তমান প্যাকেজের প্রয়োজনীয়তা বর্ণনা করে, যাতে আপনি কোনো অনানুষ্ঠানিক কপি ডাউনলোড না করেই প্রস্তুতি নিতে পারেন।

## Windows ও রানটাইম

- বর্তমান প্রকাশের লক্ষ্য **Windows x64**। Windows 11 x64 হলো বর্তমান নেটিভ যাচাইয়ের ভিত্তি। নেটিভ ARM64, x86 ও Windows Server বিতরণ দেওয়া হয় না।
- KillerBench দুইভাবে প্যাকেজ করা হয়। ইনস্টলারটি **ফ্রেমওয়ার্কের উপর নির্ভরশীল** এবং এর জন্য **.NET Desktop Runtime 10 for Windows x64** প্রয়োজন। সাধারণ .NET Runtime, ASP.NET Core Runtime ও .NET Framework WPF সরবরাহ করে না। পোর্টেবল সংস্করণ নিজস্ব রানটাইম বহন করে এবং আলাদা ইনস্টলের দরকার হয় না। কমান্ড লাইন টুল `killerbench-cli.exe`-এর জন্য .NET 10 Runtime for Windows x64 প্রয়োজন। SDK দরকার শুধু উন্নয়নের জন্য, সাধারণ ব্যবহারের জন্য নয়।
- [.NET 10 on Windows](https://learn.microsoft.com/en-us/dotnet/core/install/windows) সমর্থিত একটি Windows সংস্করণ ব্যবহার করুন। রানটাইম সমর্থিত হওয়া মানে এই দাবি নয় যে KillerBench-এর মেরামত প্রতিটি সমর্থিত সংস্করণ বা বিল্ডে যাচাই করা হয়েছে। Windows 10-এর কভারেজ এখনো বাকি এবং এর সমর্থিত সংস্করণগুলো Microsoft-এর বর্তমান লাইফসাইকেল প্রয়োজনীয়তা দ্বারা সীমিত।
- Desktop Runtime কেবল [Microsoft-এর .NET 10 ডাউনলোড পৃষ্ঠা](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) থেকে নিন এবং **.NET Desktop Runtime**, **Windows**, **x64** বেছে নিন। আপনার প্রতিষ্ঠানের সফটওয়্যার ইনস্টলের নিয়ম মেনে চলুন।

`dotnet` উপলব্ধ থাকলে, `dotnet --list-runtimes` x64 ইনস্টলেশনের জন্য `Microsoft.WindowsDesktop.App 10.0.x` তালিকাভুক্ত করা উচিত। শুধু অন্য আর্কিটেকচারের জন্য ইনস্টল করা রানটাইম x64 ইনস্টলার প্যাকেজের শর্ত পূরণ করে না।

## প্যাকেজ প্রকাশিত হলে

1. এই ওয়েবসাইট থেকে লিঙ্ক করা অফিসিয়াল ডাউনলোড ব্যবহার করুন। এখনো কোনো KillerBench ডাউনলোড লিঙ্ক সক্রিয় নেই।
2. সেই প্যাকেজের প্রয়োজনীয়তা, [GPLv3 লাইসেন্স](../license.txt), সংশ্লিষ্ট সোর্সের নির্দেশনা, অন্তর্ভুক্ত তৃতীয় পক্ষের বিজ্ঞপ্তি, এবং স্বাক্ষর ও চেকসামের তথ্য পড়ুন। শুধু ফাইলের নাম দিয়ে সত্যতা প্রমাণিত হয় না।
3. বর্তমান অ্যাকাউন্টের জন্য, অথবা অধিকার উন্নীত করার প্রম্পটের পরে সব ব্যবহারকারীর জন্য ইনস্টলার চালান। এটি একটি স্টার্ট মেনু শর্টকাট, একটি ঐচ্ছিক ডেস্কটপ শর্টকাট এবং প্রোগ্রাম যোগ বা অপসারণে একটি এন্ট্রি যোগ করে। পোর্টেবল সংস্করণ ইনস্টল ছাড়াই চলে।
4. আপনার সাধারণ অ্যাকাউন্টে KillerBench শুরু করুন এবং [আপনার প্রথম ডায়াগনসিস](first-run.html) অনুসরণ করুন। ডায়াগনস্টিক অ্যাক্সেসের ব্যর্থতা দৃশ্যমান থাকে; অধিকার উন্নীত করা একটি আলাদা, ইচ্ছাকৃত পছন্দ।

যাচাই না করা কপি চালাতে Windows নিরাপত্তা সতর্কতা এড়িয়ে যাবেন না। কম্পিউটার পরিবর্তন করে এমন কোনো কাজ বেছে নেওয়ার আগে একটি সাম্প্রতিক ব্যাকআপ রাখুন।

চালু হওয়ার সময় KillerBench একটি নতুন স্থিতিশীল রিলিজের জন্য GitHub পরীক্ষা করে এবং ইনস্টল করার আগে জিজ্ঞেস করে। ডাউনলোডটি প্রকাশিত SHA-256 চেকসামের সঙ্গে মিলতে হবে। সম্পর্কে অংশে **অ্যাপ চালু হলে আপডেট পরীক্ষা করুন** দিয়ে পরীক্ষাটি বন্ধ করুন।

## বর্তমান সীমাবদ্ধতা

বর্তমান বিল্ডে বারোটি বিভাগ, শুধু-পড়া ডায়াগনসিস, রিপোর্ট এবং আলাদাভাবে নির্বাচিত মেরামতের সুবিধা রয়েছে। নেটিভ মেরামতের যাচাই এখনো চলছে। কার্যকর UI, সফল বিল্ড বা পরীক্ষামূলক ডেটার ফলাফল আসল কম্পিউটারে মেরামতের আচরণ প্রমাণ করে না। [পরিবর্তন কীভাবে নিরাপদ থাকে](safety.html#development-status) দেখুন।

ল্যান্ডিং পৃষ্ঠার উদাহরণমূলক কনসোলটি কৃত্রিম আউটপুট। অ্যাপের চূড়ান্ত স্ক্রিনশট ও প্রথম সর্বজনীন প্যাকেজ এখনো বাকি।

## সোর্স, লাইসেন্স ও সহায়তা

KillerBench GPLv3 লাইসেন্সের অধীনে। প্রথম সর্বজনীন প্যাকেজের জন্য সোর্স সরবরাহের নির্দেশনা এবং তৃতীয় পক্ষের ফন্টের অনুমতি এখনো বাকি। সোর্সের প্রাপ্যতা, বিতরণ বিজ্ঞপ্তি, প্রমাণের গোপনীয়তা ও সহায়তার তথ্যের জন্য [KillerBench সম্পর্কে](about.html) পড়ুন। [Engine নির্দেশিকা](../engine/) অনুমোদিত সোর্স চেকআউট থাকা ডেভেলপারদের জন্য; এর মানে এই নয় যে একটি সর্বজনীন Engine প্যাকেজ উপলব্ধ।
