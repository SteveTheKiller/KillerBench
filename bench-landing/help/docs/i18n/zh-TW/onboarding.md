# 電腦準備

電腦準備用於準備新電腦。它會檢視你選擇的應用程式和設定，併為電腦命名。它本身不會下載或安裝任何內容。

操作指南：[設定新電腦](set-up-new-pc.html)。

## 執行前檢查安裝程式

命令列可以在你執行供應商的安裝程式之前對其進行驗證：

```powershell
killerbench-cli depot-verify-installer chrome C:\Installers\ChromeSetup.exe
```

只有當安裝程式帶有該供應商確切組織名稱的有效 Authenticode 簽名時，KillerBench 才會信任它。它絕不會執行安裝程式。

## 本區段的工具

準備新電腦：應用程式、名稱和設定。

### 電腦準備

檢視明確選擇的佈建應用程式和設定組。會在不下載或執行安裝程式的情況下，對目前的解除安裝、應用套件和 Office 即點即用註冊進行關聯。設定選項會說明後果，並在實現後轉到單獨的受保護工作流程。不會執行任何下載、安裝、帳戶、更新、清理、原則、登錄、服務、設定檔或重新啟動操作。

### 電腦名稱

根據目前識別和域角色檢視建議的電腦名稱。不會重新命名、收集認證或重新啟動。名稱是否可用、權限和應用程式相依性仍未驗證。
