# 隱私

隱私會讀取此電腦和執行 KillerBench 的帳戶的隱私設定，然後讓你變更所選的設定。它的範圍超出 Windows 設定應用，涵蓋應用權限、雲搜尋和搜尋要點。

操作指南：[增強 Windows 隱私](make-windows-private.html)。

## 檢視和變更設定

選擇要檢查的隱私區域，然後按 **執行診斷**。所有區域最初都未選中，且檢視是唯讀的。

要變更某項設定，請使用 **隱私設定** 控制項。KillerBench 會檢查該設定是否已由原則或裝置管理擁有，記錄目前值，只進行你所要求的一項變更，並讀回以確認。由原則擁有的設定保持不變。

這些設定包括廣告選項、剪貼簿歷史記錄、19 項應用程式權限設定（例如相機、麥克風和位置）、個人和工作帳戶的雲端內容搜尋，以及搜尋醒目提示。

## 本區段的工具

檢視並變更應用權限、建議、搜尋和廣告設定。

### 隱私

讀取此電腦和執行 KillerBench 的帳戶中所選的隱私登錄設定。單獨的顯式控制項可以在重新檢查原則、持久準備和精確驗證之後，變更剪貼簿歷史記錄或受支援的帳戶設定。其他隱私選項仍為唯讀。登錄快照不能證明有效權限或原則所有權。
