# 維護

維護讓電腦保持整潔：檔案清理、舊使用者設定檔、排程工作和 Windows 精簡。每個工具都會在刪除任何內容之前預覽將刪除的內容。

操作指南：[釋放磁碟空間](free-disk-space.html) 和 [增強 Windows 隱私](make-windows-private.html)。

## 本區段的工具

清理檔案、設定檔和排程工作，並精簡 Windows。

### 清理

使用主面板中的天數和檔案數限制設定，估算所選的臨時檔案、快取和保留的診斷證據目標。Windows Temp 和 Windows SystemTemp 是獨立的目標。傳遞最佳化是單獨的快取選項，刪除的內容可能需要重新下載。可選的永久刪除使用單獨的清理核取方塊，在所選限制範圍內重新檢查保留的候選項，並記錄每個結果。刪除會繞過回收站。目標、天數和檔案數限制也可以透過 cleanup CLI 命令進行設定。

### 設定檔

使用所選的天數閾值、確切的 ProfileList 註冊以及可選的服務和排程工作帳戶相依性來檢視 Windows 設定檔，然後返回一個有範圍限制的檢視結論。已載入的設定檔、系統設定檔和目前帳戶的設定檔不在檢視範圍內。候選項僅供檢視。不會更改任何設定檔、資料夾、登錄機碼、帳戶、服務、工作、認證、原則或檔案，也不會選擇任何刪除操作。應用程式相依性和備份的可復原性仍未驗證。

### 排程工作

清點可見的排程工作、其狀態和報告的主體。不會啟動、註冊或更改任何工作。不會驗證操作、觸發器和執行是否成功。

### Windows 精簡

針對正在執行的帳戶或所有設定檔，檢視明確的 Windows 清理區域，例如 Recall 和 AI、遙測、搜尋建議、消費者內容、工作列和開始選單、通知、Edge、電源、休眠、Office 語言以及預裝軟體。檢視是唯讀的。當高效能電源、睡眠和顯示器計時器以及休眠所在的區域是唯一的選擇時，可以在有新證據並經過明確確認後分別更改。
