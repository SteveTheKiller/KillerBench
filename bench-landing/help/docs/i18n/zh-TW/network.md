# 網路

網路會檢查連線、DNS、路由、無線和有線登入、檔案共享和遠端存取。存取其他主機的工具會使用你設定的目標和逾時，除非你確認修復，否則不會更改任何內容。

操作指南：[解決網路和 Internet 問題](fix-network.html)。

## 本區段的工具

檢查連線、DNS、路由、無線、共享和遠端存取。

### 網路

檢查介面卡、位址狀態和來源、閘道、DNS 設定、有效的 DNS 命名空間原則、TCP 設定、原生 Winsock 通訊協定和命名空間提供程式目錄結構、IP 路由表以及 Hosts 檔案對應。自動修復可以啟動已啟用的 DNS Client、DHCP Client、SMB 客戶端、Network Location Awareness、Network List 和 IP Helper 服務，併為缺少可用 IPv4 位址的已連線實體 DHCP 介面卡續訂租約。啟動網路識別服務可能會重新計算網路識別，並應用另一個現有的防火牆設定檔。IP Helper 可能會啟用現有的 IPv6 過渡、連接埠Proxy和網路通知功能。服務復原只驗證執行狀態，不驗證名稱解析成功、路由選擇、網路識別或通道執行。路由、Hosts 項目、DNS 伺服器、設定檔、防火牆規則、Winsock 提供程式、過渡設定、啟動類型和原則保持不變。續訂可能會更改租用的位址並中斷連線。靜態設定和虛擬介面卡保持不變。閘道的確切 ICMP 回應不能驗證 Internet 可存取性。

### 無線網路

檢查網路裝置和 WLAN AutoConfig 的可用性。選用的復原會在檢查相依性後，僅啟動已啟用且已停止的服務；已儲存的設定檔可能會自動重新連線。設定檔、認證、原則、無線電設定和啟動類型保持不變。不重置介面卡，也不安裝驅動程式。驗證涵蓋執行狀態，不包括無線身份驗證或連線。

### 有線身份驗證 (802.1X)

針對需要 802.1X 的網路，檢查網路裝置和 Wired AutoConfig。選用的復原會在檢查相依性後，僅啟動已啟用且已停止的服務。現有的身份驗證設定檔可能會啟用並更改網路存取。證書、認證、設定檔、原則和啟動設定保持不變。驗證僅涵蓋執行狀態，不包括身份驗證或連線。

### 網路連線

有範圍限制地檢視目前網路設定檔的分配、確切的服務故障歷史記錄以及網路連線服務的目前就緒狀態。不完整的證據優先。公用設定檔和歷史故障僅作為背景資訊，不能授權復原或網路更改。選用的復原會在重新檢查相依性後，僅啟動已啟用且已停止的確切服務。現有的網路管理介面可能會繼續。介面卡、位址、路由、DNS 設定、連線設定檔、認證、防火牆設定、原則和啟動類型保持不變。不會更改任何連線或網路設定。驗證僅涵蓋服務的穩定狀態，不包括介面卡執行、位址分配、路由、名稱解析或連線。

### WinHTTP 自動 Proxy

檢視已儲存的 WinHTTP 預設值、目前帳戶的 Internet 設定、確切的服務故障歷史記錄以及 WinHTTP 自動Proxy的目前就緒狀態。不完整的證據優先。Proxy設定和歷史故障不能授權服務復原或發現。已停止的按需啟動服務可能是正常的。僅當選擇此工具時，選用的復原才可以在重新檢查相依性後啟動已停止的已啟用服務。現有應用程式可能會在目前設定下繼續 WPAD 或 PAC 發現。Proxy定義、PAC URL、認證、網路設定、防火牆設定、原則、服務權限和啟動類型保持不變。不會取得任何 URL，也不會更改任何Proxy或網路設定。驗證僅涵蓋服務的穩定狀態，不包括發現、可存取性、身份驗證、原則所有權或應用程式使用。

### Windows 連線管理器

有範圍限制地檢視目前網路設定檔的分配、確切的服務故障歷史記錄以及 Windows 連線管理器的目前就緒狀態。不完整的證據優先。公用設定檔和歷史故障僅作為背景資訊，不能授權復原或連線決策。選用的復原會在重新檢查相依性後，僅啟動已啟用且已停止的確切服務。Windows 可能會在現有設定檔和原則下繼續自動連線決策。介面卡、設定檔、認證、按流量計費、成本、漫遊、防火牆、VPN 和身份驗證設定以及啟動類型保持不變。不會更改任何設定檔、介面卡或設定。驗證僅涵蓋服務的穩定狀態，不包括設定檔適用性、連線選擇、身份驗證、路由、名稱解析或連線。

### 網路設定服務

有範圍限制地檢視目前介面卡的通訊協定繫結、確切的服務故障歷史記錄以及網路設定服務的目前就緒狀態。不完整的證據優先。繫結狀態和歷史故障不能授權服務復原或設定更改。選用的復原會在重新檢查相依性後，僅啟動已啟用且已停止的確切服務。現有的待處理網路設定可能會按照 Windows 原則繼續。介面卡、驅動程式、驅動程式套件、繫結、位址、路由、DNS 設定、設定檔、認證、防火牆設定、原則和啟動類型保持不變。KillerBench 不會選擇任何驅動程式或設定更改。驗證僅涵蓋服務的穩定狀態，不包括介面卡可用性、驅動程式適用性、設定完成、位址分配、路由、名稱解析或連線。

### 檔案共享 (SMB)

檢查 Windows SMB 伺服器的可用性。選用的復原會在重新檢查相依性後，僅啟動已啟用且已停止的 Server 服務。現有的檔案和印表機共享可能會在目前權限和防火牆原則下變得可存取。不會更改任何共享、權限、SMB 設定、防火牆規則、認證、原則或啟動類型。驗證僅涵蓋服務的穩定狀態，不包括客戶端存取或檔案傳輸。

### 遠端存取連線管理器

在不收集機密資訊的情況下，有範圍限制地檢視目前帳戶的 VPN 設定檔設定、確切的服務故障歷史記錄以及遠端存取連線管理器的目前就緒狀態。清單為空可能是有意為之，設定檔的存在、連線標籤或歷史故障不能授權復原或連線嘗試。選用的復原會在重新檢查相依性後，僅啟動已啟用且已停止的確切服務。現有的撥號和 VPN 請求可能會繼續。連線設定檔、認證、路由、介面卡、身份驗證設定、原則和啟動類型保持不變。不會發起任何連線。驗證僅涵蓋服務的穩定狀態，不包括設定檔適用性、伺服器可存取性、身份驗證、通道協商、路由安裝、名稱解析或連線。

### 遠端桌面服務

檢視本機遠端桌面的啟用狀態、網路層級身份驗證和接聽程式連接埠、有範圍限制的連線和工作階段歷史記錄、確切的服務故障歷史記錄以及服務的目前就緒狀態。不完整的證據優先。歷史記錄不能授權服務復原或設定更改。選用的復原會在重新檢查相依性後，僅啟動已啟用且已停止的確切服務。現有的接聽程式可能會在目前原則、NLA、防火牆規則和權限下變得可存取。遠端桌面啟用狀態、接聽程式、證書、連接埠、防火牆規則、NLA、權限、工作階段、原則、服務權限和啟動類型保持不變。不會建立或更改任何接聽程式、防火牆規則、帳戶存取、證書或工作階段。驗證僅涵蓋服務的穩定狀態，不包括有效原則、接聽程式繫結、防火牆存取、證書識別、權限、身份驗證、網路可存取性、連線成功或工作階段建立。

### Windows 遠端管理

有範圍限制地檢視 WinRM 接聽程式設定、操作歷史記錄、確切的服務故障歷史記錄以及服務的目前就緒狀態。不完整的證據優先。已禁用的接聽程式或目前的服務問題需要審閱，而歷史記錄不能授權復原或設定更改。選用的復原會在重新檢查相依性後，僅啟動已啟用且已停止的確切服務。現有的 WS-Management 接聽程式可能會在目前的身份驗證、證書、防火牆、TrustedHosts 和原則設定下變得可存取。接聽程式、位址、連接埠、證書、身份驗證、加密、TrustedHosts、防火牆規則、權限、配額、原則、服務權限和啟動類型保持不變。不會建立或更改任何接聽程式、防火牆規則、信任項目、證書、認證或遠端工作階段。驗證僅涵蓋服務的穩定狀態，不包括有效原則、接聽程式繫結、防火牆存取、證書有效性、身份驗證、權限、客戶端可存取性或遠端命令執行。
