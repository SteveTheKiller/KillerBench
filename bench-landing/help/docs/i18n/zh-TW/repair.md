# 修復

修復彙集了能夠解決問題的工具。每個工具都會先進行診斷。只有當新證據顯示出它所修復的確切問題時，才會提供修復，並且只有在你開啟 **自動修復已確認的問題** 或親自確認單項修復後才會執行。每項修復都會寫入記錄，並在之後進行驗證。

操作指南：[修復系統檔案](repair-system-files.html) 和 [修復 Windows Update](fix-windows-update.html)。

## 自動修復和手動修復

**自動修復已確認的問題** 允許診斷工具在掃描後執行它證明需要的修復。此選項預設關閉。

如需單項維護修復，請開啟 **進階：記錄和手動修復** 並選擇 **修復**。選擇 **元件儲存區 (DISM)** 或 **系統檔案 (SFC)**，閱讀預覽，勾選 **在此電腦上執行此修復**，然後按 **執行修復**。有關任何變更前後會發生什麼，請參閱 [如何保證變更安全](safety.html)。

## 本區段的工具

在診斷發現問題後使用這些工具。修復需要已確認的證據和明確的核准。

### Windows 核心服務

同時檢查 Power、Plug and Play、User Manager、Group Policy Client、Network Store Interface、RPC Endpoint Mapper、Remote Procedure Call、DCOM Server Process Launcher、Background Tasks Infrastructure 和 CoreMessaging 服務。選用的復原僅啟動在啟動期間結束和完整相依性檢查之後，經新證據確認已停止的確切已啟用自動啟動服務。按需啟動的服務在空閒時保持不變。電源計畫、裝置、驅動程式、帳戶、認證、設定檔、原則、介面卡、位址、路由、DNS、防火牆設定、註冊、端點、工作註冊、應用程式資料、服務權限和啟動類型保持不變。不會要求原則重新整理、裝置掃描、帳戶操作、網路變更、電源設定變更、註冊變更或工作啟動。驗證僅涵蓋服務的穩定狀態，不包括端到端的功能行為。

### 系統檔案

有範圍限制地清點 Windows 維護套件、選用功能和功能的狀態，檢查前提條件，掃描受保護的系統檔案，並且僅在即時檢查確認損壞時才自動選擇 SFC。套件、功能或功能處於待處理狀態時需要審閱，但不會授權安裝、刪除、清理、復原、啟用或停用。

### WMI 儲存庫

先檢查 WMI 服務的可用性，再檢查儲存庫的一致性。自動修復可以啟動符合條件的已停止服務並搶救已確認的損壞，然後驗證每個結果。已停用服務的設定保持不變。可讀的註冊會被合併；不可讀的內容可能需要重新安裝提供者。管理用戶端可能會被中斷。不進行重設、刪除或自動復原。

### Windows 系統通知

讀取最近的服務控制管理員歷史記錄，然後同時檢查 COM+ Event System 和 System Event Notification Service。選用的復原會在啟動 SENS 之前驗證 COM+ Event System 的就緒狀態。現有的登入、網路、電源和 COM+ 通知可能會在目前設定下繼續。COM+ 目錄、訂閱、通知註冊、使用者、帳戶、權限、復原設定、原則和啟動類型保持不變。不會變更任何訂閱、註冊、使用者、帳戶、權限或原則。驗證僅涵蓋服務的穩定狀態，不包括端到端的通知傳遞。

### 診斷原則服務

有範圍限制地檢視診斷原則的操作歷史記錄、確切的服務故障歷史記錄以及服務的目前就緒狀態。不完整的證據優先。歷史記錄不能授權服務復原或疑難解答操作。選用的復原會在重新檢查相依性後，僅啟動已啟用且已停止的確切服務。現有的診斷場景可能會繼續。原則、疑難解答資料和啟動類型保持不變。不會執行任何疑難解答程式或建議的修復。驗證僅涵蓋服務的穩定狀態，不包括故障檢測、診斷完成或修復結果。

### Windows 錯誤報告

檢視當機傾印設定、有範圍限制的傾印檔案中繼資料、最近的系統當機報告、Windows 錯誤報告服務的確切故障歷史記錄以及服務的目前就緒狀態。歷史報告不能確定目前故障或根本原因，也不能授權復原。選用的復原會在重新檢查相依性後，僅啟動已啟用且已停止的確切服務。現有的排隊報告可能會按照目前原則繼續。報告存檔、傾印、同意設定、上傳原則和啟動類型保持不變。不會要求上傳或刪除。驗證僅涵蓋服務的穩定狀態，不包括報告的建立、上傳、傳遞、問題解決或當機診斷。

### Windows 事件收集器

有範圍限制地檢視 Windows 事件收集器的訂閱清單、確切的服務故障歷史記錄以及服務的目前就緒狀態。清單為空可能是有意為之，訂閱數量或歷史故障不能授權復原。選用的復原會在重新檢查相依性後，僅啟動已啟用且已停止的確切服務。現有訂閱可能會繼續遠端事件收集。訂閱、轉發的事件、認證、通道設定、原則和啟動類型保持不變。驗證僅涵蓋服務的穩定狀態，不包括來源可存取性、身份驗證、遠端傳遞、事件的新舊或訂閱執行狀況。

### Windows 事件記錄

檢查四個診斷通道的啟用狀態、保留模式、目前大小、設定的限制、記錄數和飽和度，然後檢查 Windows 事件記錄服務的可用性。自動修復可以在檢查相依性後啟動已停止的已啟用服務，並驗證執行狀態。單獨確認的專用操作可以啟用一個確切的、已停用且不受管理的診斷通道，同時保留報告的所有其他設定。記錄、通道權限、保留、大小限制、啟動類型和受管理的設定保持不變。事件傳遞是否成功和存檔容量仍未驗證。

### Windows 時間服務

檢查 Windows 時間的設定、服務和同步。當目前狀態報告確切的服務已停止錯誤，並且新的原則、模式和相依性檢查均透過時，自動修復可以啟動 W32Time，然後要求重新同步並驗證新狀態。這可能會使用現有的已設定來源調整時鐘。啟動類型、來源設定和受管理的設定保持不變。

### 工作排程器服務

有範圍限制地清點排程工作的狀態、執行結果和錯過的執行次數，然後在檢查服務目前可用性之前，將其與工作計畫程式服務的確切故障歷史記錄結合起來。工作發現和服務的歷史故障不能授權啟動服務。選用的復原會在重新檢查相依性後，僅啟動已啟用且已停止的確切服務。現有的已啟用工作可能會在其設定的帳戶下開始執行，包括錯過的觸發器。不會變更任何工作定義、主體、認證引用、原則或啟動類型，也不會直接啟動或刪除任何工作。驗證僅涵蓋服務的穩定狀態，不包括操作是否成功、認證是否有效或未來的工作結果。

### 使用者設定檔服務

檢查使用者設定檔服務的可用性。選用的復原會在重新檢查相依性後，僅啟動已啟用且已停止的確切服務。現有的登入和設定檔要求可能會繼續。設定檔資料夾、登錄設定單元、權限、設定檔列表註冊、認證、使用者資料、原則、服務權限和啟動類型保持不變。不會要求任何設定檔操作。驗證僅涵蓋服務的穩定狀態，不包括登入、設定檔載入或使用者資料存取。

### 備份服務

檢查 Volume Shadow Copy、Microsoft Software Shadow Copy Provider、Windows Backup 和 Block Level Backup Engine 服務，然後讀取 VSS 寫入器狀態、已註冊的提供者類型、目前快照和陰影複製儲存區分配。已停止的按需啟動服務在空閒時可能是正常的。選用的復原會在檢查相依性後，僅啟動已停止的自動啟動服務，然後驗證執行狀態。現有的計畫或中斷的備份工作可能會繼續。已停用和按需啟動的啟動設定、快照、陰影複製儲存區、提供者註冊、備份計畫、目錄、計畫、目標、認證和保留期限保持不變。不會選擇或重新設定任何備份，不會重新啟動任何服務，也不會刪除任何快照或目錄。提供者註冊、寫入器狀態、儲存分配和服務的穩定狀態不能驗證備份完成、目標存取或還原成功。
