# 安全

安全會檢查 Microsoft Defender、防火牆、證書和登入服務。它還會顯示 BitLocker 和 Windows Hello 所依賴的 TPM 和平臺安全狀態。

操作指南：[使用 BitLocker 加密磁碟機](encrypt-with-bitlocker.html) 和 [增強 Windows 隱私](make-windows-private.html)。

## 本區段的工具

檢查保護、防火牆、證書和登入服務。

### Microsoft Defender

檢查 Defender 保護和簽名狀態。只有當 Defender 報告保護處於活動狀態且簽名已過期時，自動修復才會更新簽名。使用已設定的簽名來源。不更改保護、排除項或原則；不進行惡意軟體掃描。

### Windows 安全性中心

在不解釋保護執行狀況的情況下，有範圍限制地檢視帶有提供程式原始狀態的防病毒註冊、確切的服務故障歷史記錄以及 Windows 安全中心的目前就緒狀態。列表為空並不代表對保護執行狀況的結論，註冊數量、原始狀態或歷史故障也不能授權復原或安全更改。選用的復原會在重新檢查相依性後，僅啟動已啟用且已停止的確切服務。現有的安全狀態監視和通知可能會繼續。防病毒設定、提供程式註冊、保護設定、排除項、通知、原則和啟動類型保持不變。不會請求掃描、更新或更改保護。驗證僅涵蓋服務的穩定狀態，不包括防病毒軟體是否存在、保護狀態、簽名的新舊、通知傳遞、註冊所有權或有效原則。

### 防火牆服務

從 ActiveStore 讀取域、專用和公用設定檔的啟用設定，然後檢查 Base Filtering Engine 和 Windows Defender 防火牆服務。選用的復原會在重新檢查相依性後，僅啟動已啟用且已停止的服務。現有的篩選原則可能會生效，並中斷網路或遠端存取。啟動類型、服務權限、防火牆規則、設定檔和 IPsec 設定保持不變。不進行重置、規則更改或服務停止。驗證只能確認服務正在執行；實際保護和連線性仍未驗證。

### 憑證到期

檢查證書日期，併為電腦和目前使用者的個人儲存構建僅使用快取的本機信任鏈，然後返回一個有範圍限制的執行結論。吊銷、伺服器出示、繫結、註冊、原則所有權、遠端信任和私鑰可用性仍未驗證。不會更改任何證書、信任設定、註冊、繫結、私鑰、應用程式、服務或原則。

### 認證管理器

檢查認證管理器服務的可用性。選用的復原會在重新檢查相依性後，僅啟動已啟用且已停止的確切服務。現有應用程式可能會繼續對已儲存認證的請求。保管庫內容、密碼、通行金鑰、證書、權杖、認證註冊、權限、原則、服務權限和啟動類型保持不變。不會請求認證內容或認證操作。驗證僅涵蓋服務的穩定狀態，不包括認證檢索、身份驗證或應用程式存取。

### Web 帳戶管理器

檢視已清除負載內容的帳戶Proxy歷史記錄以及 Web 帳戶管理器的確切可用性。選用的復原會在重新檢查相依性後，僅啟動已啟用且已停止的確切服務。現有應用程式可能會按照目前原則繼續帳戶和權杖請求。歷史事件不能授權復原，也不能確定目前的帳戶狀態。帳戶、認證、權杖、Cookie、應用程式註冊、權限、登入狀態、原則、服務權限和啟動類型保持不變。KillerBench 不會選擇任何帳戶、認證、權杖、Cookie、權限或登入操作。驗證僅涵蓋服務的穩定狀態，不包括身份驗證、權杖頒發或應用程式存取。
