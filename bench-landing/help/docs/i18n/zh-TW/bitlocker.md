# BitLocker

BitLocker 會檢查磁碟機加密、保護裝置和修復資訊，然後幫助你備份、保護或變更磁碟機。它僅在此電腦上工作。

操作指南：[使用 BitLocker 加密磁碟機](encrypt-with-bitlocker.html)。

## 使用 BitLocker 工具

選擇磁碟機代號和一項 **操作**，然後按 **執行診斷**。

- **檢查** 讀取加密狀態、保護狀態和保護裝置識別。這是預設操作，不會變更任何內容。
- **備份修復資訊** 將所選的修復密碼寫入受保護磁碟機之外的新檔案並進行驗證。請先按 **尋找修復保護裝置**，選擇保護裝置，然後確認備份。
- **加密** 備份所選的修復密碼，驗證備份，然後使用你選擇的方法開始一次加密。Windows 磁碟機需要 TPM 保護裝置和修復密碼。資料磁碟機只需要修復密碼。
- **繼續保護** 會為保護已暫停的完全加密磁碟機重新開啟保護。

以上每項操作都需要其單獨的確認框，並且 KillerBench 會在執行前立即重新檢查磁碟機。

## 更多 BitLocker 操作

對於 **執行診斷** 之外的變更，請開啟 **更多 BitLocker 動作**。選擇一項操作，按 **預覽** 檢視其確切要求，然後確認並按 **執行動作**。

- **開啟自動解除鎖定** 可以讓已加密的資料磁碟機在 Windows 啟動時解鎖。Windows 磁碟機必須已完全加密且保護已開啟。
- **新增 TPM 保護裝置** 或 **新增修復密碼** 會建立一個新的保護裝置。KillerBench 絕不會顯示或記錄新的修復密碼，因此請立即備份。
- **將修復密碼備份到 Active Directory** 或 **Microsoft Entra ID** 會傳送你在上方選擇的保護裝置。KillerBench 會報告 Windows 已接受要求。它無法讀取目錄中的副本，因此請在那裡確認。
- **解密此磁碟機** 會開始解密，例如在使用所需方法重新加密之前。由於磁碟機在之後將不受保護，因此需要第二次確認；當其他磁碟機正從 Windows 磁碟機自動解鎖時，它會拒絕對 Windows 磁碟機執行此操作。

## TPM 和 FIPS

如果 TPM 存在但尚未就緒，安全區段可以在不清除的情況下準備它。KillerBench 絕不會清除 TPM，因為這會銷燬 BitLocker 和 Windows Hello 持有的金鑰。FIPS 演算法原則開關作為明確且可撤消的修復提供，適用於需要符合 FIPS 的 BitLocker PIN 的組織。

## 本區段的工具

檢查加密、保護裝置和修復資訊，然後備份它們或保護磁碟機。

### BitLocker

預覽 BitLocker 選項並檢查所選磁碟區。此工作流程不會執行加密或復原備份。
