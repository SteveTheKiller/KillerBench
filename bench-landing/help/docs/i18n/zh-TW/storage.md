# 儲存

檢查磁碟、磁碟區、儲存空間和磁碟機維護服務。診斷不會選擇磁碟操作；任何受支援的、會更改電腦的操作都需要其確切的目標、前提條件和確認。

操作指南：[檢查和修復磁碟機](check-a-drive.html) 和 [釋放磁碟空間](free-disk-space.html)。

## 本區段的工具

### 儲存

在有範圍限制的情況下對應磁碟、磁碟分割和有磁碟機代號的磁碟區的識別，評估每個有磁碟機代號的磁碟區是否低於 10% 可用空間，檢查 VSS 陰影複製儲存區分配和每個磁碟區的配額預設值，彙總 Storage 模組作業的目前進度，檢查所選 NTFS 磁碟區及其線上自我修復狀態，並檢查此電腦上的磁碟和控制器裝置。容量閾值、配額設定和作業狀態是需要審閱的證據，不會選擇清理、調整大小、更改配額或控制作業。磁碟機代號對應反映的是某一時刻的情況，不涵蓋所有掛接路徑。裝置結論不會對應到所選磁碟區。預設選擇 Windows 磁碟區。不會更改任何檔案、快照、作業或驅動程式，不會更改任何設定，不會解除安裝任何磁碟區，也不會安排重新啟動。

### 儲存空間

清點非原始的儲存空間池和虛擬磁碟，包括執行狀況、操作狀態、容量、分配和復原能力，然後返回一個有範圍限制的執行結論。在回應此唯讀查詢時，Windows 可能會按需啟動其儲存空間管理提供程式。池、虛擬磁碟、實體磁碟、磁碟區、復原能力、分配、維護設定、原則和啟動類型保持不變。不會請求任何池、磁碟、磁碟區、分配、附加、修復、最佳化或設定操作。提供程式的結果不能驗證池的可存取性、冗餘、資料完整性、備份的可復原性或應用程式 I/O。

### 儲存服務

在有範圍限制的情況下檢視 Storage 模組的目前作業、確切的服務故障歷史記錄以及儲存服務的目前就緒狀態。不完整的證據優先。作業狀態和歷史故障不能授權服務復原或儲存更改。選用的復原會在重新檢查相依性後，僅啟動已啟用且已停止的確切服務。現有的儲存通知和由原則管理的儲存活動可能會繼續。磁碟區、磁碟分割、檔案系統、掛接點、裝置、驅動程式、儲存感知設定、維護原則、服務權限和啟動類型保持不變。KillerBench 不會選擇任何作業、磁碟區、磁碟分割、掛接點、檔案、裝置、驅動程式或儲存設定操作。驗證僅涵蓋服務的穩定狀態，不包括作業結果或裝置、磁碟區、儲存原則的執行情況。

### 最佳化磁碟機服務

檢查最佳化磁碟機服務的可用性。選用的復原會在重新檢查相依性後，僅啟動已啟用且已停止的確切服務。Windows 已排程的現有最佳化活動可能會按照目前維護原則繼續。磁碟區、檔案系統、資料、最佳化計畫、維護原則、服務權限和啟動類型保持不變。KillerBench 不會選擇磁碟區，也不會對任何磁碟機進行分析、修整、磁碟重組、最佳化或計畫。驗證僅涵蓋服務的穩定狀態，不包括分析、最佳化或裝置執行狀況。
