# 疑難解答

## 操作顯示被阻止

被阻止的結果表示所要求的操作無法繼續。請閱讀訊息和記錄，了解它是在傳送之前停止，還是在之前的某個步驟之後停止。不要以為部分完成的操作已經復原。最常見的前提條件原因如下。

- **需要系統管理員存取權限。** 關閉 KillerBench，然後透過 **以系統管理員身分執行** 重新啟動。
- **重新啟動狀態必須已清除。** Windows 有待處理的重新啟動。請重新啟動電腦，然後再次執行該操作。
- **存在受管理的原則。** 該設定由群組原則或裝置管理擁有。請在那裡變更。
- **證據已變化。** 在首次檢查和最後複查之間發生了變化。請再次執行工具以讀取新狀態。

## 之前的要求需要核對

KillerBench 發現了一個來自中斷要求的待處理記錄。請再次執行同一操作。它會檢查發生了什麼，並在不重複要求的情況下報告實際結果。在命令列中，請使用相應的 `-recover` 命令，例如 `killerbench-cli bitlocker-auto-unlock-recover`。

## 檢查顯示未完成或未知

無法讀取證據，通常是因為 KillerBench 未以系統管理員身份執行，或者某個 Windows 服務不可用。KillerBench 會如實報告這一點，而不會假定電腦正常。

## 檔案儲存位置

記錄、待處理記錄和已儲存的證據位於 `%LOCALAPPDATA%\KillerBench` 下。每個受保護的操作都有自己的資料夾。如果需要保留變更記錄，請保留這些檔案。

## 報告問題

KillerBench 正在開發中。報告問題時，請附上匯出的報告和活動記錄，並刪除任何不願共享的內容。
