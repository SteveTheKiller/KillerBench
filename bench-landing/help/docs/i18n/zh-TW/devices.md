# 裝置

裝置涵蓋印表機、音訊、相機、藍芽、輸入裝置以及所連線硬體依賴的 Windows 服務。

操作指南：[解決列印問題](fix-printing.html) 和 [調查當機和藍色畫面](investigate-crashes.html)。

## 本區段的工具

列印、音訊、相機、藍芽、輸入以及所連線硬體背後的服務。

### 列印

檢查 Print Spooler、本機佇列暫停、可見的列印作業、離線設定和驅動程式報告的狀況，然後清點佇列、驅動程式、連接埠、Standard TCP/IP 端點、列印處理器和列印監視器的註冊。僅當存在一個確切的目前佇列識別時，才關聯最近的 PrintService 問題。已分配的 Standard TCP/IP 端點會接受一次有範圍限制的連線嘗試，不包含應用程式資料、SNMP 或列印作業。自動修復可以啟動已啟用的列印多工緩衝處理器，僅復原具有新的等待作業證據的確切已暫停佇列，並清除離線模式。沒有作業等待的有意暫停僅供檢視。遠端連線、SNMP 團體字串、擴充功能註冊和作業內容保持不變。狀況代碼或連線成功不能確定印表機識別、耗材、機械、佇列接受、渲染成功或實際列印。

### 音訊

檢查預設多媒體輸入和輸出裝置的識別及共享格式、音訊裝置和驅動程式狀態、Audio Endpoint Builder 和 Windows Audio。自動修復會啟動已停止的已啟用服務並驗證執行狀態。啟動設定、驅動程式、所選裝置、獨佔模式和音量層級保持不變。聲音播放、錄音和應用程式音訊路由仍未測試。

### 相機支援

檢查相機和影像裝置錯誤、硬體 ID、已安裝的驅動程式證據以及 Windows Camera Frame Server 的可用性。選用的復原會在檢查相依性後，僅啟動已啟用且已停止的服務。已在請求相機存取的應用程式可能會在現有權限下繼續。相機隱私設定、權限、裝置設定、原則、驅動程式和啟動類型保持不變。不進行重置、權限更改或驅動程式安裝。驗證僅涵蓋報告的裝置設定和服務執行狀態，不包括影像擷取、隱私存取或實體執行。
