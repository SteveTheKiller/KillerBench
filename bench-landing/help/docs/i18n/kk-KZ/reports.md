# Есептер мен дәлелдер

Әр іске қосу оқуға, сүзуге және экспорттауға болатын есеп жасайды. Есеп әрқашан дәлелденгенді тек байқалғаннан бөліп көрсетеді.

## Сіз көретін күйлер

| Күй | Мағынасы |
| --- | --- |
| Қарап шығу керек | Дәлелдер назар аударуды қажет ететін мәселені растайды. |
| Ақпарат | Дәлелдер жиналып, контекст үшін көрсетілген. |
| Аяқталмаған немесе Белгісіз | Тексеру аяқталмады немесе дәлел қолжетімсіз болды. Ол ешқашан жарамды деп саналмайды. |
| Тарихи | Өткен оқиға. Ол тарихты түсіндіреді, бірақ ағымдағы ақауды дәлелдемейді. |
| Расталды | Жөндеу немесе өзгеріс нәтижені қайта оқу арқылы расталды. |

## Шикі шығыс және оқылатын есеп

**Шикі шығыс** техникалық дәлелдерді бастапқы жол нөмірлерімен сақтайды, сондықтан кез келген қорытындыны оның көзіне дейін қадағалай аласыз. **Оқылатын есеп** сол іске қосуды қарапайым тілмен қорытындылайды және келесі қауіпсіз қадамнан басталады.

## Сақталған журналдар

KillerBench компьютерде ештеңе іске қоспай-ақ CBS және Setup журналдары сияқты сақталған Windows журналдарын да оқи алады. Қорытындылар оларды тудырған нақты жолға сілтеме береді. Сеанс көздеріндегі **Үлгіні жүктеу** қауіпсіз зерттеуге болатын синтетикалық мысалды ашады.

## Экспорттау

**Есепті экспорттау** есепті бастапқы жолдарымен, талданған жазбаларымен және дәлел үзінділерімен сақтайды, оны өтінімге тіркемес бұрын қарап шығуға болады. Шикі журналдар мен дәлел үзінділерінде компьютер атаулары, тіркелгілер, жолдар немесе құпия бастапқы мәтін болуы мүмкін. Қорғалған жинаушылар сақтайтын деректерін шектейді, бірақ импортталған дәлелдердің өңделгеніне кепілдік жоқ. Бөліспес бұрын құпия ақпаратты тексеріп, алып тастаңыз.
