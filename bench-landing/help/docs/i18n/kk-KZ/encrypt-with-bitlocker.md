# Дискіні BitLocker арқылы шифрлау

Мұны BitLocker-ті қосу, қалпына келтіру кілтінің сақтық көшірмесін жасау және дискінің қорғалғанын растау үшін пайдаланыңыз. KillerBench шифрлауды бастамас бұрын қалпына келтіру құпия сөзінің сақтық көшірмесін жасап, оны растайды және қалпына келтіру құпия сөзін ешқашан көрсетпейді немесе журналға жазбайды.

## Бастамас бұрын

- KillerBench-ті әкімші ретінде іске қосыңыз.
- Windows дискісіне TPM қорғағышы мен қалпына келтіру құпия сөзі қорғағышы қажет. Деректер дискісіне тек қалпына келтіру құпия сөзі қажет.
- Қалпына келтіру кілтінің сақтық көшірмесі қайда сақталатынын шешіңіз: шифрланатын дискіден тыс файлға және қосымша түрде Active Directory немесе Microsoft Entra ID жүйесіне.

## Дискіні тексеру

1. **BitLocker** бөлімін ашып, **Том** ішінен дискіні таңдаңыз.
2. Әрекетті **Тексеру** күйінде қалдырып, **Диагнозды іске қосу** түймесін басыңыз. Есеп шифрлау күйін, қорғау күйін және қорғағыштардың сәйкестендіргіштерін көрсетеді.
3. TPM бар, бірақ дайын болмаса, әуелі оны **Қауіпсіздік** бөлімінен дайындаңыз. KillerBench TPM-ді ешқашан тазаламайды.

## Қажет қорғағыштарды қосу

1. **BitLocker-тің басқа әрекеттері** ашыңыз.
2. **TPM қорғағышын қосу** немесе **Қалпына келтіру құпия сөзін қосу** таңдап, **Алдын ала қарау** түймесін басыңыз, **Әрекетті іске қосу түймесін басқанда осы өзгерісті таңдалған дискіде жасау** белгілеңіз, содан кейін **Әрекетті іске қосу** түймесін басыңыз.
3. Жаңа қалпына келтіру құпия сөзінің сақтық көшірмесін бірден жасаңыз. KillerBench оны көрсетпейді.

## Қалпына келтіру кілтінің сақтық көшірмесін жасау және шифрлау

1. **Қалпына келтіру қорғаушыларын табу** түймесін басып, қалпына келтіру құпия сөзі қорғағышын таңдаңыз.
2. Шифрланатын дискіден тыс сақтық көшірме файлының толық жолын енгізіңіз.
3. **Шифрлау** таңдап, шифрлау әдісін таңдаңыз және **«Диагнозды іске қосу» түймесін таңдағанда таңдалған қалпына келтіру кілтінің көшірмесін жасап, шифрлауды бастау** белгілеңіз.
4. **Диагнозды іске қосу** түймесін басыңыз. KillerBench сақтық көшірмені жазады, оны растайды, содан кейін шифрлауды бір рет бастайды.
5. Шифрлау фондық режимде жалғасады. Дискі толық шифрланған және қорғау қосулы деп хабарлайтынын растау үшін кейінірек **Тексеру** іске қосыңыз.

## Active Directory немесе Entra ID жүйесіне сақтау

**BitLocker-тің басқа әрекеттері** ішінде таңдалған қорғағыш үшін каталогқа сақтық көшірме жасауды таңдаңыз. KillerBench Windows сұрауды қабылдағанын хабарлайды, бірақ каталогтағы көшірмені оқи алмайды, сондықтан оны Active Directory немесе Entra әкімші орталығында растаңыз.

## Деректер дискілері және автоматты құлыптан босату

Деректер дискісі шифрланғаннан кейін **Автоматты құлыптан босатуды қосу** оны Windows іске қосылғанда құлыптан босатады. Windows дискісі қорғау қосулы күйде толық шифрланған болуы керек.

## Пәрмен жолынан

```powershell
killerbench-cli bitlocker-protectors C:
killerbench-cli bitlocker-protector-add C: recovery --execute
killerbench-cli bitlocker-encrypt C: RECOVERY_PROTECTOR_GUID D:\Keys\C-recovery.txt --execute
killerbench-cli bitlocker-escrow C: RECOVERY_PROTECTOR_GUID entra --execute
```

[bitlocker-protectors](cli.html#cmd-bitlocker-protectors), [bitlocker-protector-add](cli.html#cmd-bitlocker-protector-add), [bitlocker-encrypt](cli.html#cmd-bitlocker-encrypt) және [bitlocker-escrow](cli.html#cmd-bitlocker-escrow) қараңыз. Әрқайсысында үзілген сұрауға арналған сәйкес `-recover` пәрмені бар.
