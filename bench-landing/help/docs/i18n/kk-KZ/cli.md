# Пәрмен жолы

`killerbench-cli` жұмыс үстелі қолданбасымен бірдей Engine-ді PowerShell-ден немесе қашықтағы консольден іске қосады. Компьютерді өзгерте алатын әр пәрмен әдепкі бойынша алдын ала қарау көрсетеді және әрекет етпес бұрын `--execute` сияқты айқын жалауша қажет етеді. Пәрмендер JSON дәлелдерін стандартты шығысқа, ал барысты стандартты қате ағынына шығарады.

Қадамдық нұсқаулықтар: [KillerBench-ті скрипттерден іске қосу](use-the-cli.html).

0 шығу коды алдын ала қарау немесе расталған нәтиже сәтті болғанын, 1 іске қосу, енгізу немесе журнал қатесін, 2 аргументтер танылмағанын, 3 бұғатталғанын, сәтсіз болғанын немесе расталмағанын, 4 жұмыс ағыны растау алдында қайта іске қосуды қажет ететінін, ал 130 оны сіз тоқтатқаныңызды білдіреді.

Бұл тізімді өз компьютеріңізде шығару үшін `killerbench-cli` пәрменін аргументсіз іске қосыңыз.

## Жаңартулар және қызмет көрсету

- `bits-job-review JOB_GUID [--all-users] [--observe]`: Тасымалды нақты қарап шығу немесе екі лездік көшірмені бақылау; қайталаусыз.
- `bits-jobs [--all-users]`: BITS тапсырмаларының күйлері, иелері және байт сандары; тасымалдар өзгертілмейді.
- `bits-retry JOB_GUID [--execute]`: Әдепкі бойынша алдын ала қарау; нақты тапсырманы айқын қайталау, қолданбаның аяқталғаны туралы мәлімдемесіз.
- `bits-retry-recover JOB_GUID`: Тек оқуға арналған екі лездік көшірме; тұрақты нәтижелерді қайта әрекетсіз мұрағаттайды.
- `component-repair-source`: Басқарылатын DISM жөндеу көзі саясаты мен қайшылықтар; өзгеріссіз.
- `delivery-optimization`: Delivery Optimization қызметінің күйі, тек оқу; JSON дәлелдері.
- `delivery-optimization-activity`: Құпиялылыққа байланысты шектелген ағымдағы тапсырма сандары мен байт қосындылары; тасымал сәйкестендіргіштерінсіз және өзгеріссіз.
- `delivery-optimization-policy`: Классикалық және Policy CSP параметрлері, тек оқу; құпия мәндер мен провайдер сәйкестендіргіштері алынып тасталған.
- `feature-service-events`: Уақыт, Search, WMI, оқиғалар журналы және дыбыс қызметтерінің нақты ақаулар тарихын оқиды.
- `feature-update-policy`: Мақсатты шығарылым, кейінге қалдыру, кідірту және қорғау саясаты, тек оқу; JSON дәлелдері.
- `pending-file-operations`: Құпиялылыққа байланысты шектелген күтудегі файл әрекеттерінің қорытындысы, тек оқу; JSON дәлелдері.
- `restart-check`: Күтудегі қайта іске қосу көздері, тек оқу; JSON дәлелдері.
- `servicing-logs`: Ең жаңа CBS, мәтіндік және сығылған CBS мұрағаттарын, DISM және Windows Setup журналдарын шектелген талдау; жөндеусіз.
- `servicing-monitor [--refresh 1..60] [--samples 1..120] [--skip-events] [--skip-history] [--skip-services] [--skip-restart] [--skip-setup] [--skip-compatibility] [--skip-readiness] [--skip-transfers] [--skip-delivery-optimization] [--skip-installer] [--skip-scheduled-task]`: Қызмет көрсету әрекетінің лездік көшірмелері, тек оқу.
- `servicing-service-events`: Windows Update қызмет көрсету тізбегінің нақты ақаулар тарихы, тек оқу.
- `servicing-service-states`: Windows Update қызмет көрсету тізбегіндегі алты қызметтің ағымдағы күйі, тек оқу.
- `setup-code DECIMAL_OR_0xHEX`: Windows Setup нәтиже кодтарының құжатталған анықтамасы; компьютерді тексерусіз және жөндеусіз.
- `update-applicability`: Windows басылымы, құрастырмасы және архитектурасы туралы дәлелдер, тек оқу.
- `update-cache`: SoftwareDistribution кэшінің шектелген қосындылары, тек оқу; файл атауларынсыз.
- `update-code DECIMAL_OR_0xHEX`: Windows Update нәтиже кодтарының құжатталған анықтамасы; компьютерді тексерусіз және жөндеусіз.
- `update-context`: Ағымдағы құқықтарды көтеру және жұмыс үстелі сеансы туралы дәлелдер, тек оқу; тіркелгі идентификаторларынсыз.
- `update-engine-files`: Жергілікті Windows Update механизмінің бары, нұсқасы және қолтаңбасы туралы дәлелдер, тек оқу.
- `update-events`: Соңғы жеті күндегі Windows Update Client тарихы, тек оқу; шикі дәлелдері бар JSON.
- `update-followup DECIMAL_OR_0xHEX`: Құжатталған Windows Update нәтиже коды бойынша таңдалған жаңа диагностика, тек оқу.
- `update-history`: Windows Update әрекеттерінің ең жаңа 100 нәтижесі, тек оқу; JSON дәлелдері.
- `update-plan --select GUID:REVISION [--drivers] [--no-software] [--allow-restart-required] [--json] [--execute]`: `--select` қайталаңыз; әдепкі бойынша алдын ала қарау.
- `update-policy`: Басқарылатын Windows Update саясаты, тек оқу; JSON дәлелдері.
- `update-policy-surfaces`: Классикалық және Policy CSP конфигурация беттері туралы дәлелдер, тек оқу; мәндер мен провайдер сәйкестендіргіштері алынып тасталған.
- `update-recover`: Күтудегі жаңартуды тексереді; оны ешқашан орнатпайды немесе қайталамайды.
- `update-restart-policy`: Сәйкестік мерзімдері, жеңілдік кезеңдері, қайта іске қосуды басу және хабарландыру мінез-құлқы, тек оқу.
- `update-search [--drivers] [--no-software] [--filter TITLE] [--downloaded-only] [--classification GUID] [--product GUID]`: JSON табу нәтижелері мен сәйкестіктер; орнатусыз.
- `update-service-events`: Windows Update қызметінің нақты ақаулар тарихы, тек оқу.
- `update-service-files`: Windows Update қызметінің нақты DLL тіркеуі мен қолтаңбасы туралы дәлелдер, тек оқу.
- `update-services`: Windows Update қызметтерінің тіркеулері, тек оқу; JSON дәлелдері.
- `update-store-reset [--source Configured|WindowsUpdate|MicrosoftUpdate] [--drivers] [--no-software] [--execute]`: Жаңа іздеуді талап етеді; әдепкі бойынша алдын ала қарау; ескі қойманы сақтайды.
- `update-store-reset-recover`: Дайындалған қойманы қалпына келтіруді қайталамай салыстырады.
- `windows-capabilities`: Онлайн Windows мүмкіндіктерінің күйлері, тек оқу; JSON нәтижесі.
- `windows-update-task`: Scheduled Start нақты тапсырмасының күйі мен орындалу тарихы, тек оқу; тапсырманы іске қосусыз және жаңарту әрекетінсіз.

## BitLocker және TPM

- `bitlocker-auto-unlock DRIVE: [--execute]`: Әдепкі бойынша алдын ала қарау; шифрланған деректер томы үшін автоматты құлыптан босатуды қосады.
- `bitlocker-auto-unlock-recover`: Үзілген автоматты құлыптан босату сұрауын қайталамай растайды.
- `bitlocker-backup DRIVE: PROTECTOR_GUID FILE_PATH [--execute]`: Әдепкі бойынша алдын ала қарау; тек жаңа қалпына келтіру көшірмесі файлы.
- `bitlocker-backup-recover DRIVE: PROTECTOR_GUID FILE_PATH`: Үзілген сақтық көшірмені қайта жазбай растайды.
- `bitlocker-decrypt DRIVE: [--execute --confirm-unprotected]`: Әдепкі бойынша алдын ала қарау; шифрды ашуды бастайды, мысалы талап етілетін әдіспен қайта шифрлау алдында.
- `bitlocker-decrypt-recover`: Үзілген шифрды ашу сұрауын қайталамай растайды.
- `bitlocker-encrypt DRIVE: RECOVERY_PROTECTOR_GUID NEW_BACKUP_FILE [--encryption XtsAes128] [--used-space-only] [--execute]`: Әдепкі бойынша алдын ала қарау; бар TPM және қалпына келтіру қорғағыштарын талап етеді.
- `bitlocker-encrypt-recover`: Күтудегі түрлендіру күйін сұрауды қайталамай растайды.
- `bitlocker-escrow DRIVE: RECOVERY_PROTECTOR_GUID ad|entra [--execute]`: Әдепкі бойынша алдын ала қарау; бар қалпына келтіру құпия сөзінің сақтық көшірмесін Active Directory немесе Microsoft Entra ID жүйесіне жасайды.
- `bitlocker-plan --volume C: --operation Encrypt --encryption XtsAes256 --backup EntraId`: Тек параметрлерді алдын ала қарау.
- `bitlocker-protector-add DRIVE: tpm|recovery [--execute]`: Әдепкі бойынша алдын ала қарау; бір TPM немесе қалпына келтіру құпия сөзі қорғағышын қосады; құпия сөз ешқашан шығарылмайды.
- `bitlocker-protector-recover`: Үзілген қорғағыш сұрауын қайталамай растайды.
- `bitlocker-protectors DRIVE:`: Тек қорғағыштардың сәйкестендіргіштері мен түрлері; қалпына келтіру құпия сөздерінсіз.
- `bitlocker-resume DRIVE: [--execute]`: Әдепкі бойынша алдын ала қарау; тек толық шифрланған, қорғауы тоқтатылған нақты том.
- `bitlocker-resume-recover`: Күтудегі қорғау күйін сұрауды қайталамай растайды.

## Қауіпсіздік және құпиялылық

- `certificate-chains`: Жеке сертификаттар үшін тек кэшке негізделген жергілікті сенім тізбегі, тек оқу; кері шақыру тексерусіз және жүктеусіз.
- `defender-overview [--report]`: Қорғауға, сканерлеу уақытына және жиынтық қауіптерге шолу, тек оқу; әрекетсіз.
- `defender-protection [--report]`: Қорғау параметрлері мен танылған саясат беттері, тек оқу; құпия мәліметтер алынып тасталған; өзгеріссіз.
- `defender-scan Quick|Full [--execute] [--report]`: Әдепкі бойынша алдын ала қарау; бір айқын қорғалған Microsoft Defender сканерлеуі.
- `defender-scan-history [--report]`: Жылдам және толық сканерлеу уақыты мен мерзімі өткен күйі, тек оқу; құпия мәліметтер алынып тасталған; сканерлеусіз.
- `defender-scan-recover [--report]`: Басқа сканерлеуді бастамай салыстыру, тек оқу.
- `defender-threats [--report]`: Жиынтық қауіптер тарихы, ағымдағы белсенді белгілер мен қауіптілік идентификаторлары; құпия мәліметтер алынып тасталған; әрекетсіз.
- `firewall-enable --profile Domain|Private|Public [--profile ...] [--execute]`: Әдепкі бойынша алдын ала қарау; тек басқарылмайтын жергілікті профильдер.
- `firewall-enable-recover`: Күтудегі өзгерісті қайталамай тексереді.
- `firewall-events`: Windows брандмауэрінің ескерту, қате және маңызды оқиғаларының шектелген жұмыс тарихын оқиды.
- `firewall-logging`: Домендік, жеке және жалпы профильдердің трафикті журналға жазу конфигурациясын журналдарды ашпай оқиды.
- `firewall-rules`: Құпиялылыққа байланысты шектелген әрекет етуші ережелер мен саясат көздерінің сандарын оқиды.
- `firewall-service-events`: BFE және Windows Defender брандмауэрі үшін Қызметтерді басқару реттеушісінің нақты ақаулар тарихын оқиды.
- `privacy-clipboard-history on|off [--execute]`: Әдепкі бойынша алдын ала қарау; саясатты сақтай отырып, ағымдағы пайдаланушының нақты мәні.
- `privacy-clipboard-history-recover`: Үзілген өзгерісті қайталамай қайта тексереді.
- `privacy-clipboard-history-undo VERIFIED_JOURNAL [--execute]`: Алдыңғы мәнді қорғалған түрде қалпына келтіру.
- `privacy-plan --select Camera --select ClipboardSync`: Тек таңдауларды қарап шығу; ешқандай параметр өзгертілмейді.
- `privacy-setting KEY on|off [--execute]`: Әдепкі бойынша алдын ала қарау; саясатты сақтайтын ағымдағы пайдаланушы өзгерісі; жарамсыз кілттер қолдау көрсетілетін таңдауларды тізімдейді.
- `privacy-setting-recover KEY`: Үзілген өзгерісті қайталамай қайта тексереді.
- `privacy-setting-undo KEY VERIFIED_JOURNAL [--execute]`: Нақты мәнді қорғалған түрде қалпына келтіру.
- `security-check`: TPM, қауіпсіз жүктеу, виртуализация қорғаулары және UAC саясаты, тек оқу; JSON дәлелдері.

## Қызметтер

- `service-binaries`: Жергілікті қызмет екілік файлдарының бары және Authenticode күйі, тек оқу; жолдар алынып тасталған, жергілікті емес жолдарға қосылмайды.
- `service-check NAME [NAME ...] | service-check --all`: Қолдау көрсетілетін қызметтердің күйлері мен тәуелділік дәлелдері, тек оқу.
- `service-dependencies`: Тікелей тәуелділіктердің тұтастығын қарап шығу, тек оқу; қызметтер өзгертілмейді.
- `service-dlls`: Тіркелген қызмет DLL файлдарының бары және Authenticode күйі, тек оқу; жолдар алынып тасталған, жергілікті емес жолдарға қосылмайды.
- `service-events`: Қызмет ақауларының тарихы, тек оқу; шикі дәлелдері бар JSON.
- `time-events`: Windows уақыт қызметінің соңғы оқиғалар тарихы, тек оқу, JSON дәлелдерімен.
- `service-logons`: Қызмет тіркелгісінің сыныбы мен жұмыс үстелімен әрекеттесуді қарап шығу, тек оқу; тіркелгі сәйкестендіргіштері алынып тасталған.
- `service-path-quoting`: Қызметтің орындалатын файл жолдарындағы тырнақшаларды қарап шығу, тек оқу; толық жолдар мен аргументтер алынып тасталған.
- `service-recovery-policy`: Орнатылған қызметтердің қалпына келтіру әрекеттерінің қорытындысы, тек оқу; пәрмендер мен қайта жүктеу хабарлары алынып тасталған.
- `service-startup-config`: Іске қосу режимдерінің үйлесімділігін қарап шығу, тек оқу; қызметтер өзгертілмейді.
- `service-transitions`: Қызметтердің күтудегі күйлерін қайта бақылау, тек оқу; қызметпен әрекетсіз.
- `service-triggers`: Орнатылған қызметтердің триггерлерінің қорытындысы, тек оқу; триггер жүктемесі алынып тасталған; өзгеріссіз.

## Сақтау орны, файлдар және сақтық көшірме

- `backup-events`: VSS және volsnap тарихы; JSON дәлелдері; өзгеріссіз.
- `backup-service-events`: VSS, бағдарламалық көлеңкелі көшірме провайдері, Windows сақтық көшірмесі және блок деңгейіндегі механизмнің нақты ақаулар тарихын оқиды.
- `backup-summary`: Жергілікті Windows сақтық көшірме әрекеттерінің қорытындысы; сақтық көшірме өзгертілмейді.
- `cleanup --user-temp [--windows-temp] [--system-temp] [--shader-caches] [--browser-caches] [--office-caches] [--thumbnail-cache] [--icon-cache] [--error-reports] [--crash-dumps] [--windows-minidumps] [--delivery-optimization-cache] [--recycle-bin] [--days 7] [--max-files 100] [--json] [--execute]`: Әдепкі бойынша алдын ала қарау; Себет толығымен тазаланады немесе мүлде тазаланбайды, файл жасы ескерілмейді.

- `uefi-vendor PACK_PATH PNP|ACPI VENDOR_ID`: UEFI жергілікті тізілімінен нақты іздеу; желі сұрауынсыз және драйвер таңдаусыз.
- `usb-vendor PACK_PATH USB_HARDWARE_ID`: Нақты жергілікті пакеттен іздеу; желі сұрауынсыз және драйвер таңдаусыз.
- `vitals-check`: Windows, жабдық, тіркелгі, ресурс, батарея және физикалық диск лездік көшірмелері, тек оқу; JSON дәлелдері.
- `win32-code DECIMAL_OR_0xHEX`: Орнатылған Windows хабарларын офлайн іздеу.
- `workflows`: Орнатылған жұмыс ағындарының кілттері мен атауларын тізімдейді; сканерлеусіз және жөндеусіз.
