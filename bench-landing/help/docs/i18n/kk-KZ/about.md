# KillerBench туралы

KillerBench Steve the Killer жасаған, [Killer Tools отбасына](https://killertools.net) кіретін Windows диагностикасы, жөндеуі және қызмет көрсетуіне арналған жұмыс құралы. 0.1.0 нұсқасы әлі шығарылмаған. Оның жұмыс үстелі қолданбасы, Engine және CLI диагностикалық дәлелдер мен қолдау көрсетілетін жөндеу жұмыс ағындарын ортақ пайдаланады.

## Қолжетімділік және ауқым

Жалпыға қолжетімді KillerBench жүктеуі немесе Engine пакеті әлі жоқ. [Жүктеу және орнату](setup.html) ағымдағы Windows x64 мақсатын және Desktop Runtime талаптарын сипаттайды. Жергілікті жөндеуді тексеру әлі жүріп жатыр; құралдың болуы әр ақаудың, үзілістің немесе Windows конфигурациясының тексерілгенін дәлелдемейді.

## Құпиялылық және сыртқы қызметтер

Диагностика мен журнал талдауы ЖИ қызметінсіз немесе KillerBench тіркелгісінсіз жергілікті түрде орындалады. Журналдар мен сақталған дәлелдер жергілікті тіркелгінің `%LOCALAPPDATA%\KillerBench` қалталарын пайдаланады. Таңдалған әрекеттер Windows Update, бағдарламаларды жүктеу қызметтері, каталогтар немесе басқа аталған мекенжайларға қосылуы мүмкін. Іске қосылғандағы жаңартуды тексеру GitHub-қа, ал білім жаңартулары мен MCP орнатушысының беті өздерінің бапталған қызметтеріне қосылады. MCP пайдаланатын ЖИ клиенті қайтарылған анықтамалық нәтижені алуы мүмкін.

Бұл веб-сайт тақырып пен екпін түсі таңдауларын браузердің жергілікті жадында сақтайды. Оның нұсқаулықтары компьютеріңізде диагностиканы іске қоспайды. Шикі журналдарда, импортталған файлдарда және экспортталған дәлелдерде компьютер атаулары, тіркелгілер, жолдар немесе құпия бастапқы мәтін болуы мүмкін. Бөліспес бұрын оларды қарап шығыңыз; жалпыға ашық есепке қалпына келтіру кілттерін, тіркелгі деректерін немесе тұтынушы деректерін қоспаңыз.

## Қолдау

Жоба туралы ақпарат жалпыға ашық репозиторийде қолжетімді. Қолдау алу үшін [автордың веб-сайтында](https://thekiller.net) жарияланған байланыс ақпаратын пайдаланыңыз; қолданба нұсқасын, Windows құрастырмасын, нақты құралды, күтілген нәтижені және байқалған нәтижені көрсетіңіз. Жіберер алдында дәлелдерді қарап шығып, құпия бөліктерін алып тастаңыз және тұтынушы ақпараты үшін бекітілген жеке арнаны пайдаланыңыз. Белгісіз жөндеу нәтижесі үшін журналдарды сақтаңыз.
