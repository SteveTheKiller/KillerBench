# Желі мен интернет мәселелерін түзету

Мұны компьютерде интернет болмағанда, серверге немесе атауға қол жеткізе алмағанда немесе қосылым үнемі үзілгенде пайдаланыңыз. KillerBench адаптерді, мекенжайды, шлюзді, DNS пен брандмауэрді ретімен тексереді және жаңа дәлелдер қажеттілікті растағанда ғана жалға алуды жаңартады немесе қызметті іске қосады.

## Қосылымды тексеру

1. **Желі** бөлімін ашып, **Желі** таңдаңыз.
2. Нақты бір нәрсені тексеру үшін **Хост атауын іздеу (міндетті емес)** немесе **TCP мақсаты (міндетті емес)** және **TCP порты** өрістерін толтырыңыз. Тек жергілікті конфигурацияны тексеру үшін оларды бос қалдырыңыз. Қолданба деректері жіберілмейді.
3. Желі баяу болса, **Әр іздеу немесе қосылым үшін күту уақыты (секунд)** орнатыңыз.
4. **Расталған мәселелерді автоматты жөндеу** өшірулі қалдырып, **Диагнозды іске қосу** түймесін басыңыз.
5. Есепті оқыңыз. Ол жоқ мекенжайды, жоқ немесе қолжетімсіз шлюзді, DNS конфигурациясы мәселелерін, прокси параметрлерін, брандмауэр профильдерінің сәйкессіздігін және сәтсіз іздеуді немесе қосылымды бөліп көрсетеді және әрқайсысы үшін келесі қадамды береді.

Шлюзден келген жауап интернетке қатынас бар екенін дәлелдемейді, ал бапталған шешуші арқылы сәтсіз іздеу сайттың істемей тұрғанын білдірмейді.

## Есеп тапқанды жөндеу

1. **Желі** құралын **Расталған мәселелерді автоматты жөндеу** қосулы күйде қайта іске қосыңыз. Ол қосулы DNS клиенті, DHCP клиенті, SMB клиенті, желі орнын анықтау, желілер тізімі және IP көмекшісі қызметтерін іске қоса алады және жарамды IPv4 мекенжайы жоқ қосылған физикалық DHCP адаптерлерінің жалға алуын жаңарта алады.
2. Жаңарту кезінде қосылым қысқа уақытқа үзілуі мүмкін. Статикалық мекенжайлар мен виртуалды адаптерлер ешқашан өзгертілмейді.
3. Кэштегі бір қате атау үшін бәрін тазаламай, сол нақты хостқа арналған DNS кэшін тазалауды пайдаланыңыз.

Маршруттар, Hosts жазбалары, DNS серверлері, брандмауэр ережелері, Winsock провайдерлері мен желі профильдері әрқашан сақталады.

## Сымсыз желі, сымды кіру және прокси

- **Сымсыз желі** адаптер мен WLAN AutoConfig қызметін тексереді және қызмет тоқтап тұрса, оны іске қоса алады.
- **Сымды аутентификация (802.1X)** портта кіруді талап ететін желілер үшін Wired AutoConfig қызметіне дәл солай жасайды.
- **WinHTTP автоматты прокси** компьютер мен ағымдағы тіркелгі үшін сақталған прокси параметрлерін көрсетеді. KillerBench диагностика кезінде ешқашан PAC URL мекенжайын жүктемейді және прокси параметрлерін өзгертпейді.

## Пәрмен жолынан

```powershell
killerbench-cli workflow network --host example.com --tcp example.com 443
killerbench-cli dns-check example.com --timeout-seconds 5
killerbench-cli tcp-check fileserver 445
killerbench-cli dhcp-renew
killerbench-cli dns-cache example.com --execute
```

[workflow](cli.html#cmd-workflow), [dns-check](cli.html#cmd-dns-check), [tcp-check](cli.html#cmd-tcp-check), [dhcp-renew](cli.html#cmd-dhcp-renew) және [dns-cache](cli.html#cmd-dns-cache) қараңыз.
