# Командний рядок

`killerbench-cli` запускає той самий Engine, що й настільний застосунок, із PowerShell або віддаленої консолі. Кожна команда, яка може змінити комп'ютер, за замовчуванням показує попередній перегляд і потребує явного прапорця, наприклад `--execute`, перш ніж діяти. Команди виводять дані JSON у стандартний вивід, а перебіг у стандартний потік помилок.

Покрокові посібники: [Запуск KillerBench зі скриптів](use-the-cli.html).

Код завершення 0 означає, що попередній перегляд чи підтверджений результат успішні, 1 означає помилку запуску, введення чи журналу, 2 означає, що аргументи не розпізнано, 3 означає заблоковано, невдало чи не підтверджено, 4 означає, що процедурі потрібен перезапуск перед перевіркою, а 130 означає, що ви її зупинили.

Запустіть `killerbench-cli` без аргументів, щоб вивести цей список на власному комп'ютері.

## Оновлення й обслуговування

- `bits-job-review JOB_GUID [--all-users] [--observe]`: Точний огляд передавання або спостереження за двома знімками; без повторної спроби.
- `bits-jobs [--all-users]`: Стани, власники й кількість байтів завдань BITS; без змін передавань.
- `bits-retry JOB_GUID [--execute]`: Попередній перегляд за замовчуванням; явна повторна спроба точного завдання без тверджень про завершення застосунком.
- `bits-retry-recover JOB_GUID`: Два знімки лише для читання; архівує стабільні результати без нової спроби.
- `component-repair-source`: Керована політика джерела виправлень DISM і конфлікти; без змін.
- `delivery-optimization`: Стан служби оптимізації доставки лише для читання; дані JSON.
- `delivery-optimization-activity`: Обмежені з міркувань конфіденційності поточні кількості завдань і загальні обсяги байтів; без ідентичностей передавань і змін.
- `delivery-optimization-policy`: Класичні параметри й параметри Policy CSP лише для читання; конфіденційні значення й ідентичності постачальників виключено.
- `feature-service-events`: Читає точну історію збоїв служб часу, Search, WMI, журналу подій і звуку.
- `feature-update-policy`: Цільовий випуск, відкладання, призупинення й політика запобіжників лише для читання; дані JSON.
- `pending-file-operations`: Обмежений з міркувань конфіденційності підсумок очікувальних файлових операцій лише для читання; дані JSON.
- `restart-check`: Джерела очікуваного перезавантаження лише для читання; дані JSON.
- `servicing-logs`: Обмежений аналіз найновіших журналів CBS, текстових і стиснених архівів CBS, журналів DISM і програми встановлення Windows; без виправлень.
- `servicing-monitor [--refresh 1..60] [--samples 1..120] [--skip-events] [--skip-history] [--skip-services] [--skip-restart] [--skip-setup] [--skip-compatibility] [--skip-readiness] [--skip-transfers] [--skip-delivery-optimization] [--skip-installer] [--skip-scheduled-task]`: Знімки активності обслуговування лише для читання.
- `servicing-service-events`: Точна історія збоїв ланцюжка обслуговування Windows Update лише для читання.
- `servicing-service-states`: Поточний стан шести служб ланцюжка обслуговування Windows Update лише для читання.
- `setup-code DECIMAL_OR_0xHEX`: Задокументований довідник кодів результату програми встановлення Windows; без перевірки комп'ютера й виправлень.
- `update-applicability`: Дані про випуск, збірку й архітектуру Windows лише для читання.
- `update-cache`: Обмежені загальні обсяги кешу SoftwareDistribution лише для читання; без імен файлів.
- `update-code DECIMAL_OR_0xHEX`: Задокументований довідник кодів результату Windows Update; без перевірки комп'ютера й виправлень.
- `update-context`: Дані про поточне підвищення прав і сеанс робочого стола лише для читання; без ідентифікаторів облікових записів.
- `update-engine-files`: Дані про наявність, версію й підпис власного модуля Windows Update лише для читання.
- `update-events`: Історія клієнта Windows Update за останні сім днів лише для читання; JSON із необробленими даними.
- `update-followup DECIMAL_OR_0xHEX`: Свіжа діагностика лише для читання, вибрана за задокументованим кодом результату Windows Update.
- `update-history`: Найновіші 100 результатів операцій Windows Update лише для читання; дані JSON.
- `update-plan --select GUID:REVISION [--drivers] [--no-software] [--allow-restart-required] [--json] [--execute]`: Повторюйте `--select`; попередній перегляд за замовчуванням.
- `update-policy`: Керована політика Windows Update лише для читання; дані JSON.
- `update-policy-surfaces`: Дані про поверхні конфігурації класичних параметрів і Policy CSP лише для читання; значення й ідентичності постачальників виключено.
- `update-recover`: Перевіряє очікуване оновлення; ніколи не встановлює його й не повторює спроб.
- `update-restart-policy`: Терміни відповідності, пільгові періоди, придушення перезавантаження й поведінка сповіщень лише для читання.
- `update-search [--drivers] [--no-software] [--filter TITLE] [--downloaded-only] [--classification GUID] [--product GUID]`: Виявлення й збіги у форматі JSON; без встановлення.
- `update-service-events`: Точна історія збоїв служби Windows Update лише для читання.
- `update-service-files`: Дані про реєстрацію й підпис точної бібліотеки DLL служби Windows Update лише для читання.
- `update-services`: Реєстрації служб Windows Update лише для читання; дані JSON.
- `update-store-reset [--source Configured|WindowsUpdate|MicrosoftUpdate] [--drivers] [--no-software] [--execute]`: Потребує свіжого пошуку; попередній перегляд за замовчуванням; зберігає старе сховище.
- `update-store-reset-recover`: Узгоджує підготовлене скидання сховища, не повторюючи його.
- `windows-capabilities`: Стани онлайн-можливостей Windows лише для читання; результат JSON.
- `windows-update-task`: Точний стан завдання Scheduled Start та історія виконання лише для читання; без запуску завдань і операцій оновлення.

## BitLocker і TPM

- `bitlocker-auto-unlock DRIVE: [--execute]`: Попередній перегляд за замовчуванням; вмикає автоматичне розблокування зашифрованого тому даних.
- `bitlocker-auto-unlock-recover`: Перевіряє перерваний запит автоматичного розблокування, не повторюючи його.
- `bitlocker-backup DRIVE: PROTECTOR_GUID FILE_PATH [--execute]`: Попередній перегляд за замовчуванням; лише новий файл резервної копії відновлення.
- `bitlocker-backup-recover DRIVE: PROTECTOR_GUID FILE_PATH`: Перевіряє перервану резервну копію, не записуючи її знову.
- `bitlocker-decrypt DRIVE: [--execute --confirm-unprotected]`: Попередній перегляд за замовчуванням; запускає розшифрування, наприклад перед повторним шифруванням потрібним методом.
- `bitlocker-decrypt-recover`: Перевіряє перерваний запит розшифрування, не повторюючи його.
- `bitlocker-encrypt DRIVE: RECOVERY_PROTECTOR_GUID NEW_BACKUP_FILE [--encryption XtsAes128] [--used-space-only] [--execute]`: Попередній перегляд за замовчуванням; потребує наявних засобів захисту TPM і відновлення.
- `bitlocker-encrypt-recover`: Перевіряє стан очікуваного перетворення, не повторюючи запиту.
- `bitlocker-escrow DRIVE: RECOVERY_PROTECTOR_GUID ad|entra [--execute]`: Попередній перегляд за замовчуванням; створює резервну копію наявного пароля відновлення в Active Directory або Microsoft Entra ID.
- `bitlocker-plan --volume C: --operation Encrypt --encryption XtsAes256 --backup EntraId`: Лише попередній перегляд параметрів.
- `bitlocker-protector-add DRIVE: tpm|recovery [--execute]`: Попередній перегляд за замовчуванням; додає один засіб захисту TPM чи пароль відновлення; пароль ніколи не виводиться.
- `bitlocker-protector-recover`: Перевіряє перерваний запит засобу захисту, не повторюючи його.
- `bitlocker-protectors DRIVE:`: Лише ідентичності й типи засобів захисту; без паролів відновлення.
- `bitlocker-resume DRIVE: [--execute]`: Попередній перегляд за замовчуванням; лише точний повністю зашифрований призупинений том.
- `bitlocker-resume-recover`: Перевіряє стан очікуваного захисту, не повторюючи запиту.

## Безпека й конфіденційність

- `certificate-chains`: Локальна перевірка ланцюжка довіри лише за кешем для особистих сертифікатів, лише читання; без перевірки відкликання й завантажень.
- `defender-overview [--report]`: Огляд захисту, часу сканування й зведених загроз лише для читання; без дій.
- `defender-protection [--report]`: Параметри захисту й розпізнані поверхні політики лише для читання; конфіденційні подробиці виключено; без змін.
- `defender-scan Quick|Full [--execute] [--report]`: Попередній перегляд за замовчуванням; одне явне захищене сканування Microsoft Defender.
- `defender-scan-history [--report]`: Час швидкого й повного сканування та стан прострочення лише для читання; конфіденційні подробиці виключено; без сканування.
- `defender-scan-recover [--report]`: Узгодження лише для читання без запуску нового сканування.
- `defender-threats [--report]`: Зведена історія загроз, поточні активні ознаки й ідентифікатори серйозності; конфіденційні подробиці виключено; без дій.
- `firewall-enable --profile Domain|Private|Public [--profile ...] [--execute]`: Попередній перегляд за замовчуванням; лише некеровані локальні профілі.
- `firewall-enable-recover`: Перевіряє очікувану зміну, не повторюючи її.
- `firewall-events`: Читає обмежену робочу історію попереджень, помилок і критичних подій брандмауера Windows.
- `firewall-logging`: Читає конфігурацію журналювання трафіку для профілів домену, приватного й загального, не відкриваючи журналів.
- `firewall-rules`: Читає обмежені з міркувань конфіденційності кількості чинних правил і джерел політики.
- `firewall-service-events`: Читає точну історію збоїв диспетчера керування службами для BFE і брандмауера Windows Defender.
- `privacy-clipboard-history on|off [--execute]`: Попередній перегляд за замовчуванням; точне значення поточного користувача зі збереженням політики.
- `privacy-clipboard-history-recover`: Повторно перевіряє перервану зміну, не повторюючи її.
- `privacy-clipboard-history-undo VERIFIED_JOURNAL [--execute]`: Захищене відновлення попереднього значення.
- `privacy-plan --select Camera --select ClipboardSync`: Лише огляд вибору; параметри не змінюються.
- `privacy-setting KEY on|off [--execute]`: Попередній перегляд за замовчуванням; зміна для поточного користувача зі збереженням політики; для недійсних ключів виводяться підтримувані варіанти.
- `privacy-setting-recover KEY`: Повторно перевіряє перервану зміну, не повторюючи її.
- `privacy-setting-undo KEY VERIFIED_JOURNAL [--execute]`: Захищене відновлення точного значення.
- `security-check`: TPM, безпечне завантаження, захист віртуалізації й політика UAC лише для читання; дані JSON.

## Служби

- `service-binaries`: Наявність локальних двійкових файлів служб і стан Authenticode лише для читання; шляхи виключено, нелокальні шляхи не опитуються.
- `service-check NAME [NAME ...] | service-check --all`: Стани підтримуваних служб і дані про залежності лише для читання.
- `service-dependencies`: Огляд цілісності прямих залежностей лише для читання; без змін служб.
- `service-dlls`: Наявність зареєстрованих бібліотек DLL служб і стан Authenticode лише для читання; шляхи виключено, нелокальні шляхи не опитуються.
- `service-events`: Історія збоїв служб лише для читання; JSON із необробленими даними.
- `time-events`: Нещодавня історія подій служби часу Windows лише для читання з даними JSON.
- `service-logons`: Огляд класу облікового запису служби й взаємодії з робочим столом лише для читання; ідентичності облікових записів виключено.
- `service-path-quoting`: Огляд лапок у шляхах до виконуваних файлів служб лише для читання; повні шляхи й аргументи виключено.
- `service-recovery-policy`: Підсумок дій відновлення встановлених служб лише для читання; команди й повідомлення про перезавантаження виключено.
- `service-startup-config`: Огляд узгодженості режимів запуску лише для читання; без змін служб.
- `service-transitions`: Повторне спостереження очікуваних станів служб лише для читання; без дій зі службами.
- `service-triggers`: Підсумок тригерів установлених служб лише для читання; вміст тригерів виключено; без змін.

## Сховище, файли й резервне копіювання

- `backup-events`: Історія VSS і volsnap; дані JSON; без змін.
- `backup-service-events`: Читає точну історію збоїв VSS, програмного постачальника тіньових копій, архівації Windows і модуля архівації на рівні блоків.
- `backup-summary`: Підсумок локальних операцій архівації Windows; без змін резервного копіювання.
- `cleanup --user-temp [--windows-temp] [--system-temp] [--shader-caches] [--browser-caches] [--office-caches] [--thumbnail-cache] [--icon-cache] [--error-reports] [--crash-dumps] [--windows-minidumps] [--delivery-optimization-cache] [--recycle-bin] [--days 7] [--max-files 100] [--json] [--execute]`: Попередній перегляд за замовчуванням; кошик очищається повністю, а вік не застосовується.
- `disk-cleanup-task`: Точний стан завдання й історія виконання лише для читання; без запуску завдань і очищення.
- `disk-diagnostic`: Зіставляє точні завдання діагностики дисків та історію подій; без дій із завданнями чи дисками.
- `disk-diagnostic-tasks`: Точна історія завдань збирача й розв'язувача лише для читання; без дій із завданнями чи дисками.
- `disk-quotas`: Стандартні параметри й стан квот для кожного тому лише для читання; ідентичності користувачів виключено; без змін.
- `file-history-events`: Кількості попереджень і помилок історії файлів з урахуванням конфіденційності; без змін.
- `file-history-status`: Стан захисту історії файлів поточного облікового запису; без змін.
- `search-index-rebuild [--execute]`: Попередній перегляд за замовчуванням; зберігає попередній індекс і перевіряє свіжий стан.
- `search-index-rebuild-recover`: Узгодження лише для читання без повторення команд виправлення.
- `storage-check DRIVE_LETTER`: Фіксована перевірка NTFS лише для читання; результати JSON і перебіг у реальному часі.
- `storage-events`: Історія сховища лише для читання; JSON із необробленими даними.
- `storage-jobs`: Зведений стан і перебіг завдань модуля Storage лише для читання; JSON; без змін.
- `storage-reliability`: Лічильники температури, зношення й операцій введення-виведення лише для читання; JSON; без виправлень.
- `storage-repair DRIVE: SpotFix|OfflineScanAndFix [--allow-dismount] [--backup-confirmed] [--execute]`: Попередній перегляд за замовчуванням; виконання потребує підтвердження резервної копії; для системних томів планується під час перезапуску.
- `storage-repair-plan DRIVE: SpotFix|OfflineScanAndFix [--allow-dismount]`: Лише попередній перегляд; без виправлення й планування.
- `storage-repair-recover`: Перевіряє завершене чи заплановане виправлення файлової системи, не повторюючи його.
- `storage-repair-review DRIVE: SpotFix|OfflineScanAndFix [--allow-dismount]`: Збирає й прив'язує поточні дані; без виправлення й планування.
- `storage-sense-policy`: Розпізнана політика очищення комп'ютера лише для читання; параметри користувачів і ідентичності файлів виключено.
- `storage-sense-task`: Точний стан завдання й історія виконання лише для читання; без запуску завдань і очищення.
- `storage-service-events`: Читає точну історію збоїв служби сховища, оптимізації дисків, VSS і програмного постачальника тіньових копій.
- `volume-capacity DRIVE:`: Доступне місце лише для читання з даними JSON.
- `volume-dirty DRIVE:`: Стан біта забруднення лише для читання; без виправлення й перезапуску.
- `volume-optimize DRIVE: [Recommended|ReTrim|Defragment] [--execute]`: Аналіз лише для читання за замовчуванням; потрібні точний справний том і сумісний носій.
- `volume-optimize-recover`: Перевіряє очікувану завершену операцію, не повторюючи її.
- `vss-providers`: Імена, версії й типи постачальників VSS лише для читання; ідентифікатори виключено; без змін реєстрацій.
- `vss-writers`: Повідомлені стани модулів запису; тлумачення англомовного виводу; без скидання.

## Друк

- `print-events`: Історія PrintService Admin за останні сім днів лише для читання; дані JSON.
- `print-extension-files`: Підсумок наявності й підписів двійкових файлів обробників і моніторів друку лише для читання; повні шляхи виключено.

- `knowledge-set CONTEXT CODE PACK_PATH [PACK_PATH ...]`: Розв'язує одну точну ідентичність у до 32 пакетах; конфлікти ніколи не вибираються.
- `knowledge-status CONFIG_JSON STORAGE_ROOT`: Перевіряє кожну налаштовану встановлену базу даних; без завантаження й активації.
- `knowledge-update CONFIG_JSON STORAGE_ROOT`: Отримує й атомарно активує підписані кандидати баз даних із налаштованих кінцевих точок HTTPS.
- `open <file.kbench> [--json]`: Знову відкриває збережений знімок і повторно оцінює його за встановленими правилами.
- `scan --output <new-file.kbench> [--json]`: Знімок Windows Update лише для читання, збережений у новий файл.
- `validation-coverage RECORD.json [...]`: Підсумовує дані нативної перевірки на ВМ для поточної версії; без діагностики й виправлень.
- `validation-plan [--recipe RECIPE_ID | --workflow WORKFLOW]`: План сценаріїв для одноразових ВМ лише для читання; без діагностики й виправлень.
- `validation-record RECORD.json`: Перевіряє один обмежений запис даних нативної перевірки на ВМ; без діагностики й виправлень.
- `validation-report OUTPUT.html|OUTPUT.txt RECORD.json [...] [--theme THEME] [--accent ACCENT] [--overwrite]`: Локальний звіт про охоплення ВМ для поточної версії.
- `workflow WORKFLOW --set KEY=VALUE [--set KEY=VALUE ...] [--report OUTPUT.html|OUTPUT.txt] [--json]`: Виконує перевірений спільний план параметрів лише для читання.
- `workflow app-packages [--all-users] [--include-provisioned] [--json]`: Лише інвентаризація.
- `workflow common-problems --scope NAME [--scope NAME ...] [--report OUTPUT.html|OUTPUT.txt] [--json]`: Журнал вузько спрямованої діагностики; без виправлень.
- `workflow computer-name --name PROPOSED_NAME [--json]`: Лише огляд із записом у журнал.
- `workflow installer [--product-code {PRODUCT-CODE}] [--auto-repair] [--json]`: Необов'язковий точний стан продукту включається до журналу.
- `workflow network [--host HOST] [--tcp HOST PORT] [--auto-repair] [--json]`: Необов'язкова діагностика вибраної цілі включається до журналу.
- `workflow storage [--volume D:] [--json]`: Перевірка файлової системи лише для читання із записом у журнал.
- `workflow-journal FILE.json`: Історичний вміст; код 0 означає успішне читання, а не справність.
- `workflow-options [WORKFLOW [--set KEY=VALUE ...]]`: Показує чи перевіряє незалежні від хоста елементи керування; без сканування й виправлень.
- `workflow-report JOURNAL.json OUTPUT.html|OUTPUT.txt [--include-repairs] [--theme THEME] [--accent ACCENT] [--overwrite]`: Лише історичний звіт; команди не виконуються.

## Інші команди

- `<analyze|investigate> <text-log-path> [--json]`: Аналізує локальні текстові дані.
- `adapter-bindings`: Підсумок прив'язок основних протоколів лише для читання; дані JSON.
- `adapter-statistics`: Лічильники байтів, помилок і відкинутих пакетів адаптерів лише для читання; дані JSON.
- `application-events`: Нещодавні помилки журналу «Застосунок», згруповані кількості й дані JSON лише для читання.
- `applocker-policy`: Чинні режими збирання й зведені кількості правил лише для читання; подробиці правил виключено; без змін.
- `common-check [--scope NAME ...]`: Усі діагностичні області за замовчуванням; лише вибрані області, якщо їх указано; JSON лише для читання.
- `delete-notifications`: Конфігурація сповіщень про видалення для NTFS і ReFS лише для читання; JSON; без оптимізації й зміни параметрів.
- `diagnostic-scopes [--all]`: Показує 11 рекомендованих груп результатів або всі 49 областей лише для читання; без збирання.
- `full-scan --scope NAME [--scope NAME ...] [--report OUTPUT.html|OUTPUT.txt] [--json]`: Журнал вузько спрямованої діагностики; без виправлень.
- `full-scan [--recipes ID[,ID]] [--auto-repair] [--report OUTPUT.html|OUTPUT.txt] [--json]`: Усі діагностичні області; без виправлень, якщо явно не вказано `--auto-repair`.
- `gateway-check`: Обмежені перевірки ICMP точних налаштованих стандартних наступних вузлів; без сканування адрес.
- `infrastructure-service-events`: Читає один обмежений точний знімок збоїв служб підключення, віддаленого керування, сповіщень і основних служб.
- `investigate-batch FILE [FILE ...]`: До 12 файлів; JSON Lines; код 3 для невдалих чи часткових імпортів.
- `licensing-check`: Стан активації Windows без ключів продукту лише для читання; дані JSON.
- `mac-vendor PACK_PATH MAC_ADDRESS`: Локальний пошук у пакеті за найдовшим префіксом; без мережних запитів.
- `ncsi-policy`: Політика класифікації підключення Windows лише для читання; адреси перевірок виключено.
- `neighbor-cache`: Обмежені з міркувань конфіденційності дані про доступність сусідів лише для читання; результат JSON.
- `ntfs-self-healing DRIVE:`: Конфігурація онлайн-виправлення NTFS для вибраного тому лише для читання; без виправлення й зміни параметрів.
- `pagefile-check`: Підсумок керування, виділення й використання файлу підкачки лише для читання; повні шляхи виключено.
- `pci-vendor PACK_PATH PCI_HARDWARE_ID`: Точний локальний пошук у пакеті; без мережних запитів і вибору драйвера.
- `physical-disks`: Поточний стан справності, роботи, носія, шини й використання лише для читання; JSON; без виправлень.
- `platform-service-events`: Читає один обмежений точний знімок збоїв служб застосунків, ідентичності, профілів і підтримки пристроїв.
- `previous-windows [--execute --backup-confirmed]`: Попередній перегляд за замовчуванням; остаточно видаляє можливість відкату Windows через DISM.
- `previous-windows-recover`: Узгодження лише для читання без повторення видалення відкату.
- `provisioned-packages`: Пакети, підготовлені для нових користувачів у локальній Windows; без видалення.
- `recipes [WORKFLOW]`: Показує встановлені визначення або залежності й обмеження конкретної процедури; без виконання.
- `repair <dism|sfc> [--execute]`: Попередній перегляд за замовчуванням.
- `reserved-storage`: Стан зарезервованого сховища онлайн-Windows лише для читання; дані JSON.
- `restore-point DESCRIPTION [ModifySettings|ApplicationInstall|DeviceDriverInstall] [--execute]`: Попередній перегляд за замовчуванням; створює одну точку після свіжих перевірок.
- `restore-point-recover`: Перевіряє очікуваний запит, не створюючи іншої точки.
- `schedule-preview daily|weekly|monthly YYYY-MM-DD HH:mm TIME_ZONE_ID [Mon,Tue|1,15|last]`: Лише попередній перегляд.
- `shadow-copies`: Поточні стани й атрибути знімків VSS лише для читання; ідентичності виключено; без змін знімків.
- `shadow-storage`: Виділення й заповненість диференціальної області VSS лише для читання; JSON; без зміни розміру й дій зі знімками.
- `uac-policy`: Увімкнення UAC і політика запитів підвищення прав лише для читання; без даних облікових записів і облікових даних.
- `uefi-vendor PACK_PATH PNP|ACPI VENDOR_ID`: Точний пошук у локальному реєстрі UEFI; без мережних запитів і вибору драйвера.
- `usb-vendor PACK_PATH USB_HARDWARE_ID`: Точний локальний пошук у пакеті; без мережних запитів і вибору драйвера.
- `vitals-check`: Знімки Windows, обладнання, облікового запису, ресурсів, акумулятора й фізичних дисків лише для читання; дані JSON.
- `win32-code DECIMAL_OR_0xHEX`: Автономний пошук повідомлень установленої Windows.
- `workflows`: Показує ключі й назви встановлених процедур; без сканування й виправлень.
