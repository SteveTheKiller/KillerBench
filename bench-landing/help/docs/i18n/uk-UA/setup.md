# Завантаження й налаштування

KillerBench 1.0.0 ще не випущено. Загальнодоступного пакета чи завантаження KillerBench поки немає. На цій сторінці описано поточні вимоги до пакета, щоб ви могли підготуватися, не завантажуючи неофіційну копію.

## Windows і середовище виконання

- Поточна ціль публікації: **Windows x64**. Поточна база нативної перевірки: Windows 11 x64. Нативних дистрибутивів для ARM64, x86 і Windows Server немає.
- KillerBench постачається у двох варіантах. Інсталятор **залежить від платформи** й потребує **.NET Desktop Runtime 10 for Windows x64**. Звичайні .NET Runtime, ASP.NET Core Runtime і .NET Framework не надають WPF. Портативна версія містить власне середовище виконання й не потребує окремого встановлення. Для інструмента командного рядка `killerbench-cli.exe` потрібне .NET 10 Runtime for Windows x64. SDK потрібен для розробки, а не для звичайного використання.
- Використовуйте версію Windows, яку підтримує [.NET 10 on Windows](https://learn.microsoft.com/en-us/dotnet/core/install/windows). Підтримка середовища виконання не означає, що виправлення KillerBench перевірено в кожному підтримуваному випуску чи збірці. Охоплення Windows 10 ще не завершено, а її підтримувані випуски обмежено поточними вимогами життєвого циклу Microsoft.
- Отримуйте Desktop Runtime лише зі [сторінки завантаження .NET 10 від Microsoft](https://dotnet.microsoft.com/en-us/download/dotnet/10.0), вибравши **.NET Desktop Runtime**, **Windows**, **x64**. Дотримуйтеся правил установлення програм, прийнятих у вашій організації.

Якщо доступна команда `dotnet`, команда `dotnet --list-runtimes` має показати `Microsoft.WindowsDesktop.App 10.0.x` для установки x64. Середовище виконання, встановлене лише для іншої архітектури, не підходить для пакета інсталятора x64.

## Коли пакет буде опубліковано

1. Використовуйте офіційне завантаження за посиланням із цього сайту. Посилання на завантаження KillerBench поки не активне.
2. Прочитайте вимоги цього пакета, [ліцензію GPLv3](../license.txt), інструкції щодо відповідного вихідного коду, додані повідомлення третіх сторін, а також відомості про підпис і контрольну суму. Саме лише ім'я файлу не підтверджує справжності.
3. Запустіть інсталятор для поточного облікового запису або, після запиту на підвищення прав, для всіх користувачів. Він додає ярлик у меню «Пуск», необов'язковий ярлик на робочому столі та запис у списку встановлення й видалення програм. Портативна версія працює без установлення.
4. Запустіть KillerBench під своїм звичайним обліковим записом і виконайте кроки зі сторінки [Перша діагностика](first-run.html). Помилки доступу під час діагностики залишаються видимими; підвищення прав є окремим свідомим вибором.

Не обходьте попереджень безпеки Windows, щоб запустити неперевірену копію. Перш ніж вибрати будь-яку дію, що змінює комп'ютер, створіть актуальну резервну копію.

Під час запуску KillerBench перевіряє на GitHub наявність новішого стабільного випуску й запитує дозвіл перед установленням. Завантаження має збігатися з опублікованою контрольною сумою SHA-256. Вимкнути перевірку можна параметром **Перевіряти оновлення під час запуску** в розділі «Про програму».

## Поточні обмеження

Поточна збірка має дванадцять розділів, діагностику лише для читання, звіти та окремо вибирані виправлення. Нативна перевірка виправлень ще триває. Робочий інтерфейс, успішна збірка чи результат тестового набору не підтверджують поведінки виправлення на реальному комп'ютері. Див. [Як зміни залишаються безпечними](safety.html#development-status).

Ілюстративна консоль на головній сторінці показує синтетичний вивід. Остаточні знімки екрана застосунку та перший загальнодоступний пакет ще не готові.

## Вихідний код, ліцензія та підтримка

KillerBench поширюється за ліцензією GPLv3. Інструкції з надання вихідного коду й дозволи на шрифти третіх сторін для першого загальнодоступного пакета ще не готові. Відомості про доступність вихідного коду, повідомлення про поширення, конфіденційність даних і підтримку наведено на сторінці [Про KillerBench](about.html). [Посібник з Engine](../engine/) призначено для розробників з авторизованою копією вихідного коду; він не означає, що загальнодоступний пакет Engine існує.
