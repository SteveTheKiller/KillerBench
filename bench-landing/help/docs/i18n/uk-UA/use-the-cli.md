# Запуск KillerBench зі скриптів

Використовуйте командний рядок, коли дані KillerBench потрібні у скрипті, завданні RMM або віддаленій консолі. `killerbench-cli` запускає той самий Engine, що й настільний застосунок, і виводить JSON.

## Початок роботи

1. Відкрийте PowerShell у папці, де розміщено `killerbench-cli.exe`, або додайте цю папку до шляху.
2. Виконайте `killerbench-cli help`, щоб вивести всі команди з їхніми межами безпеки.
3. Виконайте `killerbench-cli diagnostic-scopes`, щоб побачити 11 рекомендованих діагностичних груп.

## Запуск перевірки та збереження звіту

```powershell
killerbench-cli full-scan --report C:\Reports\scan.html --json
```

`full-scan` виконує лише діагностику й відхиляє `--auto-repair`. Якщо потрібна конкретна дія, використовуйте окрему процедуру виправлення. `--report` записує той самий тематичний звіт, який експортує застосунок. Використовуйте `--scope`, щоб перевірити лише деякі області, і `common-check` для об'єднаного JSON без журналу процедури.

## Коди завершення

| Код | Значення |
| --- | --- |
| 0 | Попередній перегляд або підтверджений результат виконано успішно. |
| 1 | Команду зупинила помилка запуску, введення чи журналу. |
| 2 | Аргументи не розпізнано. |
| 3 | Заблоковано, помилка або не підтверджено. |
| 4 | Процедурі потрібне перезавантаження перед перевіркою. |
| 130 | Ви зупинили виконання. |

Код 0 у команди лише для читання означає, що вона виконалася, а не що комп'ютер справний. Результати читайте в JSON.

## Внесення зміни

Кожна команда, що може змінити комп'ютер, за замовчуванням виконує попередній перегляд. Прочитайте попередній перегляд, а потім виконайте ту саму команду з `--execute`. Якщо запит перервався, виконайте відповідну команду `-recover`; вона повідомить фактичний результат і ніколи не повторить зміну.

```powershell
killerbench-cli dhcp-renew
killerbench-cli dhcp-renew --execute
killerbench-cli dhcp-renew-recover
```

## Повторне відкриття старих результатів

```powershell
killerbench-cli workflow-journal C:\Users\me\AppData\Local\KillerBench\journal.json
killerbench-cli workflow-report journal.json report.html --include-repairs
```
