Қалай пайдалану керек

Әр бөлім мен құрал: не істейді және жиі кездесетін жұмыстарды қадам бойынша қалай орындауға болады.

Ашу үшін жолды басыңыз. KillerBench-тің ішкі жұмысы туралы Техникалық бетінен оқыңыз.

Осы жерден бастаңыз

KillerBench техниктерге арналған Windows диагностикасы мен жөндеу құралы. Ол әуелі компьютерді тексереді, тапқанын әр қорытындының артындағы дәлелмен түсіндіреді және нақты түзетуді таңдап, оны растағанда ғана Windows-ты өзгертеді.

KillerBench әзірленуде. Жалпыға жүктеу әлі жоқ. Бұл беттер ағымдағы құрастырманы сипаттайды.

Не істейді

  • Windows Update, құрылғылар, сақтау орны, желі, басып шығару, қауіпсіздік, қолданбалар мен профильдер бойынша тек оқуға арналған диагностиканы орындап, оқуға ыңғайлы есеп жазады.
  • Жаңа дәлелдер нақты мәселені растағанда ғана орындалатын қорғалған жөндеулерді ұсынады және кейін нәтижені растайды.
  • BitLocker, құпиялылық параметрлері, Windows-ты ретке келтіру және жаңа компьютерді дайындау сияқты баптау мен қорғауды күшейту жұмыстарын қамтиды.
  • Диагностика мен есеп талдауын ЖИ-сіз және KillerBench тіркелгісінсіз жергілікті түрде орындайды. Жүктеулер мен қалпына келтіру кілтін Entra ID жүйесіне сақтау сияқты таңдалған әрекеттер сыртқы қызметтерге қосылуы мүмкін.
  • Консоль, есептер, растаулар және Ашу, Сақтау және Қалта сұхбат терезелері үшін қолданбаның белсенді тақырыбын пайдаланады.

Неден бастау керек

  • Жүктеу және орнату
  • KillerBench туралы
  • Алғашқы диагностика жүйені толық тексеруді қадам бойынша көрсетеді.
  • Жұмыс аймағы бөлімдерді, панельдерді және пернелер тіркесімдерін түсіндіреді.
  • Өзгерістер қалай қауіпсіз болады KillerBench кез келген өзгерістің алдында және одан кейін нені тексеретінін түсіндіреді.
  • Қадамдық нұсқаулықтар жиі кездесетін жұмыстарды қадам бойынша көрсетеді.
  • Бөлімдер беттері әр құралды қолданбадағыдай топтастырып сипаттайды.
  • Пәрмен жолы killerbench-cli пәрмендерінің барлығын тізімдейді.
  • Ақауларды жою бұғатталған әрекеттерді, қайта іске қосуларды және үзілген сұрауларды қарастырады.

Диагностиканы өз құралдарына енгізгісі келетін әзірлеушілер Engine әзірлеуші нұсқаулығын оқи алады.

KillerBench 1.0.0 әлі шығарылмаған. Жалпыға қолжетімді KillerBench пакеті немесе жүктеуі әлі жоқ. Бұл бет ресми емес көшірмені жүктемей-ақ дайындала алуыңыз үшін ағымдағы пакет талаптарын сипаттайды.

Windows және орындау ортасы

  • Ағымдағы жариялау мақсаты Windows x64. Windows 11 x64 ағымдағы жергілікті тексерудің негізгі нұсқасы. Жергілікті ARM64, x86 және Windows Server таратылымдары берілмейді.
  • KillerBench екі түрде пакетталады. Орнатушы платформаға тәуелді және .NET Desktop Runtime 10 for Windows x64 қажет етеді. Қарапайым .NET Runtime, ASP.NET Core Runtime және .NET Framework WPF бермейді. Тасымалы нұсқа өз орындау ортасын қамтиды және бөлек орнатуды қажет етпейді. killerbench-cli.exe пәрмен жолы құралы .NET 10 Runtime for Windows x64 қажет етеді. SDK қарапайым пайдалану үшін емес, әзірлеу үшін керек.
  • .NET 10 on Windows қолдайтын Windows нұсқасын пайдаланыңыз. Орындау ортасының қолдауы KillerBench жөндеулері қолдау көрсетілетін әр басылымда немесе құрастырмада тексерілген дегенді білдірмейді. Windows 10 қамтуы әлі күтілуде және оның қолдау көрсетілетін басылымдары Microsoft-тың ағымдағы өмірлік цикл талаптарымен шектеледі.
  • Desktop Runtime-ды тек Microsoft-тың .NET 10 жүктеу бетінен алыңыз және .NET Desktop Runtime, Windows, x64 таңдаңыз. Ұйымыңыздың бағдарламалық жасақтаманы орнату ережелерін сақтаңыз.

Егер dotnet қолжетімді болса, dotnet --list-runtimes x64 орнатылымы үшін Microsoft.WindowsDesktop.App 10.0.x көрсетуі керек. Тек басқа архитектура үшін орнатылған орындау ортасы x64 орнатушы пакетіне сай келмейді.

Пакет жарияланғанда

  1. Осы веб-сайттағы ресми жүктеу сілтемесін пайдаланыңыз. KillerBench жүктеу сілтемесі әлі белсенді емес.
  2. Сол пакеттің талаптарын, GPLv3 лицензиясын, Сәйкес бастапқы код нұсқауларын, қоса берілген үшінші тарап хабарламаларын, қолтаңба мен бақылау сомасы туралы ақпаратты оқыңыз. Файл атауының өзі түпнұсқалықты дәлелдемейді.
  3. Орнатушыны ағымдағы тіркелгі үшін немесе құқықтарды көтеру сұрауынан кейін барлық пайдаланушылар үшін іске қосыңыз. Ол Бастау мәзіріне таңбаша, қосымша жұмыс үстелі таңбашасын және Бағдарламаларды қосу немесе жою тізіміне жазба қосады. Тасымалы нұсқа орнатусыз жұмыс істейді.
  4. KillerBench-ті әдеттегі тіркелгіңізбен бастап, Алғашқы диагностика бетін орындаңыз. Диагностикалық қатынас қателері көрінетін болып қалады; құқықтарды көтеру бөлек әдейі таңдау болып табылады.

Тексерілмеген көшірмені іске қосу үшін Windows қауіпсіздік ескертулерін айналып өтпеңіз. Компьютерді өзгертетін кез келген әрекетті таңдамас бұрын ағымдағы сақтық көшірмені сақтаңыз.

Іске қосылғанда KillerBench GitHub-тан жаңарақ тұрақты шығарылымды тексереді және оны орнатпас бұрын сұрайды. Жүктелген файл жарияланған SHA-256 бақылау сомасына сәйкес келуі керек. Тексеруді «Бағдарлама туралы» ішіндегі Іске қосылғанда жаңартуларды тексеру арқылы өшіріңіз.

Ағымдағы шектеулер

Ағымдағы құрастырмада он екі бөлім, тек оқуға арналған диагностика, есептер және жеке таңдалатын жөндеу беттері бар. Жергілікті жөндеуді тексеру әлі жүріп жатыр. Жұмыс істейтін интерфейс, сәтті құрастыру немесе тест деректерінің нәтижесі нақты компьютердегі жөндеу мінез-құлқын дәлелдемейді. Өзгерістер қалай қауіпсіз болады бетін қараңыз.

Бастапқы беттегі иллюстрациялық консоль синтетикалық шығыс болып табылады. Алғашқы жалпыға қолжетімді пакет әлі күтілуде.

Бастапқы код, лицензия және қолдау

KillerBench GPLv3 бойынша лицензияланған. Бастапқы кодты жеткізу нұсқаулары мен үшінші тарап қаріптерінің рұқсаттары алғашқы жалпыға қолжетімді пакет үшін әлі күтілуде. Бастапқы кодтың қолжетімділігі, тарату хабарламалары, дәлелдердің құпиялылығы және қолдау туралы ақпарат үшін KillerBench туралы бетін оқыңыз. Engine нұсқаулығы рұқсат етілген бастапқы код көшірмесі бар әзірлеушілерге арналған; ол жалпыға қолжетімді Engine пакеті бар дегенді білдірмейді.

Жүктеу және орнату бетінен бастап, содан кейін жүйені толық тексеруді іске қосыңыз. Ол диагностикалық дәлелдерді жинап, жергілікті журналды сақтайды; жөндеулерді іске қоспайды. Қорытынды компьютердегі барлық ықтимал ақауды емес, тексерілген ауқымды сипаттайды.

Тексеруді іске қосу

  1. KillerBench-ті ашыңыз. Диагностика бөлімі Жүйені толық тексеру таңдалған күйде ашылады.
  2. Алғашқы іске қосу үшін Расталған мәселелерді автоматты жөндеу параметрін өшірулі қалдырыңыз.
  3. Диагнозды іске қосу түймесін басыңыз. Әр тексеру орындалған кезде барысы оң жақтағы Шикі шығыс ішінде көрсетіледі.
  4. Аяқталғанда шығыс тақтасы Оқылатын есеп көрінісіне ауысады.

Құқықтарды көтермей бастаңыз. BitLocker қорғағыштары мен қорғалған қызметтер сияқты кейбір Windows дәлелдері әкімші құқықтарын қажет етеді. Стандартты тіркелгіде бұл тексерулер дәлелдің қолжетімсіз екенін хабарлайды. Егер сізге сол дәлел керек болса, ағымдағы іске қосуды аяқтап, есепті сақтаңыз, содан кейін KillerBench-ті Әкімші ретінде іске қосу арқылы әдейі қайта ашыңыз. Құқықтарды көтеру жөндеуді таңдамайды және мақұлдамайды.

Есепті оқу

Есеп Қарап шығу керек, Расталған жөндеулер, Аяқталмаған және Тексерілді сандарынан басталады, одан кейін ұсынылған келесі қадам беріледі.

  • Назар аударуды қажет ететіндер дәлелдер растайтын мәселелерді маңыздысынан бастап тізімдейді.
  • Жиналған ақпарат не оқылғанын, соның ішінде толық емес немесе қолжетімсіз болған дәлелдерді көрсетеді.
  • Бұрынғы оқиғалар тарих ретінде белгіленеді. Өткен айдағы қате ағымдағы ақау ретінде қарастырылмайды.

Жоқ дәлел ешқашан сау күй деп саналмайды. Егер тексеру орындалмаса, есеп мұны көрсетеді.

Тексерулерді өзіңіз таңдау

Толық тексерудің орнына жеке тексерулерді таңдау үшін Тексерулерді таңдау (кеңейтілген) бөлімін ашыңыз. Қолданбадағы әр бөлімде мақсатты құралдар да бар, олар осы нұсқаулықтың Бөлімдер беттерінде сипатталған.

Табылғанды түзету

Есеп түзетуді ұсынғанда, ашылатын бөлім мен құралдың атауын көрсетеді. Алғашқы жөндеудің алдында Өзгерістер қалай қауіпсіз болады бетін оқыңыз. Жергілікті тексеру әлі жүріп жатыр; сәтті диагностика ұсынылған әр жөндеудің сіздің Windows құрастырмаңызда тексерілгенін білдірмейді. Сақтық көшірмелерді сақтап, кез келген өзгеріс алдында нақты мақсат пен салдарын қарап шығыңыз.

KillerBench терезесінде жұмыс тәртібіңізге сай үш тақта бар: сол жақтан бөлімді таңдайсыз, ортада құрал параметрлерін орнатасыз, оң жақта шығысты оқисыз. Параметрлердің астында әрекет журналы ашылуы мүмкін.

Бөлімдер

Сол жақтағы бүйірлік тақта барлық құралдарды он екі бөлімге тізімдейді: Диагностика, Жөндеу, Жаңартулар, Құрылғылар, Желі, Қолданбалар, Қызмет көрсету, Дайындау, Қауіпсіздік, BitLocker, Құпиялылық және Сақтау орны. Өлшемін өзгерту үшін оның шетін сүйреңіз немесе жабу үшін оны ең аз енінен әрі сүйреңіз.

Құрал параметрлері

Ортаңғы тақта таңдалған бөлімді, оның құралдар тізімін және таңдалған құралдың параметрлерін көрсетеді. Компьютерді өзгерте алатын параметрлер әдепкі бойынша әрқашан өшірулі. Құралды бастау үшін Диагнозды іске қосу түймесін басыңыз. Расталған мәселелерді автоматты жөндеу қосулы болғанда, сол түйме Жөндеуді іске қосу деп аталады. Тоқтату ағымдағы пәрмен аяқталғаннан кейін іске қосуды аяқтайды.

Шығыс

Оң жақтағы шығыс тақтасының екі көрінісі бар.

  • Шикі шығыс техникалық дәлелдерді жиналу барысында бастапқы жол нөмірлерімен көрсетеді. Құрал жұмыс істеп тұрғанда ол өздігінен ашылады.
  • Оқылатын есеп соңғы іске қосудың аяқталған есебін көрсетеді. Іске қосу аяқталғанда ол шикі шығыстың орнына шығады.

Тек сәйкес жолдарды көрсету үшін Шикі шығыстағы сүзгі өрісін пайдаланыңыз. Есепті экспорттау есепті бастапқы жолдарымен және дәлел үзінділерімен сақтайды. Сеанс көздері осы сеанста жиналған әр дәлелді тізімдейді.

Әрекет журналы

Құрал параметрлерінің астындағы әрекет журналы KillerBench осы сеанста не істегенін жазады.

Тақырыптар, тілдер және пернелер тіркесімдері

Бүйірлік тақта мен құрал параметрлерінің арасындағы жолақта тақырып таңдағыш, тіл таңдағыш, пернелер тіркесімдерінің тізімі және әрекет журналын ауыстырғыш орналасқан. KillerBench-те 13 тақырып және 20 тіл бар.

Ысталған шыны тәрізді консоль мен оқылатын есептер белсенді тақырыпқа сай болады. Растаулар және Ашу, Сақтау және Қалта сұхбат терезелері сол отбасылық безендіруді, соның ішінде 98SE тақырыбын пайдаланады. Бүкіл жұмыс ағыны бойы сол көріністі пайдалану үшін сұхбат терезесін ашпас бұрын тақырыпты таңдаңыз.

Сол қабатты көру үшін Ctrl немесе Alt+Shift пернесін басып тұрыңыз. Әрекетін көру үшін жанған пернеге меңзерді апарыңыз.

KillerBench диагностика мен өзгерісті әртүрлі жұмыс ретінде қарастырады. Диагностика тек оқиды. Жүйені толық тексеру ешқашан жөндеулерді іске қоспайды. Нақты жөндеуді немесе әрекетті таңдап, оның параметрлері мен алғышарттарын қарап шығыңыз және ұсынылған өзгерісті растаңыз.

Өзгеріс алдында

  1. Жаңа дәлелдер. Құрал ағымдағы күйді қайта оқиды. Сақталған есеп немесе ескі оқиға ешқашан өзгерістің негізі бола алмайды.
  2. Нақты жарамдылық. Өзгеріс дәлелдер ол түзететін нақты мәселеге сәйкес келгенде ғана ұсынылады. Толық емес кез келген нәрсе оны бұғаттайды.
  3. Сіздің растауыңыз. Таңдалған әрекетті оның растау сұхбат терезесінде қарап шығыңыз. Дискінің шифрын ашу сияқты кейбір әрекеттер екінші растауды қажет етеді. Сұхбат терезесі қолданбаның белсенді тақырыбына сай болады; оның көрінісі әрекеттің талаптарын өзгертпейді.
  4. Алғышарттар. Әкімші құқықтары, қайта іске қосу күйі және параметрдің саясатқа немесе құрылғыларды басқару жүйесіне тиесілігі тексеріледі. Саясатқа тиесілі параметрлер өзгертілмейді.
  5. Күтудегі жазба. KillerBench Windows-тан әрекетті орындауды сұрамас бұрын не істейтінін жазып қояды.
  6. Соңғы қайта тексеру. Сұрау алдында бәрі дереу қайта тексеріледі, сондықтан арада болған өзгеріс оны тоқтатады.

Өзгерістен кейін

  • KillerBench нәтижені қайта оқиды және Windows күтілген күйді көрсеткенде ғана Расталды деп хабарлайды.
  • Егер Windows сәттілік қайтарса, бірақ күй өзгермесе, нәтиже мұны көрсетеді және ештеңе қайталанбайды.
  • Әр өзгеріс %LOCALAPPDATA%\KillerBench ішіндегі журналда сақталады.

Бірдеңе үзілсе

Сұрау Windows-қа жеткен болуы мүмкін, бірақ растау аяқталмаған кезде, қолдау көрсетілетін журналданатын әрекеттер күтудегі жазбаны сақтайды. Сол жазбаны тексеру үшін әрекеттің құжатталған салыстыру жолын немесе оған сәйкес -recover пәрменін пайдаланыңыз. Салыстыру автоматты кері қайтару емес. Нәтиже белгісіз болғанда журналды сақтаңыз және өзгерісті қолмен қайталамаңыз. Апат, бас тарту және кейінгі жүктелу кезіндегі мінез-құлық әлі де әр әрекет үшін жергілікті тексеруді қажет етеді.

KillerBench не істемейді

  • TPM-ді тазаламайды, өзі жасамаған қорғағыштарды жоймайды және қалпына келтіру құпия сөздерін көрсетпейді.
  • Топтық саясат немесе құрылғыларды басқару жүйесі басқаратын параметрді өзгертпейді.
  • Бұрынғы оқиға немесе импортталған есеп мәселені атап өткені үшін ғана жөндеуді іске қоспайды.

Диагностика мен есеп талдауы жергілікті түрде орындалады. Сіз таңдаған әрекет сыртқы мекенжайға, соның ішінде бағдарламаларды жүктеу қызметтеріне немесе қалпына келтіру кілтін Active Directory не Entra ID жүйесіне сақтауға қосылуы мүмкін. Растамас бұрын мақсатты қарап шығыңыз. Сақталған түсірілімдер мен шикі дәлелдер компьютердің сәйкестендіргішін және бастапқы жолдарды қамтуы мүмкін, сондықтан бөліспес бұрын оларды қарап шығыңыз.

Әзірлеу күйі

Жөндеулердің қамтуы әлі кеңейіп келеді. Сәтті құрастыру немесе модельденген тексеру жергілікті жөндеудің мінез-құлқын дәлелдемейді.

Қадамдық нұсқаулықтар

Мұны жаңартулар сәтсіз аяқталғанда, тоқтап қалғанда немесе қайта-қайта орнатыла бергенде пайдаланыңыз. KillerBench әуелі жаңарту тізбегін оқиды, ақауды оның артындағы дәлелмен түсіндіреді және жаңа дәлелдер дәл сол мәселені растағанда ғана қызметті іске қосады немесе компоненттер қоймасын жөндейді.

Бастамас бұрын

  • KillerBench-ті әкімші ретінде іске қосыңыз. Толық дәлел алу үшін жаңарту қызметтері, компоненттер қоймасы және қорғалған жүйелік файлдар құқықтарды көтеруді қажет етеді.
  • Егер Windows-та күтудегі қайта іске қосу болса, әуелі қайта іске қосыңыз. Қайта іске қосуға дайындық анық болмайынша, көптеген жаңарту жөндеулері бұғатталады.
  • Қызмет көрсету жұмыстары кезінде компьютерді желіден қоректендіріп ұстаңыз.

Жаңартулардың неге сәтсіз екенін анықтау

  1. Жаңартулар бөлімін ашып, құралдар тізімінен Windows Update таңдаңыз.
  2. Алғашқы өту үшін Расталған мәселелерді автоматты жөндеу өшірулі қалдырып, Диагнозды іске қосу түймесін басыңыз.
  3. Оқылатын есеп оқыңыз. Ол тоқтап тұрған жаңарту қызметтерін, күтудегі қайта іске қосуларды, бос орынның аздығын, компоненттер қоймасының зақымдануын және Windows жазған нақты қате кодтарын ұсынылған келесі қадаммен бірге тізімдейді.
  4. Егер есепте қате коды аталса, сәйкес қосымша тексерулер автоматты түрде іске қосылады. Сондай-ақ кодты өзіңіз killerbench-cli update-code 0x80070002 арқылы іздей аласыз.

Тоқтап қалған сияқты жаңартуды бақылау

Жаңартулар ішінде Қызмет көрсету әрекеті мониторы таңдап, Диагнозды іске қосу түймесін басыңыз. Ол жаңарту, Setup және Installer әрекетінің, тасымал көлемдерінің және қайта іске қосу көрсеткіштерінің қайталанған лездік көшірмелерін алады. Әрекет тек дәлел ретінде көрсетіледі; ол өздігінен тоқтап қалу немесе ақау туралы ешқашан мәлімдемейді.

Есеп тапқанды жөндеу

  1. Windows Update құралын Расталған мәселелерді автоматты жөндеу қосулы күйде қайта іске қосыңыз. Ол тоқтағаны расталған қосулы жаңарту қызметтерін іске қоса алады және DISM немесе SFC-ті тек тікелей тексеру зақымдануды растағанда іске қосады.
  2. Жеке қызмет үшін оның мақсатты құралын таңдаңыз, мысалы BITS қызметі, Криптография қызметтері, Windows модульдерін орнатушы немесе Update Orchestrator қызметі. Әрқайсысы тек сол нақты қызметті қалпына келтіруді ұсынады.
  3. Есеп қайта іске қосуды айтқанда, басқа ештеңе іске қоспас бұрын қайта іске қосыңыз. KillerBench қайта іске қосуды қажет ететін нәтижелерді жазады және қайта іске қосу аяқталғанша кейінгі жұмысты кейінге қалдырады.

Әр жөндеу журналға жазылады және қайта оқылады. Толық реттілік үшін Өзгерістер қалай қауіпсіз болады бетін қараңыз.

Нақты жаңартуды орнату

  1. Бапталған көзден жаңартуларды табу үшін Жаңартулар ішінде Қолжетімді жаңартулар таңдап, Диагнозды іске қосу түймесін басыңыз.
  2. Қажет жаңартуларды таңдап, Таңдалғанды алдын ала қарау түймесін басыңыз. Алдын ала қарау нақты не орнатылатынын және қайта іске қосу талабын тізімдейді.
  3. Алдын ала қарауды оқып, растау құсбелгісін қойыңыз, содан кейін Орнату түймесін басыңыз. Құсбелгі әр іске қосудан кейін алынып тасталады және KillerBench сіз үшін жаңартуды ешқашан таңдамайды және мақұлдамайды.

Пәрмен жолынан

killerbench-cli update-search
killerbench-cli update-history
killerbench-cli servicing-monitor --samples 10
killerbench-cli update-plan --select GUID:REVISION --execute

update-search, update-history, servicing-monitor және update-plan қараңыз. Орнату үзілсе, update-recover іске қосыңыз; ол нәтижені тексереді және жаңартуды ешқашан қайталамайды.

Қатысты

  • Жаңартулар бөлімі
  • Жүйелік файлдарды жөндеу
  • Ақауларды жою

Мұны Windows компоненттері зақымданғанда пайдаланыңыз: мүмкіндіктер орнатылмайды, жаңартулар компонент қателерін хабарлайды немесе жүйелік құралдар апатқа ұшырайды. KillerBench DISM мен SFC-ті тек тікелей тексеру зақымдануды растағаннан кейін іске қосады, содан кейін нәтижені растайды.

Бастамас бұрын

  • KillerBench-ті әкімші ретінде іске қосыңыз.
  • Әуелі күтудегі қайта іске қосуды аяқтаңыз.
  • Егер компьютер басқарылатын болса, саясат DISM-ді нақты жөндеу көзіне бағыттай ма, соны тексеріңіз. KillerBench бұл саясатты хабарлайды және оны өзгертпейді.

Зақымдануды тексеру

  1. Жөндеу бөлімін ашып, Жүйелік файлдар таңдаңыз.
  2. Расталған мәселелерді автоматты жөндеу өшірулі қалдырып, Диагнозды іске қосу түймесін басыңыз.
  3. Есепті оқыңыз. Ол қызмет көрсету пакеттерінің, қосымша компоненттер мен мүмкіндіктердің күйлерін тізімдейді, алғышарттарды тексереді және қорғалған жүйелік файлдарды сканерлейді. Таза нәтиже жөндеу ұсынылмайтынын білдіреді.

Расталған зақымдануды жөндеу

  1. Расталған мәселелерді автоматты жөндеу қосып, Жөндеуді іске қосу түймесін басыңыз. KillerBench DISM немесе SFC-ті тек тікелей тексеру зақымдануды растағанда таңдайды.
  2. Растауды күтіңіз. Есеп бақылау тексерісі жөнделген күйді қайта оқығанда ғана Расталды деп көрсетеді.
  3. Егер есеп қойманы қалпына келтіру мүмкін емес немесе жөндеу көзі қолжетімсіз деп айтса, сол жерде тоқтаңыз. Жөндеуді қайталау нәтижені өзгертпейді.

Үзілген DISM немесе SFC іске қосылымы қызмет көрсету пәрменін қайталамай келесі жүктелуде салыстырылады.

Компоненттер қоймасын тазалау

Жаңартулар ішінде Компоненттер қоймасын тазалау таңдаңыз. Ол әуелі Windows-тан тазалау ұсынылатынын сұрайды. Қосымша қызмет көрсету ауыстырылған компоненттерді жояды және қайта талдайды. Ол ешқашан ResetBase пайдаланбайды және WinSxS мазмұнын ешқашан қолмен жоймайды.

Пәрмен жолынан

killerbench-cli component-repair-source
killerbench-cli repair dism
killerbench-cli repair sfc --execute
killerbench-cli servicing-logs

component-repair-source, repair және servicing-logs қараңыз. repair әдепкі бойынша алдын ала қарау көрсетеді және тек --execute болғанда әрекет етеді.

Қатысты

  • Windows Update-ті түзету
  • Жөндеу бөлімі
  • Өзгерістер қалай қауіпсіз болады

Мұны дискіде орын азайғанда пайдаланыңыз. KillerBench орынның қайда кететінін көрсетеді, әр тазалау мақсаты нені жоятынын алдын ала көрсетеді және тұрақты тазалауды қосқаннан кейін ғана жояды.

Қанша орын қалғанын көру

  1. Сақтау орны бөлімін ашып, Сақтау орны таңдаңыз.
  2. Диагнозды іске қосу түймесін басыңыз. Есеп бос орны 10%-дан аз әріп тағайындалған әр томды белгілейді және көлеңкелі көшірмелерге бөлінген орынды, квоталардың әдепкі мәндерін және Storage Sense саясатын көрсетеді.
  3. Апат дамптары мен ескі жаңарту мазмұны үшін Диагностика ішінде Негізгі көрсеткіштер және Жаңартулар ішінде Windows Update құралдарын да іске қосыңыз; жаңарту кэшінің өлшемі сонда көрсетіледі.

Тазалауды алдын ала қарау

  1. Қызмет көрсету бөлімін ашып, Тазалау таңдаңыз.
  2. Қажет мақсаттарды белгілеңіз, мысалы Ағымдағы пайдаланушы уақытша файлдары, Windows уақытша файлдары, Ағымдағы пайдаланушы браузер кэштері, Delivery Optimization кэші немесе Ағымдағы пайдаланушының Себеті. Мақсат қандай қалталарды қамтитынын нақты оқу үшін оның үстіне меңзерді апарыңыз.
  3. Ең аз жас (күн) және Әр мақсатқа ең көп файл саны орнатыңыз.
  4. Жаңа тексерулерден кейін таңдалған тұрақты тазалауды орындау өшірулі күйде Диагнозды іске қосу түймесін басыңыз. Есеп әр мақсат бойынша үміткерлерді және болжамды орынды тізімдейді. Ештеңе жойылмайды.

Файлдарды жою

  1. Жаңа тексерулерден кейін таңдалған тұрақты тазалауды орындау қосып, Диагнозды іске қосу түймесін басыңыз.
  2. KillerBench әр үміткерді жоймас бұрын қайта тексереді, жақында өзгерген, қорғалған немесе пайдаланылып жатқан файлдарды өткізіп жібереді және әр нәтижені журналға жазады.

Тұрақты тазалау Себетті айналып өтеді және оны болдырмау мүмкін емес. Қате есептері мен апат дамптарын жою апаттарды зерттеуге қажет болуы мүмкін дәлелдерді жояды, сондықтан әуелі оларды қарап шығыңыз.

Алдыңғы Windows орнатылымын жою

Мүмкіндіктер жаңартуынан кейін Тазалау ішіндегі Алдыңғы Windows орнатылымы кері қайтару көшірмесін Windows қолдайтын кері қайтаруды жою сұрауы арқылы жоя алады. Ол жеке орындалады, Алдыңғы орнатылымнан қажет файлдар мен параметрлердің сақтық көшірмесін жасадым белгісін қажет етеді және алдыңғы нұсқаға қайту мүмкіндігін біржола жояды.

Пәрмен жолынан

killerbench-cli volume-capacity C:
killerbench-cli cleanup --user-temp --windows-temp --days 7 --max-files 500
killerbench-cli cleanup --user-temp --windows-temp --days 7 --max-files 500 --execute

volume-capacity, cleanup және previous-windows қараңыз.

Қатысты

  • Қызмет көрсету бөлімі
  • Сақтау орны бөлімі
  • Дискіні тексеру және жөндеу

Мұны том қателерді хабарлағанда, Windows дискіні сканерлеуді сұрағанда немесе файлдар ашылмағанда пайдаланыңыз. KillerBench әуелі томды тек оқу режимінде тексереді және сақтық көшірмені растағаннан кейін ғана файл жүйесін жөндеуді жоспарлайды немесе іске қосады.

Бастамас бұрын

  • Томдағы маңызды деректердің сақтық көшірмесін жасаңыз. Файл жүйесін жөндеу зақымдалған файлдарды өзгертуі немесе жоюы мүмкін.
  • KillerBench-ті әкімші ретінде іске қосыңыз.

Томды тексеру

  1. Сақтау орны бөлімін ашып, Сақтау орны таңдаңыз.
  2. Тексерілетін том ішінен дискіні таңдап, Диагнозды іске қосу түймесін басыңыз.
  3. Есепті оқыңыз. Ол диск пен томның күйін, dirty битін, NTFS-тің желідегі өзін-өзі қалпына келтіруін, контроллер мен диск құрылғыларының қателерін, сенімділік есептегіштерін және бастапқы күйге қайтарулар, қайталаулар мен күтпеген ажыратулар сияқты сақтау құрылғыларының соңғы оқиғаларын көрсетеді.

Таза тексеру жөндеу ұсынылмайтынын білдіреді. Диск температурасы, тозуы және түзетілмеген енгізу-шығару есептегіштері қарап шығуға арналған дәлелдер болып табылады және өздігінен жөндеуді іске қоспайды.

Файл жүйесін жөндеу

  1. Файл жүйесі жөндеуін қарап шығу түймесін басып, Нүктелік жөндеу немесе Офлайн сканерлеу және жөндеу таңдаңыз.
  2. Деректер томы үшін оны пайдаланатын барлық нәрсені жаба алсаңыз, Жүйелік емес томды офлайн етуге рұқсат беру белгілеңіз. Windows томы офлайн бола алмайды, сондықтан оның жөндеуі келесі қайта іске қосуға жоспарланады.
  3. Осы томдағы маңызды деректердің сақтық көшірмесі жасалған белгілеңіз.
  4. Жөндеуді растаңыз. KillerBench әрекет етер алдында нақты томды дереу қайта тексереді және әуелі күтудегі жазбаны жазады.
  5. Жоспарланған жөндеу үшін ыңғайлы уақытта қайта іске қосыңыз. KillerBench қайта іске қосудан кейін жөндеуді қайта іске қоспай нәтижені растайды.

Оңтайландыру немесе retrim

Сол құрал томды талдап, Windows ұсынған оңтайландыруды, Қатты күйлі сақтау құрылғысын retrim ету немесе қатты дискіні дефрагментациялауды іске қоса алады. Әрқайсысы бір нақты сау томдағы бөлек расталатын әрекет.

Пәрмен жолынан

killerbench-cli storage-check C
killerbench-cli storage-repair-plan D: OfflineScanAndFix --allow-dismount
killerbench-cli storage-repair D: OfflineScanAndFix --allow-dismount --backup-confirmed --execute
killerbench-cli storage-repair-recover

storage-check, storage-repair-plan, storage-repair және volume-optimize қараңыз.

Қатысты

  • Сақтау орны бөлімі
  • Дискідегі орынды босату
  • Ақауларды жою

Мұны компьютерде интернет болмағанда, серверге немесе атауға қол жеткізе алмағанда немесе қосылым үнемі үзілгенде пайдаланыңыз. KillerBench адаптерді, мекенжайды, шлюзді, DNS пен брандмауэрді ретімен тексереді және жаңа дәлелдер қажеттілікті растағанда ғана жалға алуды жаңартады немесе қызметті іске қосады.

Қосылымды тексеру

  1. Желі бөлімін ашып, Желі таңдаңыз.
  2. Нақты бір нәрсені тексеру үшін Хост атауын іздеу (міндетті емес) немесе TCP мақсаты (міндетті емес) және TCP порты өрістерін толтырыңыз. Тек жергілікті конфигурацияны тексеру үшін оларды бос қалдырыңыз. Қолданба деректері жіберілмейді.
  3. Желі баяу болса, Әр іздеу немесе қосылым үшін күту уақыты (секунд) орнатыңыз.
  4. Расталған мәселелерді автоматты жөндеу өшірулі қалдырып, Диагнозды іске қосу түймесін басыңыз.
  5. Есепті оқыңыз. Ол жоқ мекенжайды, жоқ немесе қолжетімсіз шлюзді, DNS конфигурациясы мәселелерін, прокси параметрлерін, брандмауэр профильдерінің сәйкессіздігін және сәтсіз іздеуді немесе қосылымды бөліп көрсетеді және әрқайсысы үшін келесі қадамды береді.

Шлюзден келген жауап интернетке қатынас бар екенін дәлелдемейді, ал бапталған шешуші арқылы сәтсіз іздеу сайттың істемей тұрғанын білдірмейді.

Есеп тапқанды жөндеу

  1. Желі құралын Расталған мәселелерді автоматты жөндеу қосулы күйде қайта іске қосыңыз. Ол қосулы DNS клиенті, DHCP клиенті, SMB клиенті, желі орнын анықтау, желілер тізімі және IP көмекшісі қызметтерін іске қоса алады және жарамды IPv4 мекенжайы жоқ қосылған физикалық DHCP адаптерлерінің жалға алуын жаңарта алады.
  2. Жаңарту кезінде қосылым қысқа уақытқа үзілуі мүмкін. Статикалық мекенжайлар мен виртуалды адаптерлер ешқашан өзгертілмейді.
  3. Кэштегі бір қате атау үшін бәрін тазаламай, сол нақты хостқа арналған DNS кэшін тазалауды пайдаланыңыз.

Маршруттар, Hosts жазбалары, DNS серверлері, брандмауэр ережелері, Winsock провайдерлері мен желі профильдері әрқашан сақталады.

Сымсыз желі, сымды кіру және прокси

  • Сымсыз желі адаптер мен WLAN AutoConfig қызметін тексереді және қызмет тоқтап тұрса, оны іске қоса алады.
  • Сымды аутентификация (802.1X) портта кіруді талап ететін желілер үшін Wired AutoConfig қызметіне дәл солай жасайды.
  • WinHTTP автоматты прокси компьютер мен ағымдағы тіркелгі үшін сақталған прокси параметрлерін көрсетеді. KillerBench диагностика кезінде ешқашан PAC URL мекенжайын жүктемейді және прокси параметрлерін өзгертпейді.

Пәрмен жолынан

killerbench-cli workflow network --host example.com --tcp example.com 443
killerbench-cli dns-check example.com --timeout-seconds 5
killerbench-cli tcp-check fileserver 445
killerbench-cli dhcp-renew
killerbench-cli dns-cache example.com --execute

workflow, dns-check, tcp-check, dhcp-renew және dns-cache қараңыз.

Қатысты

  • Желі бөлімі
  • Басып шығару мәселелерін түзету
  • Өзгерістер қалай қауіпсіз болады

Мұны тапсырмалар кезекте тұрып қалғанда, принтер офлайн болып көрсетілгенде немесе әдепкі принтер дұрыс емес болғанда пайдаланыңыз. KillerBench әуелі басып шығару спулерін, кезектерді, тапсырмаларды, драйверлер мен порттарды оқиды, содан кейін бір нақты кезекті немесе тапсырманы түзетуге мүмкіндік береді.

Принтерлерді тексеру

  1. Құрылғылар бөлімін ашып, Басып шығару таңдаңыз.
  2. Жергілікті принтерлерді табу түймесін басып, дұрыс жұмыс істемей тұрған кезекті таңдаңыз. Барлық кезекті тексеру үшін Жалпы басып шығару тексерулерін пайдалану таңдаңыз.
  3. Расталған мәселелерді автоматты жөндеу өшірулі қалдырып, Диагнозды іске қосу түймесін басыңыз.
  4. Есепті оқыңыз. Ол басып шығару спулерінің күйін, кідіртілген кезектерді, офлайн режимін, көрінетін тапсырмаларды, драйвер күйлерін, порт тіркеулерін, PrintService соңғы қателерін және желілік принтерлер үшін принтерге тағайындалған мекенжайға бір қосылу әрекетін көрсетеді.

Сәтті қосылым немесе таза күй коды принтерде қағаз, тонер немесе жұмыс істейтін механизм бар екенін дәлелдемейді.

Кезекті жөндеу

  1. Басып шығару құралын Расталған мәселелерді автоматты жөндеу қосулы күйде қайта іске қосыңыз. Ол қосулы спулерді іске қоса алады, тапсырмалары күтіп тұрған нақты кідіртілген кезекті жалғастыра алады және офлайн режимін алып тастай алады.
  2. Офлайн режимін алып тастау күтудегі тапсырмаларды босатуы мүмкін, сондықтан ол тапсырмалар әлі де басып шығарылуы керек екеніне көз жеткізіңіз.
  3. Біреу әдейі кідірткен, күтіп тұрған ештеңесі жоқ кезек кідіртілген күйде қалады.

Тұрып қалған бір тапсырманы тазалау

  1. Бұғатталған басып шығару тапсырмаларын табу түймесін басыңыз.
  2. Error немесе Blocked күйін көрсететін тапсырманы таңдап, Тек осы таңдалған тапсырмадан бас тарту белгілеңіз.
  3. Диагнозды іске қосу түймесін басыңыз. Тек сол тапсырмадан бас тартылады және нәтиже қайта оқылады.

Әдепкі принтерді түзету

Әдепкі болуы тиіс кезекті таңдап, Жоқ немесе қайшы әдепкі принтерді осы кезекпен жөндеу белгілеңіз, содан кейін Диагнозды іске қосу түймесін басыңыз. Бұл тек әдепкі принтер жоқ немесе қайшы болғанда әрекет етеді.

Пәрмен жолынан

killerbench-cli printer-list
killerbench-cli printer-check --queue "Office Laser"
killerbench-cli printer-repair --queue "Office Laser" --execute
killerbench-cli print-job-list
killerbench-cli print-job-cancel "Office Laser" 12 --execute

printer-list, printer-check, printer-repair, print-job-cancel және default-printer-set қараңыз.

Қатысты

  • Құрылғылар бөлімі
  • Желі мен интернет мәселелерін түзету

Мұны BitLocker-ті қосу, қалпына келтіру кілтінің сақтық көшірмесін жасау және дискінің қорғалғанын растау үшін пайдаланыңыз. KillerBench шифрлауды бастамас бұрын қалпына келтіру құпия сөзінің сақтық көшірмесін жасап, оны растайды және қалпына келтіру құпия сөзін ешқашан көрсетпейді немесе журналға жазбайды.

Бастамас бұрын

  • KillerBench-ті әкімші ретінде іске қосыңыз.
  • Windows дискісіне TPM қорғағышы мен қалпына келтіру құпия сөзі қорғағышы қажет. Деректер дискісіне тек қалпына келтіру құпия сөзі қажет.
  • Қалпына келтіру кілтінің сақтық көшірмесі қайда сақталатынын шешіңіз: шифрланатын дискіден тыс файлға және қосымша түрде Active Directory немесе Microsoft Entra ID жүйесіне.

Дискіні тексеру

  1. BitLocker бөлімін ашып, Том ішінен дискіні таңдаңыз.
  2. Әрекетті Тексеру күйінде қалдырып, Диагнозды іске қосу түймесін басыңыз. Есеп шифрлау күйін, қорғау күйін және қорғағыштардың сәйкестендіргіштерін көрсетеді.
  3. TPM бар, бірақ дайын болмаса, әуелі оны Қауіпсіздік бөлімінен дайындаңыз. KillerBench TPM-ді ешқашан тазаламайды.

Қажет қорғағыштарды қосу

  1. BitLocker-тің басқа әрекеттері ашыңыз.
  2. TPM қорғағышын қосу немесе Қалпына келтіру құпия сөзін қосу таңдап, Алдын ала қарау түймесін басыңыз, Әрекетті іске қосу түймесін басқанда осы өзгерісті таңдалған дискіде жасау белгілеңіз, содан кейін Әрекетті іске қосу түймесін басыңыз.
  3. Жаңа қалпына келтіру құпия сөзінің сақтық көшірмесін бірден жасаңыз. KillerBench оны көрсетпейді.

Қалпына келтіру кілтінің сақтық көшірмесін жасау және шифрлау

  1. Қалпына келтіру қорғағыштарын табу түймесін басып, қалпына келтіру құпия сөзі қорғағышын таңдаңыз.
  2. Шифрланатын дискіден тыс сақтық көшірме файлының толық жолын енгізіңіз.
  3. Шифрлау таңдап, шифрлау әдісін таңдаңыз және «Диагнозды іске қосу» түймесін таңдағанда таңдалған қалпына келтіру кілтінің көшірмесін жасап, шифрлауды бастау белгілеңіз.
  4. Диагнозды іске қосу түймесін басыңыз. KillerBench сақтық көшірмені жазады, оны растайды, содан кейін шифрлауды бір рет бастайды.
  5. Шифрлау фондық режимде жалғасады. Дискі толық шифрланған және қорғау қосулы деп хабарлайтынын растау үшін кейінірек Тексеру іске қосыңыз.

Active Directory немесе Entra ID жүйесіне сақтау

BitLocker-тің басқа әрекеттері ішінде таңдалған қорғағыш үшін каталогқа сақтық көшірме жасауды таңдаңыз. KillerBench Windows сұрауды қабылдағанын хабарлайды, бірақ каталогтағы көшірмені оқи алмайды, сондықтан оны Active Directory немесе Entra әкімші орталығында растаңыз.

Деректер дискілері және автоматты құлыптан босату

Деректер дискісі шифрланғаннан кейін Автоматты құлыптан босатуды қосу оны Windows іске қосылғанда құлыптан босатады. Windows дискісі қорғау қосулы күйде толық шифрланған болуы керек.

Пәрмен жолынан

killerbench-cli bitlocker-protectors C:
killerbench-cli bitlocker-protector-add C: recovery --execute
killerbench-cli bitlocker-encrypt C: RECOVERY_PROTECTOR_GUID D:\Keys\C-recovery.txt --execute
killerbench-cli bitlocker-escrow C: RECOVERY_PROTECTOR_GUID entra --execute

bitlocker-protectors, bitlocker-protector-add, bitlocker-encrypt және bitlocker-escrow қараңыз. Әрқайсысында үзілген сұрауға арналған сәйкес -recover пәрмені бар.

Қатысты

  • BitLocker бөлімі
  • Қауіпсіздік бөлімі
  • Өзгерістер қалай қауіпсіз болады

Мұны Windows күтпеген жерден қайта іске қосылғанда, тоқтау қатесін көрсеткенде немесе қолданба үнемі апатқа ұшырағанда пайдаланыңыз. KillerBench апат, жұмысты аяқтау, жабдық қатесі және сенімділік дәлелдерін бір есепке жинайды. Ол не жазылғанын сипаттайды және түпкі себепті ешқашан болжамайды.

Компьютерді тексеру

  1. Диагностика бөлімін ашып, Негізгі көрсеткіштер таңдаңыз.
  2. Диагнозды іске қосу түймесін басыңыз. Есеп жадты, диск күйін, құрылғы мәселелерін, сенімділік мониторының тарихын, жабдық қатесінің жазбаларын, апат есептерін, күтпеген жұмысты аяқтауларды және Windows жадын диагностикалау нәтижелерін біріктіреді.
  3. Қорытындыны және оның астындағы дәлелдерді оқыңыз. Бұрынғы апаттар не болғанын түсіндіреді; олар ақаудың әлі бар екенін дәлелдемейді.

Ауқымды тарылту

  • Жабдық қателерінің тарихы WHEA және жад диагностикасы жазбаларын құрылғы мәселелерімен және диск күйімен бірге оқиды.
  • Сенімділік тарихы соңғы 14 күндегі қолданба апаттарын, қатып қалуларды және күтпеген жұмысты аяқтауларды топтастырады.
  • Қолданба қателері апатқа ұшыраған бағдарламаларға назар аударады.
  • Драйвер орнату тарихы қазір бар құрылғыларға сәйкестендірілген сәтсіз драйвер орнатуларын көрсетеді.
  • Құрылғы мәселелері Құрылғылар диспетчерінің қате кодтары бар құрылғыларды тізімдейді.

Апат дамптарын оқу

KillerBench дамп конфигурациясы мен дамп файлдарының метадеректерін тізімдейді және ерекше жағдай мен модуль атаулары үшін мини-дамп құрылымын талдай алады. Жұмыс үстелі қолданбасында дамп мазмұны ешқашан ашылмайды. Bug-check білім пакеті жүктелгенде тоқтау кодтары олардың құжатталған мағынасына сәйкестендіріледі.

Зерттеуді аяқтағанша дамптарды сақтаңыз. Тазалау оларды жоя алады, бірақ бұл дәлелдерді жояды.

Пәрмен жолынан

killerbench-cli vitals-check
killerbench-cli crash-config
killerbench-cli crash-dumps
killerbench-cli crash-review
killerbench-cli device-code 43

vitals-check, crash-review және device-code қараңыз.

Қатысты

  • Диагностика бөлімі
  • Есептер мен дәлелдер

Мұны ноутбуктағы құпиялылықты қарап шығу және күшейту үшін пайдаланыңыз. KillerBench ағымдағы параметрлерді оқиды, олардың қайсысы саясатқа немесе құрылғыларды басқару жүйесіне тиесілі екенін көрсетеді және тек сіз таңдаған параметрлерді бір-бірлеп, нақты кері қайтару мүмкіндігімен өзгертеді.

Ағымдағы параметрлерді қарап шығу

  1. Құпиялылық бөлімін ашыңыз.
  2. Қарап шығатын аймақтарды белгілеңіз. Әр аймақ белгіленбеген күйде басталады.
  3. Диагнозды іске қосу түймесін басыңыз. Есеп осы компьютер мен KillerBench-ті іске қосқан тіркелгі үшін ағымдағы мәнді көрсетеді және саясатқа тиесілі параметрлерді белгілейді.

Параметрді өзгерту

  1. Құпиялылық параметрі ішінен параметрді таңдаңыз, мысалы камера, микрофон, орналасу, диагностикалық деректер, жарнама, алмасу буферінің тарихы, бұлттық мазмұнды іздеу немесе іздеу ерекшеліктері.
  2. Жаңа мәнді таңдап, «Диагнозды іске қосу» түймесін таңдағанда қолдану белгілеңіз.
  3. Диагнозды іске қосу түймесін басыңыз. KillerBench саясат иесін тексереді, ағымдағы мәнді жазады, бір өзгерісті жасайды және оны қайта оқиды.

Топтық саясатқа немесе құрылғыларды басқару жүйесіне тиесілі параметрлер өзгертілмейді. Оларды басқарылатын жерде өзгертіңіз.

Өзгерісті кері қайтару

Әр расталған өзгеріс журналды сақтайды. Сәйкес кері қайтару саясатты қайта тексергеннен кейін нақты алдыңғы мәнді қалпына келтіреді.

Windows-ты ретке келтіру

Ұсыныстар, тұтынушы мазмұны, Recall және ЖИ мүмкіндіктері, тапсырмалар тақтасы мен Бастау мәзіріндегі артық элементтер, Edge және алдын ала орнатылған бағдарламалар үшін Қызмет көрсету ашып, Windows-ты ретке келтіру таңдаңыз. Қарап шығу тек оқуға арналған және ештеңе автоматты түрде таңдалмайды.

Пәрмен жолынан

killerbench-cli privacy-plan --select Camera --select ClipboardSync
killerbench-cli privacy-setting camera-access off --execute
killerbench-cli privacy-setting-undo camera-access VERIFIED_JOURNAL --execute
killerbench-cli debloat-review --area TelemetryAndReporting

privacy-plan, privacy-setting, privacy-setting-undo және debloat-review қараңыз. Қолдау көрсетілмейтін кілт қолдау көрсетілетін таңдауларды тізімдейді.

Қатысты

  • Құпиялылық бөлімі
  • Жаңа компьютерді баптау

Мұны жаңа немесе жаңадан бастапқы күйге қайтарылған компьютерді дайындағанда пайдаланыңыз. KillerBench компьютерді, орнатуды жоспарлаған қолданбаларды және оған бергіңіз келетін атауды қарап шығады, содан кейін әр өзгерісті жасайтын қорғалған құралдарды көрсетеді.

Бастапқы күйден бастау

  1. Диагностика бөлімінен Жүйені толық тексеру іске қосып, есепті компьютердің бастапқы күйінің жазбасы ретінде сақтаңыз.
  2. Күтудегі жаңартуларды орнатыңыз. Қайсыбірі сәтсіз болса, Windows Update-ті түзету бетін қараңыз.

Қолданбалар мен конфигурацияны қарап шығу

  1. Дайындау бөлімін ашып, Дайындау таңдаңыз.
  2. Баптауды жоспарлаған қолданбалар мен конфигурация топтарын таңдап, Диагнозды іске қосу түймесін басыңыз. Қарап шығу оларды бұрыннан орнатылғанмен салыстырады. KillerBench орнатушыларды жүктемейді және іске қоспайды.
  3. Жеткізушінің орнатушысын іске қоспас бұрын оны пәрмен жолынан тексеріңіз. KillerBench оған сол жеткізушінің нақты ұйым атауымен берілген жарамды қолтаңбасы болғанда ғана сенеді.

Компьютерге ат беру

  1. Компьютер атауы таңдап, атауды енгізіңіз және оны ағымдағы сәйкестендіргішпен және домендегі рөлмен салыстырып қарап шығу үшін Диагнозды іске қосу түймесін басыңыз.
  2. Жұмыс тобындағы компьютерде атын өзгерту үшін Жаңа тексерулерден кейін осы жұмыс тобы компьютерінің атын өзгерту белгілеңіз. Аяқтау үшін қайта іске қосу қажет.

Қорғау және ретке келтіру

  • Дискіні BitLocker арқылы шифрлаңыз және қалпына келтіру кілтінің сақтық көшірмесін жасаңыз.
  • Windows құпиялылығын арттырыңыз және Қызмет көрсету ішіндегі Windows-ты ретке келтіру қарап шығыңыз.
  • Бәрі орнына келгенде Бір қалпына келтіру нүктесін дайындау арқылы қалпына келтіру нүктесін жасаңыз.

Пәрмен жолынан

killerbench-cli depot-verify-installer chrome C:\Installers\ChromeSetup.exe
killerbench-cli workflow computer-name --name FRONTDESK-01
killerbench-cli restore-point "Baseline after setup" --execute

workflow және restore-point қараңыз.

Қатысты

  • Дайындау бөлімі
  • Алғашқы диагностика

KillerBench дәлелдері скриптте, RMM тапсырмасында немесе қашықтағы консольде қажет болғанда пәрмен жолын пайдаланыңыз. killerbench-cli жұмыс үстелі қолданбасымен бірдей Engine-ді іске қосады және JSON шығарады.

Бастау

  1. PowerShell-ді killerbench-cli.exe орналасқан жерде ашыңыз немесе оның қалтасын жолға қосыңыз.
  2. Әр пәрменді оның қауіпсіздік шекарасымен тізімдеу үшін killerbench-cli help іске қосыңыз.
  3. 11 ұсынылған диагностика тобын көру үшін killerbench-cli diagnostic-scopes іске қосыңыз.

Сканерлеуді іске қосу және есепті сақтау

killerbench-cli full-scan --report C:\Reports\scan.html --json

full-scan тек диагностика жасайды және --auto-repair параметрін қабылдамайды. Нақты әрекет қажет болса, мақсатты жөндеу жұмыс ағынын пайдаланыңыз. --report қолданба экспорттайтын тақырыпқа сай есепті жазады. Тек кейбір аймақтарды тексеру үшін --scope, ал жұмыс ағыны журналынсыз біріктірілген JSON үшін common-check пайдаланыңыз.

Шығу кодтарын оқу

КодМағынасы
0Алдын ала қарау немесе расталған нәтиже сәтті болды.
1Іске қосу, енгізу немесе журнал қатесі пәрменді тоқтатты.
2Аргументтер танылмады.
3Бұғатталды, сәтсіз болды немесе расталмады.

Тек оқуға арналған пәрменнің 0 кодымен шығуы оның орындалғанын білдіреді, компьютердің сау екенін емес. Қорытындылар үшін JSON оқыңыз.

Өзгеріс жасау

Компьютерді өзгерте алатын әр пәрмен әдепкі бойынша алдын ала қарау көрсетеді. Алдын ала қарауды оқып, сол пәрменді --execute арқылы іске қосыңыз. Сұрау үзілсе, сәйкес -recover пәрменін іске қосыңыз; ол нақты нәтижені хабарлайды және өзгерісті ешқашан қайталамайды.

killerbench-cli dhcp-renew
killerbench-cli dhcp-renew --execute
killerbench-cli dhcp-renew-recover

Ескі нәтижелерді қайта ашу

killerbench-cli workflow-journal C:\Users\me\AppData\Local\KillerBench\journal.json
killerbench-cli workflow-report journal.json report.html --include-repairs

ЖИ көмекшісінен пайдалану

KillerMCP Құрылғылар диспетчері мен Windows қате кодтарын іздеу үшін орнатылған CLI-ды шақыра алады.

Қатысты

  • Пәрмен жолы анықтамасы
  • Engine әзірлеуші нұсқаулығы
  • Ақауларды жою

Бөлімдер

Әр сапар диагностикадан басталуы керек. Әр құрал компьютерді оқып, есеп жазады. Мұнда ештеңе Windows-ты өзгертпейді. Әдепкі құрал, жүйені толық тексеру, тек оқуға арналған кең тексерулер жиынын орындап, назар аударуды қажет ететінді маңыздылығы бойынша реттейді.

Қадамдық нұсқаулықтар: Апаттар мен көк экрандарды зерттеу және Жүйелік файлдарды жөндеу.

Осы бөлімдегі құралдар

Әуелі компьютерді тексеріп, содан кейін есептен назар аударуды қажет ететінді және келесі қауіпсіз қадамды оқыңыз.

Жүйені толық тексеру

49 диагностика аймағын тексереді және орнатылған жөндеу рецептерін ағымдағы дәлелдер бойынша бағалайды. Тексерулер бірнеше минутқа созылуы мүмкін. Жүйені толық тексеру тек диагностикаға арналған. Жаңа алғышарттарды қарап шыққаннан кейін бір қолдау көрсетілетін әрекетті таңдап, растау үшін тар бағытталған жөндеу жұмыс ағынын пайдаланыңыз. Бұрынғы, сақтық көшірме және тасымал лездік көшірмелері тек оқуға арналған. Дамп мазмұны ашылмайды. Кір битті тексеру жөндеуді немесе қайта іске қосуды жоспарламайды. Бұл тексеру жаңартуларды орнатпайды, драйверлерді өзгертпейді, файлдарды жоймайды және жабдықты толық сынамайды.

Негізгі көрсеткіштер

Қолжетімді жадты, провайдер хабарлаған диск күйін және BitLocker қорғау күйін түсіреді, содан кейін ағымдағы көрсеткіштерді құрылғы мәселелерімен, сенімділік тарихымен, жабдық қатесінің жазбаларымен, апат дәлелдерімен, күтпеген жұмысты аяқтаулармен және Windows жадын диагностикалау нәтижелерімен салыстырады. Қайта іске қосу көрсеткіштері, жүйелік дискідегі бос орын, құқықтарды көтеру және жаңарту қызметінің конфигурациясы көрінетін болып қалады. Қалпына келтіру құпия сөздері жиналмайды. Бұл жұмыс ағынында жөндеулер іске қосылмайды. Біріктірілген нәтиже жабдықты, бағдарламаларды немесе тұрақтылықты толық сынау емес.

Сенімділік тарихы

Windows сенімділік мониторының соңғы 14 күндегі жазбаларын соңғы қолданба қателерімен және күтпеген жұмысты аяқтау оқиғаларымен бірге оқиды, содан кейін бір шектелген тарихи қорытындыны қайтарады. Бұрынғы жазбалар ағымдағы күйді немесе түпкі себепті анықтамайды. Ешқандай жөндеу таңдалмайды және ешқандай қолданба, қызмет немесе параметр өзгертілмейді.

Іске қосу өнімділігі

Windows-тың іске қосылу және жұмысты аяқтау өнімділігі оқиғаларының соңғы 14 күндегі метадеректерін оқиды, тек провайдер сәйкестендіргішін және шектелген сандық ұзақтық өрістерін сақтайды, содан кейін оларды қолдау көрсетілетін күтудегі қайта іске қосу көрсеткіштерімен салыстырады. Жолдар, процесс атаулары, тіркелгілер және оқиғаның басқа жүктемесі дәлелдер сақталмас бұрын жойылады. Бұрынғы баяулау жазбалары ағымдағы тар жерді анықтамайды және іске қосу, қызмет, қолданба, драйвер, тапсырма, қуат, қайта іске қосу немесе саясат өзгерістеріне негіз болмайды.

Жабдық қателерінің тарихы

Windows Hardware Error Architecture пен жад диагностикасының соңғы 14 күндегі тарихын, Plug and Play құрылғыларының ағымдағы мәселелерін, физикалық дискілердің күйін және провайдердің сенімділік есептегіштерін оқиды, содан кейін жабдық туралы бір шектелген қорытындыны қайтарады. Жазбалар олардың жүктемесімен, микробағдарлама диагностикасымен және жеткізушінің жабдық сынақтарымен салыстыруды қажет етеді. Ақаулы компонент немесе түпкі себеп шығарылмайды, жөндеу таңдалмайды және ешқандай жабдық, микробағдарлама, драйвер, диск, пул, том, файл, қызмет, қуат, қайта іске қосу немесе параметр өзгертілмейді.

Драйвер орнату тарихы

Windows SetupAPI құрылғы орнату тарихының сақталған соңғы бөлігін оқиды, сәтсіз бөлімдерді ағымдағы нақты Plug and Play сәйкестендіргіштерімен салыстырады және бір шектелген қорытындыны қайтарады. Журналдың бұрынғы бөлімдері құрылғының әлі бар екенін немесе ақаудың ағымдағы екенін дәлелдемейді. Ешқандай драйвер орнатылмайды, жойылмайды, кері қайтарылмайды немесе жаңартылмайды.

Жүйені қалпына келтіру нүктелері

Жүйені қалпына келтірудің 256-ға дейінгі қолжетімді нүктесін тізімдейді, нүкте жасаудың айқын жарамдылығын қарап шығады және дайындық туралы бір шектелген қорытындыны қайтарады. Тізім қорғаудың әр томда қосулы екенін немесе қалпына келтірудің сәтті болатынын дәлелдемейді. Диагностика кезінде ешқандай қалпына келтіру нүктесі жасалмайды, жойылмайды немесе қолданылмайды.

Windows қалпына келтіру ортасы

Windows қалпына келтіру ортасының ағымдағы конфигурациясын REAgentC арқылы оқиды, қосулы жергілікті орынды ағымдағы нақты дискімен және бөліммен салыстырады және дайындық туралы бір шектелген қорытындыны қайтарады. Қосымша автоматты жөндеу өшірілген бар конфигурацияны қосып, содан кейін оның хабарланған күйін растай алады. Қалпына келтіру бейнесі жүктелмейді, көшірілмейді немесе ауыстырылмайды, қалпына келтіру режимінде жүктелу басталмайды және Windows қайта іске қосылмайды. Қосулы күй мен бөлімнің болуы қалпына келтіру бейнесі осы компьютерді жүктей немесе жөндей алатынын дәлелдемейді.

Windows белсендіру

Windows лицензиясының ағымдағы күйін өнім кілттерін толық немесе ішінара жинамай оқиды, бағдарламалық жасақтаманы қорғаудың соңғы жеті күндегі ескерту, қате және маңызды оқиғаларының тазартылған метадеректерін сақтайды, содан кейін бір шектелген жұмыс қорытындысын қайтарады. Оқиға жүктемесі дәлелдер сақталмас бұрын жойылады. Ағымдағы лицензиялау Licensed деп хабарлағанда, бұрынғы жазбалар контекст ретінде қалады. Ешқандай белсендіру, өнім кілті, токен, лицензия, тіркелгі, қызмет немесе саясат әрекеті таңдалмайды. Провайдер күйі мен оқиғалар тарихы жазылым құқығын, белсендіру серверінің қолжетімділігін, токен қоймасының тұтастығын, болашақтағы жарамдылықты немесе түпкі себепті дәлелдемейді.

Windows қызметтері

Орнатылған қызметтердің атауларын, көрсетілетін атауларын, күйлерін, іске қосу режимдерін және құпиялылыққа байланысты шектелген қалпына келтіру әрекеттерінің түрлерін тіркелгілерді, орындалатын файл жолдарын, қалпына келтіру пәрмендерін немесе қайта жүктеу хабарларын жинамай тізімдейді. Іске қосу режимдерінің үйлесімділігін, тікелей тәуелділіктердің сәйкестендіргіштері мен циклдерін қарап шығады, нақты күтудегі күйлерді қайталайды, қолдау көрсетілетін қызметтерді және тоқтатылған қызметтердің тәуелділіктерін тексереді, содан кейін бір нақты қызмет атауы немесе бірегей көрсетілетін атау болғанда ғана Қызметтерді басқару реттеушісінің соңғы ақауларын салыстырады. Жүктеу реті топтарының пайдаланылуы құрамын ашпай есептеледі, ал анық емес сәйкестендіргіштер шешілмеген күйде қалады. Сұраныс бойынша іске қосылатын тоқтатылған қызметтер қалыпты болуы мүмкін. Ешқандай қызмет іске қосылмайды және іске қосу, тәуелділік пен қалпына келтіру параметрлері сақталады. Нақты функция қалпына келтіруді қажет еткенде, Жөндеу бөліміндегі сәйкес жұмыс ағынын пайдаланыңыз.

Қолданба қателері

Қолданба журналының соңғы қате және маңызды оқиғаларын сенімділік мониторының шектелген тарихымен бірге оқиды, содан кейін тұрақтылық тарихы туралы бір қорытындыны қайтарады. Бұрынғы жазбалар ағымдағы ақауды немесе түпкі себепті дәлелдемейді және тек тарырақ диагностикаға бағыттайды. Ешқандай қолданба тоқтатылмайды, жөнделмейді, жойылмайды немесе қайта бапталмайды.

Дисплей құрылғылары

Графикалық адаптерлер мен мониторлардың хабарланған құрылғы қателерін, жабдық идентификаторларын және орнатылған драйвер нұсқаларын тексереді. Драйвер орнату, құрылғыны қалпына келтіру немесе ажыратымдылықты өзгерту жоқ. Сурет сапасы мен физикалық қосылымдар сыналмайды.

Енгізу құрылғылары

Пернетақта, тінтуір және HID құрылғыларының қателерін және драйверлер тізімін тексереді. Пернелерді басу жазылмайды, құрылғылар қалпына келтірілмейді, драйверлер өзгертілмейді. Енгізудің физикалық жұмысы сыналмайды.

Құрылғы мәселелері

Құрылғылардың барлық сыныптары бойынша нөлдік емес Plug and Play конфигурация қате кодтарын табады, содан кейін бар құрылғылардың дәлелдерін драйвер орнату, құрылғыны баптау және Plug and Play туралы шектелген SetupAPI тарихымен салыстырады. Тек бұрынғы жазбалар ағымдағы ақауды анықтамайды. Жабдықты, драйверлерді немесе конфигурацияны өзгертпей, құрылғының нақты сәйкестендіргішін және мақұлданған драйвер дәлелдерін қарап шығыңыз. Жоқ құрылғылар мен физикалық жұмыс тексерілмейді.

Жөндеу бірдеңені түзете алатын құралдарды жинайды. Олардың әрқайсысы әуелі диагностика жасайды. Жөндеу жаңа дәлелдер ол түзететін нақты мәселені көрсеткенде ғана ұсынылады және Расталған мәселелерді автоматты жөндеу қосқаннан кейін немесе жеке жөндеуді өзіңіз растағаннан кейін ғана орындалады. Әр жөндеу журналға жазылады және кейін расталады.

Қадамдық нұсқаулықтар: Жүйелік файлдарды жөндеу және Windows Update-ті түзету.

Автоматты және қолмен жөндеу

Расталған мәселелерді автоматты жөндеу диагностика құралына сканерлеуден кейін қажеттілігін дәлелдеген жөндеулерді орындауға мүмкіндік береді. Әдепкі бойынша ол өшірулі.

Жеке қызмет көрсету жөндеуі үшін Кеңейтілген: журналдар және қолмен жөндеулер ашып, Жөндеулер таңдаңыз. Компоненттер қоймасы (DISM) немесе Жүйелік файлдар (SFC) таңдап, алдын ала қарауды оқыңыз, Осы жөндеуді осы компьютерде іске қосу белгілеңіз және Жөндеуді іске қосу түймесін басыңыз. Кез келген өзгерістің алдында және одан кейін не болатынын Өзгерістер қалай қауіпсіз болады бетінен қараңыз.

Осы бөлімдегі құралдар

Мұны диагностика мәселені анықтағаннан кейін пайдаланыңыз. Жөндеулер расталған дәлелдер мен айқын мақұлдауды қажет етеді.

Негізгі Windows қызметтері

Қуат, Plug and Play, Пайдаланушылар реттеушісі, Топтық саясат клиенті, Желілік сақтау интерфейсі қызметі, RPC соңғы нүктелерін салыстырушы, Қашықтағы процедураны шақыру (RPC), DCOM сервер процесін іске қосушы, Фондық тапсырмалар инфрақұрылымы қызметі және CoreMessaging қызметтерін бірге тексереді. Қосымша қалпына келтіру іске қосу кезеңінен және толық тәуелділік тексерулерінен кейін жаңа дәлелдер тоқтатылғанын растаған нақты қосулы автоматты қызметтерді ғана іске қосады. Сұраныс бойынша іске қосылатын қызметтер әрекетсіз болғанда өзгеріссіз қалады. Қуат жоспарлары, құрылғылар, драйверлер, тіркелгілер, тіркелгі деректері, профильдер, саясат, адаптерлер, мекенжайлар, маршруттар, DNS, брандмауэр конфигурациясы, тіркеулер, соңғы нүктелер, тапсырма тіркеулері, қолданба деректері, қызмет рұқсаттары және іске қосу түрлері сақталады. Саясатты жаңарту, құрылғыларды сканерлеу, тіркелгі әрекеті, желіні өзгерту, қуат параметрін өзгерту, тіркеуді өзгерту немесе тапсырманы іске қосу сұралмайды. Растау функциялардың басынан аяғына дейінгі жұмысын емес, тек қызметтердің тұрақты күйін қамтиды.

Жүйелік файлдар

Windows қызмет көрсету пакеттерінің, қосымша компоненттер мен мүмкіндіктердің күйлерін шектелген түрде тізімдейді, алғышарттарды тексереді, қорғалған жүйелік файлдарды сканерлейді және тікелей тексеру зақымдануды растағанда ғана SFC-ті автоматты түрде таңдайды. Пакеттердің, компоненттердің немесе мүмкіндіктердің күтудегі күйлері қарап шығуды талап етеді, бірақ орнатуға, жоюға, тазалауға, кері қайтаруға, қосуға немесе өшіруге негіз болмайды.

WMI қоймасы

WMI қызметінің қолжетімділігін, содан кейін қойманың үйлесімділігін тексереді. Автоматты жөндеу жарамды тоқтатылған қызметті іске қосып, расталған зақымданудан деректерді құтқара алады, содан кейін әр нәтижені растайды. Өшірілген қызмет параметрлері сақталады. Оқылатын тіркеулер біріктіріледі; оқылмайтын мазмұн провайдерді қайта орнатуды қажет етуі мүмкін. Басқару клиенттері үзілуі мүмкін. Қалпына келтіру, жою немесе автоматты кері қайтару жоқ.

Windows жүйелік хабарландырулары

Қызметтерді басқару реттеушісінің соңғы тарихын оқиды, содан кейін COM+ оқиғалар жүйесі мен Жүйелік оқиғалар туралы хабарландыру қызметін бірге тексереді. Қосымша қалпына келтіру SENS-ті іске қоспас бұрын COM+ оқиғалар жүйесінің дайындығын растайды. Бар кіру, желі, қуат және COM+ хабарландырулары ағымдағы конфигурация бойынша жалғасуы мүмкін. COM+ каталогтары, жазылымдар, хабарландыру тіркеулері, тұтынушылар, тіркелгілер, рұқсаттар, қалпына келтіру параметрлері, саясат және іске қосу түрлері сақталады. Ешқандай жазылым, тіркеу, тұтынушы, тіркелгі, рұқсат немесе саясат өзгертілмейді. Растау хабарландыруларды басынан аяғына дейін жеткізуді емес, тек қызметтердің тұрақты күйін қамтиды.

Диагностика саясаты қызметі

Диагностика саясатының шектелген жұмыс тарихын, нақты қызмет ақауларының тарихын және қызметтің ағымдағы дайындығын қарап шығады. Толық емес дәлелдердің басымдығы бар. Бұрынғы жазбалар қызметті қалпына келтіруге немесе ақауларды жою әрекетіне негіз бола алмайды. Қосымша қалпына келтіру жаңа тәуелділік тексерулерінен кейін тек қосулы, тоқтатылған нақты қызметті іске қосады. Бар диагностика сценарийлері жалғасуы мүмкін. Саясат, ақауларды жою деректері және іске қосу түрі сақталады. Ешқандай ақаулар жою құралы немесе ұсынылған түзету іске қосылмайды. Растау ақауды анықтауды, диагностиканың аяқталуын немесе жөндеу нәтижесін емес, тек қызметтің тұрақты күйін қамтиды.

Windows қате есептері

Апат дампының конфигурациясын, дамп файлдарының шектелген метадеректерін, соңғы жүйелік апат есептерін, Windows қате есептері қызметінің нақты ақаулар тарихын және қызметтің ағымдағы дайындығын қарап шығады. Бұрынғы есептер ағымдағы ақауды немесе түпкі себепті анықтамайды және қалпына келтіруге негіз бола алмайды. Қосымша қалпына келтіру жаңа тәуелділік тексерулерінен кейін тек қосулы, тоқтатылған нақты қызметті іске қосады. Кезектегі бар есептер ағымдағы саясат бойынша жалғасуы мүмкін. Есеп мұрағаттары, дамптар, келісім, жүктеп жіберу саясаты және іске қосу түрі сақталады. Жүктеп жіберу немесе жою сұралмайды. Растау есепті жасауды, жүктеп жіберуді, жеткізуді, мәселені шешуді немесе апат диагностикасын емес, тек қызметтің тұрақты күйін қамтиды.

Windows оқиғаларын жинаушы

Windows оқиғаларын жинаушы жазылымдарының шектелген тізімін, нақты қызмет ақауларының тарихын және қызметтің ағымдағы дайындығын қарап шығады. Бос тізім әдейі болуы мүмкін, ал жазылымдар саны немесе бұрынғы ақаулар қалпына келтіруге негіз бола алмайды. Қосымша қалпына келтіру жаңа тәуелділік тексерулерінен кейін тек қосулы, тоқтатылған нақты қызметті іске қосады. Бар жазылымдар оқиғаларды қашықтан жинауды жалғастыруы мүмкін. Жазылымдар, қайта жіберілген оқиғалар, тіркелгі деректері, арна параметрлері, саясат және іске қосу түрі сақталады. Растау көздердің қолжетімділігін, аутентификацияны, қашықтан жеткізуді, оқиғалардың жаңалығын немесе жазылымдардың күйін емес, тек қызметтің тұрақты күйін қамтиды.

Windows оқиғалар журналы

Төрт диагностикалық арнаның қосулы күйін, сақтау режимін, ағымдағы өлшемін, бапталған шегін, жазбалар санын және толу деңгейін тексереді, содан кейін Windows оқиғалар журналы қызметінің қолжетімділігін тексереді. Автоматты жөндеу тәуелділіктерді тексергеннен кейін тоқтатылған, қосулы қызметті іске қосып, жұмыс күйін растай алады. Бөлек расталатын мақсатты әрекет хабарланған барлық басқа параметрлерді сақтай отырып, бір нақты өшірілген басқарылмайтын диагностикалық арнаны қоса алады. Журналдар, арна рұқсаттары, сақтау, өлшем шектері, іске қосу түрлері және басқарылатын параметрлер сақталады. Оқиғаларды сәтті жеткізу мен мұрағат сыйымдылығы тексерілмеген күйде қалады.

Windows уақыт қызметі

Windows уақыт конфигурациясын, қызметін және үндестіруін тексереді. Ағымдағы күй нақты тоқтатылған қызмет қатесін хабарлағанда және саясат, режим мен тәуелділіктің жаңа тексерулерінен өткенде, автоматты жөндеу W32Time-ды іске қосып, содан кейін қайта үндестіруді сұрап, жаңа күйді растай алады. Бұл бұрыннан бапталған көздерді пайдаланып сағатты түзетуі мүмкін. Іске қосу түрі, көз конфигурациясы және басқарылатын параметрлер сақталады.

Тапсырмалар жоспарлағышы қызметі

Жоспарланған тапсырмалардың күйін, орындалу нәтижелерін және өткізіп алынған іске қосулар санын шектелген түрде тізімдейді, содан кейін қызметтің ағымдағы қолжетімділігін тексермес бұрын оларды Тапсырмалар жоспарлағышы қызметінің нақты ақаулар тарихымен біріктіреді. Тапсырмалар туралы қорытындылар мен қызметтің бұрынғы ақаулары қызметті іске қосуға негіз бола алмайды. Қосымша қалпына келтіру жаңа тәуелділік тексерулерінен кейін тек қосулы, тоқтатылған нақты қызметті іске қосады. Бар қосулы тапсырмалар өткізіп алынған триггерлерді қоса, бапталған тіркелгілерімен басталуы мүмкін. Ешқандай тапсырма анықтамасы, субъект, тіркелгі деректеріне сілтеме, саясат немесе іске қосу түрі өзгертілмейді және ешқандай тапсырма тікелей іске қосылмайды немесе жойылмайды. Растау әрекеттердің сәттілігін, тіркелгі деректерінің жарамдылығын немесе тапсырмалардың болашақ нәтижелерін емес, тек қызметтің тұрақты күйін қамтиды.

Пайдаланушы профилі қызметі

Пайдаланушы профилі қызметінің қолжетімділігін тексереді. Қосымша қалпына келтіру жаңа тәуелділік тексерулерінен кейін тек қосулы, тоқтатылған нақты қызметті іске қосады. Бар кіру және профиль сұраулары жалғасуы мүмкін. Профиль қалталары, тізілім бұталары, рұқсаттар, профильдер тізіміндегі тіркеулер, тіркелгі деректері, пайдаланушы деректері, саясат, қызмет рұқсаттары және іске қосу түрі сақталады. Ешқандай профиль әрекеті сұралмайды. Растау кіруді, профильді жүктеуді немесе пайдаланушы деректеріне қатынасты емес, тек қызметтің тұрақты күйін қамтиды.

Сақтық көшірме қызметтері

Томның көлеңкелі көшірмесі, Microsoft бағдарламалық көлеңкелі көшірме провайдері, Windows сақтық көшірмесі және блок деңгейіндегі сақтық көшірме механизмі қызметтерін тексереді, содан кейін VSS жазушыларының күйін, тіркелген провайдер түрлерін, ағымдағы лездік көшірмелерді және көлеңкелі сақтау орнының бөлінуін оқиды. Сұраныс бойынша іске қосылатын тоқтатылған қызметтер әрекетсіз болғанда қалыпты болуы мүмкін. Қосымша қалпына келтіру тәуелділік тексерулерінен кейін тек тоқтатылған автоматты қызметтерді іске қосады, содан кейін жұмыс күйін растайды. Бар жоспарланған немесе үзілген сақтық көшірме жұмысы жалғасуы мүмкін. Өшірілген және сұраныс бойынша іске қосу параметрлері, лездік көшірмелер, көлеңкелі сақтау орны, провайдер тіркеулері, сақтық көшірме жоспарлары, каталогтар, кестелер, мақсатты орындар, тіркелгі деректері мен сақтау мерзімі сақталады. Ешқандай сақтық көшірме таңдалмайды немесе қайта бапталмайды, ешқандай қызмет қайта іске қосылмайды және ешқандай лездік көшірме немесе каталог жойылмайды. Провайдер тіркеуі, жазушы күйі, сақтау орнының бөлінуі және қызметтің тұрақты күйі сақтық көшірменің аяқталуын, мақсатты орынға қатынасты немесе қалпына келтірудің сәттілігін растамайды.

Жаңартулар Windows Update-ті, оның артындағы қызметтерді және компоненттер қоймасын қамтиды. Не орнатылғанын, не күтуде екенін және жаңартудың неге сәтсіз болатынын көре аласыз, сондай-ақ орнатуға таңдамас бұрын қолжетімді жаңартуларды қарап шыға аласыз.

Қадамдық нұсқаулықтар: Windows Update-ті түзету және Жүйелік файлдарды жөндеу.

Осы бөлімдегі құралдар

Қызмет көрсету әрекетін бақылаңыз, қолжетімді жаңартуларды қарап шығыңыз және Windows Update тізбегін жөндеңіз.

Қызмет көрсету әрекеті мониторы

Windows Update пен Setup-тің шектелген қызмет көрсету әрекетін бір немесе бірнеше лездік көшірмеде бақылайды. Параметрлер жаңарту аралығын және жаңарту оқиғалары, жаңарту тарихы, Windows Update нақты жоспарланған тапсырмасы, қызметтердің нақты күйлері, қайта іске қосу көрсеткіштері, ағымдағы тіркелгінің фондық тасымалдары, Delivery Optimization әрекеті және құпиялылыққа байланысты шектелген Windows Installer әрекеті қосылатынын басқарады. Процесс идентификаторлары, пәрмен жолдары, пайдаланушылар мен жолдар алынып тасталады. Әрекет барысты, аяқталуды, тоқтап қалуды немесе ақауды дәлелдемейді. Ешқандай жаңарту, орнату, тасымал, тапсырма, қызмет, процесс, саясат, қайта іске қосу немесе жөндеу әрекеті сұралмайды.

Қолжетімді жаңартулар

Бапталған көзді, Windows Update немесе бұрыннан тіркелген Microsoft Update қызметін пайдаланып, таңдалған бағдарлама мен драйвер жаңартуларын табады. Табу алдында көздің дайындығы тексеріледі. Табу ештеңе орнатпайды, лицензияны қабылдамайды, көзді тіркемейді және саясатты өзгертпейді. Таңдалған жаңартуларды кейін, бөлек, тек растау құсбелгісін қойғаннан кейін ғана орнатуға болады. Бұл қызмет көрсету жөндеуінен бөлек.

Windows Update

Windows қызмет көрсету пакеттерінің, қосымша компоненттер мен мүмкіндіктердің күйлерін шектелген түрде тізімдейді, қайта іске қосу көрсеткіштерін, бос орынды және жаңарту қызметтерін тексереді, Delivery Optimization-ді іске қоспай бақылайды, содан кейін компоненттер қоймасы мен қорғалған жүйелік файлдарды сканерлейді. Пакеттердің, компоненттердің немесе мүмкіндіктердің күтудегі күйлері қарап шығуды талап етеді, бірақ компонент әрекетіне негіз болмайды. Автоматты жөндеу тоқтатылған және автоматты түрде іске қосылуға бапталған Windows Update, BITS, Криптография қызметтері, Windows модульдерін орнатушы және Update Orchestrator қызметтерін іске қоса алады. Тоқтатылған, сұраныс бойынша іске қосылатын қызмет іске қосылмайды, тек хабарланады. Update Orchestrator-ды іске қосу ағымдағы саясат бойынша бар жоспарланған жаңарту әрекетін жалғастыруы мүмкін. Пакеттер, қосымша компоненттер, мүмкіндіктер, Delivery Optimization кэші, тең түйіндер, өткізу жолағы, саясат, көзді тіркеу, кестелер мен іске қосу параметрлері сақталады. DISM немесе SFC зақымданудың тікелей дәлелін қажет етеді. Бұл жұмыс ағыны ешқандай жаңартуды таңдамайды немесе мақұлдамайды.

Windows Update қызметі

Қосылымдарды, DNS-ті, маршруттарды, сымсыз желіні, ортақ пайдалануды және қашықтан қатынасты тексеріңіз.

Желі

Адаптерлерді, мекенжай күйі мен шығу тегін, шлюздерді, DNS конфигурациясын, әрекет етуші DNS аттар кеңістігі саясатын, TCP параметрлерін, Winsock протоколдары мен аттар кеңістігі провайдерлерінің жергілікті каталог құрылымын, IP маршруттау кестесін және Hosts файлының сәйкестіктерін тексереді. Автоматты жөндеу қосулы DNS клиенті, DHCP клиенті, SMB клиенті, желі орнын анықтау, желілер тізімі және IP көмекшісі қызметтерін іске қоса алады және жарамды IPv4 мекенжайы жоқ қосылған физикалық DHCP адаптерлерінің жалға алуын жаңарта алады. Желіні анықтау қызметтерін іске қосу желі сәйкестендіргішін қайта есептеп, бар басқа брандмауэр профилін қолдануы мүмкін. IP көмекшісі бар IPv6 өтпелі, порт проксиі және желі хабарландыруы мүмкіндіктерін белсендіруі мүмкін. Қызметті қалпына келтіру атауды сәтті шешуді, маршрут таңдауды, желіні анықтауды немесе туннель жұмысын емес, жұмыс күйін растайды. Маршруттар, Hosts жазбалары, DNS серверлері, профильдер, брандмауэр ережелері, Winsock провайдерлері, өтпелі конфигурация, іске қосу түрлері және саясат сақталады. Жаңарту жалға алынған мекенжайларды өзгертіп, қосылымдарды үзуі мүмкін. Статикалық параметрлер мен виртуалды адаптерлер сақталады. Шлюздің нақты ICMP жауаптары интернеттің қолжетімділігін растамайды.

Сымсыз желі

Желі құрылғылары мен WLAN AutoConfig қызметінің қолжетімділігін тексереді. Қосымша қалпына келтіру тәуелділік тексерулерінен кейін тек қосулы, тоқтатылған қызметті іске қосады; сақталған профильдер автоматты түрде қайта қосылуы мүмкін. Профильдер, тіркелгі деректері, саясат, радио параметрлері және іске қосу түрлері сақталады. Адаптерді қалпына келтіру немесе драйвер орнату жоқ. Растау сымсыз аутентификацияны немесе қосылымды емес, жұмыс күйін қамтиды.

Сымды аутентификация (802.1X)

802.1X талап ететін желілер үшін желі құрылғылары мен Wired AutoConfig қызметін тексереді. Қосымша қалпына келтіру тәуелділік тексерулерінен кейін тек қосулы, тоқтатылған қызметті іске қосады. Бар аутентификация профильдері белсендіріліп, желіге қатынасты өзгертуі мүмкін. Сертификаттар, тіркелгі деректері, профильдер, саясат және іске қосу параметрлері сақталады. Растау аутентификацияны немесе қосылымды емес, тек жұмыс күйін қамтиды.

Желі қосылымдары

Желі профильдерінің ағымдағы тағайындауларын шектелген түрде, нақты қызмет ақауларының тарихын және Желі қосылымдары қызметінің ағымдағы дайындығын қарап шығады. Толық емес дәлелдердің басымдығы бар. Жалпы профильдер мен бұрынғы ақаулар контекст ретінде қалады және қалпына келтіруге немесе желіні өзгертуге негіз бола алмайды. Қосымша қалпына келтіру жаңа тәуелділік тексерулерінен кейін тек қосулы, тоқтатылған нақты қызметті іске қосады. Бар желіні басқару интерфейстері жалғасуы мүмкін. Адаптерлер, мекенжайлар, маршруттар, DNS параметрлері, қосылым профильдері, тіркелгі деректері, брандмауэр конфигурациясы, саясат және іске қосу түрі сақталады. Ешқандай қосылым немесе желі параметрі өзгертілмейді. Растау адаптер жұмысын, мекенжай тағайындауды, маршруттауды, атауды шешуді немесе қосылымды емес, тек қызметтің тұрақты күйін қамтиды.

WinHTTP автоматты прокси

Сақталған WinHTTP әдепкі мәндерін, ағымдағы тіркелгінің интернет параметрлерін, нақты қызмет ақауларының тарихын және WinHTTP автоматты прокси қызметінің ағымдағы дайындығын қарап шығады. Толық емес дәлелдердің басымдығы бар. Прокси конфигурациясы мен бұрынғы ақаулар қызметті қалпына келтіруге немесе анықтауға негіз бола алмайды. Сұраныс бойынша іске қосылатын тоқтатылған қызмет қалыпты болуы мүмкін. Дәл осы құрал таңдалғанда қосымша қалпына келтіру жаңа тәуелділік тексерулерінен кейін тек тоқтатылған қосулы қызметті іске қоса алады. Бар қолданбалар ағымдағы параметрлер бойынша WPAD немесе PAC анықтауын жалғастыруы мүмкін. Прокси анықтамалары, PAC URL мекенжайлары, тіркелгі деректері, желі параметрлері, брандмауэр конфигурациясы, саясат, қызмет рұқсаттары және іске қосу түрі сақталады. Ешқандай URL жүктелмейді және ешқандай прокси немесе желі параметрі өзгертілмейді. Растау анықтауды, қолжетімділікті, аутентификацияны, саясат иелігін немесе қолданбалардың пайдалануын емес, тек қызметтің тұрақты күйін қамтиды.

Windows қосылымдар реттеушісі

Желі профильдерінің ағымдағы тағайындауларын шектелген түрде, нақты қызмет ақауларының тарихын және Windows қосылымдар реттеушісінің ағымдағы дайындығын қарап шығады. Толық емес дәлелдердің басымдығы бар. Жалпы профильдер мен бұрынғы ақаулар контекст ретінде қалады және қалпына келтіруге немесе қосылу шешіміне негіз бола алмайды. Қосымша қалпына келтіру жаңа тәуелділік тексерулерінен кейін тек қосулы, тоқтатылған нақты қызметті іске қосады. Windows бар профильдер мен саясат бойынша автоматты қосылу шешімдерін жалғастыруы мүмкін. Адаптерлер, профильдер, тіркелгі деректері, трафикті шектеу, құн, роуминг, брандмауэр, VPN және аутентификация параметрлері мен іске қосу түрі сақталады. Ешқандай профиль, адаптер немесе параметр өзгертілмейді. Растау профильдердің қолданылуын, қосылымды таңдауды, аутентификацияны, маршруттауды, атауды шешуді немесе қосылымды емес, тек қызметтің тұрақты күйін қамтиды.

Желіні баптау қызметі

Адаптерлер мен протоколдардың ағымдағы байланыстыруларын шектелген түрде, нақты қызмет ақауларының тарихын және Желіні баптау қызметінің ағымдағы дайындығын қарап шығады. Толық емес дәлелдердің басымдығы бар. Байланыстыру күйі мен бұрынғы ақаулар қызметті қалпына келтіруге немесе баптауды өзгертуге негіз бола алмайды. Қосымша қалпына келтіру жаңа тәуелділік тексерулерінен кейін тек қосулы, тоқтатылған нақты қызметті іске қосады. Бар күтудегі желі баптауы Windows саясаты бойынша жалғасуы мүмкін. Адаптерлер, драйверлер, драйвер пакеттері, байланыстырулар, мекенжайлар, маршруттар, DNS параметрлері, профильдер, тіркелгі деректері, брандмауэр конфигурациясы, саясат және іске қосу түрі сақталады. KillerBench ешқандай драйвер немесе конфигурация өзгерісін таңдамайды. Растау адаптердің қолжетімділігін, драйвердің жарамдылығын, баптаудың аяқталуын, мекенжай тағайындауды, маршруттауды, атауды шешуді немесе қосылымды емес, тек қызметтің тұрақты күйін қамтиды.

Файлдарды ортақ пайдалану (SMB)

Windows SMB серверінің қолжетімділігін тексереді. Қосымша қалпына келтіру жаңа тәуелділік тексерулерінен кейін тек қосулы, тоқтатылған Server қызметін іске қосады. Бар файл мен принтер ортақ ресурстары ағымдағы рұқсаттар мен брандмауэр саясаты бойынша қолжетімді болуы мүмкін. Ешқандай ортақ ресурс, рұқсат, SMB параметрі, брандмауэр ережесі, тіркелгі деректері, саясат немесе іске қосу түрі өзгертілмейді. Растау клиенттің қатынасын немесе файл тасымалын емес, тек қызметтің тұрақты күйін қамтиды.

Қашықтан қатынас қосылымдарының реттеушісі

Құпияларды жинамай, ағымдағы тіркелгінің VPN профилі конфигурациясын шектелген түрде, нақты қызмет ақауларының тарихын және Қашықтан қатынас қосылымдарының реттеушісінің ағымдағы дайындығын қарап шығады. Бос тізім әдейі болуы мүмкін, ал профильдердің болуы, қосылым белгілері немесе бұрынғы ақаулар қалпына келтіруге немесе қосылу әрекетіне негіз бола алмайды. Қосымша қалпына келтіру жаңа тәуелділік тексерулерінен кейін тек қосулы, тоқтатылған нақты қызметті іске қосады. Бар dial-up және VPN сұраулары жалғасуы мүмкін. Қосылым профильдері, тіркелгі деректері, маршруттар, адаптерлер, аутентификация параметрлері, саясат және іске қосу түрі сақталады. Ешқандай қосылым басталмайды. Растау профильдердің қолданылуын, сервердің қолжетімділігін, аутентификацияны, туннель келісімін, маршрут орнатуды, атауды шешуді немесе қосылымды емес, тек қызметтің тұрақты күйін қамтиды.

Қашықтағы жұмыс үстелі қызметтері

Қашықтағы жұмыс үстелінің жергілікті қосылуын, желі деңгейіндегі аутентификацияны және тыңдаушы портын, қосылымдар мен сеанстардың шектелген тарихын, нақты қызмет ақауларының тарихын және қызметтің ағымдағы дайындығын қарап шығады. Толық емес дәлелдердің басымдығы бар. Бұрынғы жазбалар қызметті қалпына келтіруге немесе конфигурацияны өзгертуге негіз бола алмайды. Қосымша қалпына келтіру жаңа тәуелділік тексерулерінен кейін тек қосулы, тоқтатылған нақты қызметті іске қосады. Бар тыңдаушы ағымдағы саясат, NLA, брандмауэр ережелері мен рұқсаттар бойынша қолжетімді болуы мүмкін. Қашықтағы жұмыс үстелінің қосылуы, тыңдаушылар, сертификаттар, порттар, брандмауэр ережелері, NLA, рұқсаттар, сеанстар, саясат, қызмет рұқсаттары және іске қосу түрі сақталады. Ешқандай тыңдаушы, брандмауэр ережесі, тіркелгі қатынасы, сертификат немесе сеанс жасалмайды немесе өзгертілмейді. Растау әрекет етуші саясатты, тыңдаушының байланыстыруын, брандмауэр арқылы қатынасты, сертификат сәйкестігін, рұқсаттарды, аутентификацияны, желінің қолжетімділігін, қосылымның сәттілігін немесе сеанс жасауды емес, тек қызметтің тұрақты күйін қамтиды.

TPM бар, бірақ дайын болмаса, Қауіпсіздік бөлімі оны тазаламай дайындай алады. KillerBench TPM-ді ешқашан тазаламайды, өйткені бұл BitLocker мен Windows Hello сақтайтын кілттерді жояды. FIPS алгоритм саясатының ауыстырғышы FIPS бекіткен BitLocker PIN кодтары қажет ұйымдар үшін айқын, кері қайтарылатын жөндеу ретінде қолжетімді.

Осы бөлімдегі құралдар

BitLocker

BitLocker параметрлерін алдын ала қарап, таңдалған томды тексереді. Бұл жұмыс ағыны шифрлауды немесе қалпына келтіру көшірмесін жасауды орындамайды.

Құпиялылық осы компьютердің және KillerBench-ті іске қосқан тіркелгінің құпиялылық параметрлерін оқиды, содан кейін өзіңіз таңдағандарын өзгертуге мүмкіндік береді. Ол Windows Параметрлер қолданбасынан кеңірек: қолданба рұқсаттарын, бұлттық іздеуді және іздеу ерекшеліктерін қамтиды.

Параметрді өзгерту үшін Құпиялылық параметрі басқару элементін пайдаланыңыз. KillerBench параметр саясатқа немесе құрылғыларды басқару жүйесі басқаратын-басқармайтынын тексереді, ағымдағы мәнді жазады, сіз сұраған бір өзгерісті жасайды және растау үшін оны қайта оқиды. Саясатқа тиесілі параметрлер өзгертілмейді.

Параметрлерге жарнама таңдаулары, алмасу буферінің тарихы, камера, микрофон және орналасу сияқты 19 қолданба рұқсаты параметрі, жеке және жұмыс тіркелгілеріне арналған бұлттық мазмұнды іздеу және іздеу ерекшеліктері кіреді.

Қолданба рұқсаттарын, ұсыныстарды, іздеу және жарнама параметрлерін қарап шығыңыз және өзгертіңіз.

Құпиялылық

Осы компьютердің және KillerBench-ті іске қосқан тіркелгінің таңдалған құпиялылық тізілім параметрлерін оқиды. Бөлек айқын басқару элементтері жаңа саясат тексерулерінен, тұрақты дайындықтан және нақты растаудан кейін алмасу буферінің тарихын немесе қолдау көрсетілетін тіркелгі параметрін өзгерте алады. Басқа құпиялылық таңдаулары тек оқуға арналған болып қалады. Тізілімнің лездік көшірмелері нақты әрекет ететін рұқсаттарды немесе саясат иелігін дәлелдемейді.

Дискілерді, томдарды, сақтау кеңістіктерін және дискілерге қызмет көрсету қызметтерін тексеріңіз. Диагностика диск әрекетін таңдамайды; компьютерді өзгертетін кез келген қолдау көрсетілетін әрекет өзінің нақты мақсатын, алғышарттарын және растауын қажет етеді.

Қадамдық нұсқаулықтар: Дискіні тексеру және жөндеу және Дискідегі орынды босату.

Осы бөлімдегі құралдар

Сақтау орны

Дискілердің, бөлімдердің және әріп тағайындалған томдардың шектелген сәйкестендіргіштерін салыстырады, әріп тағайындалған әр том бойынша 10% бос орын қысымын бағалайды, VSS көлеңкелі сақтау орнының бөлінуін және әр томның квота әдепкі мәндерін тексереді, Storage модулі тапсырмаларының ағымдағы барысын қорытындылайды, таңдалған NTFS томын және оның желідегі өзін-өзі қалпына келтіру күйін тексереді және осы компьютердегі диск пен контроллер құрылғыларын тексереді. Сыйымдылық шектері, квота параметрлері мен тапсырма күйлері қарап шығуға арналған дәлелдер болып табылады және тазалауды, өлшемді өзгертуді, квотаны өзгертуді немесе тапсырманы басқаруды таңдамайды. Әріптердің сәйкестендірілуі белгілі бір сәттегі күйді көрсетеді және әр тіркеу жолын қамтымайды. Құрылғы қорытындылары таңдалған томға сәйкестендірілмейді. Әдепкі бойынша Windows томы таңдалады. Ешқандай файл, лездік көшірме, тапсырма немесе драйвер өзгертілмейді, ешқандай параметр өзгертілмейді, ешқандай том ажыратылмайды және қайта іске қосу жоспарланбайды.

Сақтау кеңістіктері

Бастапқы емес сақтау кеңістіктерінің пулдары мен виртуалды дискілерін күйін, жұмыс күйін, сыйымдылығын, бөлінуін және тұрақтылығын қоса тізімдейді, содан кейін бір шектелген жұмыс қорытындысын қайтарады. Windows бұл тек оқуға арналған сұрауға жауап беру кезінде сақтау кеңістіктерін басқару провайдерін сұраныс бойынша іске қосуы мүмкін. Пулдар, виртуалды дискілер, физикалық дискілер, томдар, тұрақтылық, бөліну, қызмет көрсету параметрлері, саясат және іске қосу түрі сақталады. Ешқандай пул, диск, том, бөліну, қосу, жөндеу, оңтайландыру немесе параметр әрекеті сұралмайды. Провайдер нәтижелері пулдың қолжетімділігін, артықтықты, деректердің тұтастығын, сақтық көшірмеден қалпына келтіру мүмкіндігін немесе қолданбалардың енгізу-шығаруын растамайды.

Сақтау қызметі

Storage модулінің ағымдағы шектелген тапсырмаларын, нақты қызмет ақауларының тарихын және Сақтау қызметінің ағымдағы дайындығын қарап шығады. Толық емес дәлелдердің басымдығы бар. Тапсырма күйі мен бұрынғы ақаулар қызметті қалпына келтіруге немесе сақтау орнын өзгертуге негіз бола алмайды. Қосымша қалпына келтіру жаңа тәуелділік тексерулерінен кейін тек қосулы, тоқтатылған нақты қызметті іске қосады. Бар сақтау хабарландырулары мен саясат басқаратын сақтау әрекеті жалғасуы мүмкін. Томдар, бөлімдер, файл жүйелері, тіркеу нүктелері, құрылғылар, драйверлер, Storage Sense параметрлері, қызмет көрсету саясаты, қызмет рұқсаттары және іске қосу түрі сақталады. KillerBench ешқандай тапсырма, том, бөлім, тіркеу нүктесі, файл, құрылғы, драйвер немесе сақтау параметрі әрекетін таңдамайды. Растау тапсырма нәтижесін, құрылғының, томның немесе сақтау саясатының жұмысын емес, тек қызметтің тұрақты күйін қамтиды.

Дискілерді оңтайландыру қызметі

Дискілерді оңтайландыру қызметінің қолжетімділігін тексереді. Қосымша қалпына келтіру жаңа тәуелділік тексерулерінен кейін тек қосулы, тоқтатылған нақты қызметті іске қосады. Windows жоспарлаған бар оңтайландыру әрекеті ағымдағы қызмет көрсету саясаты бойынша жалғасуы мүмкін. Томдар, файл жүйелері, деректер, оңтайландыру кестелері, қызмет көрсету саясаты, қызмет рұқсаттары және іске қосу түрі сақталады. KillerBench томды таңдамайды, ешбір дискіні талдамайды, trim жасамайды, дефрагментацияламайды, оңтайландырмайды немесе жоспарламайды. Растау талдауды, оңтайландыруды немесе құрылғы күйін емес, тек қызметтің тұрақты күйін қамтиды.

Экспорттау

Есепті экспорттау есепті бастапқы жолдарымен, талданған жазбаларымен және дәлел үзінділерімен сақтайды, оны өтінімге тіркемес бұрын қарап шығуға болады. Экспортталған есептерде осы компьютердің атауы болады, ал шикі журналдар мен дәлел үзінділерінде тіркелгілер, жолдар немесе құпия бастапқы мәтін болуы мүмкін. Қорғалған жинаушылар сақтайтын деректерін шектейді, бірақ импортталған дәлелдердің өңделгеніне кепілдік жоқ. Бөліспес бұрын құпия ақпаратты тексеріп, алып тастаңыз.

killerbench-cli жұмыс үстелі қолданбасымен бірдей Engine-ді PowerShell-ден немесе қашықтағы консольден іске қосады. Компьютерді өзгерте алатын әр пәрмен әдепкі бойынша алдын ала қарау көрсетеді және әрекет етпес бұрын --execute сияқты айқын жалауша қажет етеді. Пәрмендер JSON дәлелдерін стандартты шығысқа, ал барысты стандартты қате ағынына шығарады.

Жаңартулар және қызмет көрсету

  • bits-job-review JOB_GUID [--all-users] [--observe]: Тасымалды нақты қарап шығу немесе екі лездік көшірмені бақылау; қайталаусыз.

  • bits-retry JOB_GUID [--execute]: Әдепкі бойынша алдын ала қарау; нақты тапсырманы айқын қайталау, қолданбаның аяқталғаны туралы мәлімдемесіз.

  • component-repair-source: Басқарылатын DISM жөндеу көзі саясаты мен қайшылықтар; өзгеріссіз.

  • delivery-optimization-activity: Құпиялылыққа байланысты шектелген ағымдағы тапсырма сандары мен байт қосындылары; тасымал сәйкестендіргіштерінсіз және өзгеріссіз.
  • delivery-optimization-policy: Классикалық және Policy CSP параметрлері, тек оқу; құпия мәндер мен провайдер сәйкестендіргіштері алынып тасталған.
  • feature-service-events: Уақыт, Search, WMI, оқиғалар журналы және дыбыс қызметтерінің нақты ақаулар тарихын оқиды.
  • feature-update-policy: Мақсатты шығарылым, кейінге қалдыру, кідірту және қорғау саясаты, тек оқу; JSON дәлелдері.
  • pending-file-operations: Құпиялылыққа байланысты шектелген күтудегі файл әрекеттерінің қорытындысы, тек оқу; JSON дәлелдері.
  • restart-check: Күтудегі қайта іске қосу көздері, тек оқу; JSON дәлелдері.

Әрекет бұғатталғанын хабарлайды

Бұғатталған нәтиже сұралған әрекеттің жалғаса алмағанын білдіреді. Ол жіберілгенге дейін немесе алдыңғы қадамнан кейін тоқтағанын білу үшін хабар мен журналды оқыңыз. Ішінара аяқталған операция кері қайтарылды деп есептемеңіз. Ең жиі кездесетін алғышарт себептері төменде берілген.

  • Әкімші қатынасы қажет. KillerBench-ті жауып, оны Әкімші ретінде іске қосу арқылы қайта бастаңыз.
  • Қайта іске қосуға дайындық анық болуы керек. Windows-та күтудегі қайта іске қосу бар. Компьютерді қайта іске қосып, әрекетті қайта орындаңыз.
  • Басқарылатын саясат бар. Параметр топтық саясатқа немесе құрылғыларды басқару жүйесіне тиесілі. Оны сол жерде өзгертіңіз.
  • Дәлелдер өзгерді. Алғашқы тексеру мен соңғы қайта тексерудің арасында бірдеңе өзгерді. Жаңа күйді оқу үшін құралды қайта іске қосыңыз.

Алдыңғы сұрау салыстыруды қажет етеді

KillerBench үзілген сұраудан қалған күтудегі жазбаны тапты. Сол әрекетті қайта орындаңыз. Ол не болғанын тексеріп, сұрауды қайталамай нақты нәтижені хабарлайды. Пәрмен жолында сәйкес -recover пәрменін пайдаланыңыз, мысалы killerbench-cli bitlocker-auto-unlock-recover.

Тексеру Аяқталмаған немесе Белгісіз деп көрсетеді

Дәлелді оқу мүмкін болмады, көбінесе KillerBench әкімші ретінде іске қосылмағандықтан немесе Windows қызметі қолжетімсіз болғандықтан. KillerBench компьютерді сау деп болжамай, мұны адал хабарлайды.

Файлдар қайда сақталады

Журналдар, күтудегі жазбалар мен сақталған дәлелдер %LOCALAPPDATA%\KillerBench ішінде орналасады. Әр қорғалған әрекеттің өз қалтасы бар. Не өзгергені туралы жазба қажет болса, оларды сақтаңыз.
