What it can do

The current KillerBench integration exposes two deterministic reference tools.

Device Manager problem codesReturn the exact code identity, a short explanation, a bounded next evidence step, and whether a restart may help.
Windows system error codesReturn the installed Windows message for an unsigned decimal or hexadecimal Win32 code.
Read-only by designThese lookups do not scan, repair, restart, install, remove, or change anything on the computer.
Evidence stays explicitA reference result explains a code. It does not prove root cause, machine health, or permission to run a repair.

Data safety and permissions

KillerBench code lookups run locally through its command line interface. They receive only the requested numeric code and do not read logs, files, devices, or machine state. The hosted Cloudflare Worker never receives these app requests.

Your MCP client and model provider can still receive the requested code and returned reference text. Their data handling rules still apply.

How it works

KillerMCP is an open-source local runtime. It includes all 81 KillerTools utilities, detects installed Killer apps, and exposes only supported adapters. For KillerBench, it validates the numeric input, calls the dedicated read-only CLI, validates the JSON response, and returns it to the agent.

The optional public endpoint is a separate open-source MCP server running as a Cloudflare Worker. It provides web based KillerTools utilities but cannot invoke the local KillerBench CLI.

Current limits

The current integration accepts unsigned values up to 32 bits. Device Manager lookups use KillerBench's curated problem-code catalog. Win32 results use the installed Windows system message table and do not load vendor message modules. Broader KillerBench diagnostic workflows are not exposed through MCP yet.

One connection for the family

Install KillerMCP once. It adds all KillerTools utilities and detects supported Killer apps on the computer. Each app contributes its tools through the same agent connection.
