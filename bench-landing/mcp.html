Install KillerMCP

KillerMCP includes all 81 KillerTools utilities plus tools from supported Killer apps in one local connection. It detects KillerBench and exposes the tools supported by that installed version. Repairs stay off until you allow them in KillerBench.

KillerBench availability

These tools require a supported KillerBench CLI installed on your computer. Installing KillerMCP does not supply KillerBench. No public KillerBench package is available yet; review Download and setup before configuring this integration.

What it can do

The KillerBench integration offers code lookups, read-only diagnosis and repairs you allow.

Code lookupsExplain Device Manager problem codes, Win32 errors, Windows Update results and Windows Setup results offline.
Read-only diagnosisRun one check or a full scan of this PC and return the evidence. Nothing is changed.
Repairs you allowRepairs are off until you turn them on in the KillerMCP section of KillerBench About. Each repair is previewed first, Windows asks for administrator approval, and disruptive repairs also need your approval on the desktop.
Evidence stays explicitA code lookup explains a code. It does not prove root cause, machine health, or permission to run a repair.

Data safety and permissions

KillerBench runs every lookup, check and scan locally through its command line interface. Checks and scans read this computer's state but change nothing. Only one repair runs at a time, and an uncertain result locks further repairs until you clear the lock in KillerBench.

How it works

KillerMCP is a small program that lets your AI assistant use supported Killer apps installed on your computer. You install and connect it once, and it automatically finds the apps and tools available on your computer. When you ask your assistant about a code or a problem on this PC, KillerMCP asks the installed KillerBench to look it up or diagnose it, and gives the result back to your assistant. The work is done by the installed KillerBench app, not by this webpage.

Current limits

  • The current integration accepts unsigned values up to 32 bits.
  • Device Manager lookups use KillerBench's curated problem-code catalog.
  • Win32 results use the installed Windows system message table and do not load vendor message modules.
  • Agents can request only the repairs KillerBench lists for MCP, at the level you allowed.

Why KillerMCP runs twice

Claude Desktop starts each local MCP server twice. One copy serves the app's own chats, and the other serves Claude sessions that use this computer remotely. Seeing two KillerMCP.exe processes under Claude in Task Manager is normal. KillerMCP is not installed twice, and nothing needs to be fixed.
