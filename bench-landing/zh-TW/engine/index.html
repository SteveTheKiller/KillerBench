KillerBench.Engine

本頁連結的詳細指南以英語提供。

KillerBench.Engine 是 Windows 診斷與修復程式庫，適用於需要結構化證據而非一組不透明指令碼的應用程式。它為 KillerBench 桌面與命令列工具提供支援，也可以嵌入其他 .NET 宿主應用程式。

它提供什麼

  • 具有明確範圍的診斷流程，涵蓋 Windows 維護、裝置、儲存、網路、列印、安全性、應用程式、使用者設定檔及其他系統領域
  • 具有明確的完整、不完整、未知與歷史狀態的型別化證據
  • 執行前需要準確且目前有效的證據的修復方案
  • 持久保存的日誌，用於修復驗證與中斷執行復原
  • 用於維護活動等即時顯示的進度回呼
  • 用於報告與整合的文字、JSON、HTML 及結構化 .NET 結果
  • 包含錯誤碼、硬體識別碼、廠商與支援參考資料的版本化知識套件

專為可追溯性設計

每項發現都連結至產生它的證據。歷史事件仍是歷史事件。缺少資料並不代表系統健康。資料提供者失敗不會被視為空白結果。Engine 會報告檢查範圍的界線，讓宿主應用程式能夠說明哪些情況已知，哪些仍然未知。

診斷優先

Engine 的大多數操作僅執行讀取。修復支援的範圍刻意小於診斷範圍。修復必須具備支援的方案、新的適用性證據、宿主應用程式的明確授權、持久保存的準備記錄、範圍受限的原生操作，以及操作後的驗證。

全系統掃描僅用於診斷，即使某個專門流程啟用了自動修復也是如此。儲存的擷取記錄與歷史事件絕不會授權修復。原生修復驗證仍限於保留的一次性 Windows 測試機證據，這些證據記錄在存放庫中的以下檔案： VM-VALIDATION.md.

桌面宿主應用程式

桌面介面透過「原始輸出」與「可讀報告」檢視呈現 Engine 輸出。確認提示以及開啟、儲存和資料夾對話方塊都遵循目前的應用程式主題。這些控制項屬於桌面宿主應用程式；嵌入 Engine 的宿主應用程式必須提供自己的審查與授權介面，同時保留 Engine 對證據、必要條件、日誌記錄和驗證的要求。

目前狀態

Engine 面向 .NET 10 與 Windows。它正在積極開發，目前透過 KillerBench 存放庫內的專案參考使用。尚未發行公開套件。
