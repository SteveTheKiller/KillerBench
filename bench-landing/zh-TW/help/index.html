KillerBench 說明

本頁連結的詳細指南以英語提供。

KillerBench 是面向技術人員的 Windows 診斷與修復工具台。它先檢查電腦，說明發現的情況及每項發現背後的證據，只有在您選擇並確認某項具體修復後才會變更 Windows。

KillerBench 正在開發中。目前尚未提供公開下載。這些頁面描述目前的組建。

它能做什麼

  • 對 Windows Update、裝置、儲存、網路、列印、安全性、應用程式與使用者設定檔執行唯讀診斷，然後產生可讀報告。
  • 提供受控修復，只有新的證據確認具體問題時才會執行，並在執行後驗證結果。
  • 涵蓋設定與安全性強化工作，例如 BitLocker、隱私設定、精簡 Windows 與新電腦的初始設定。
  • 在本機執行診斷與報告分析，無需 AI 或 KillerBench 帳戶。所選操作，例如下載和將復原金鑰備份至 Entra ID，可能連線至外部服務。
  • 主控台、報告、確認提示，以及開啟、儲存和資料夾對話方塊都使用目前的應用程式主題。

從何處開始

  • 您的首次診斷 逐步介紹全系統掃描。
  • 工作區 說明分區、面板與快捷鍵。
  • 如何確保變更安全 說明 KillerBench 在任何變更前後會檢查哪些條件。
  • 這些 分區 頁面介紹了每個工具，分組方式與應用程式相同。
  • 命令列 列出了所有 killerbench-cli 命令。
  • 疑難排解 涵蓋遭封鎖的操作、重新啟動和中斷的要求。
