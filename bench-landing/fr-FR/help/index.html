Aide KillerBench

Les guides détaillés accessibles depuis cette page sont en anglais.

KillerBench est un atelier de diagnostic et de réparation Windows destiné aux techniciens. Il vérifie d'abord l'ordinateur, explique chaque constat avec les preuves correspondantes et ne modifie Windows que lorsque vous choisissez une correction précise et la confirmez.

KillerBench est en développement. Aucun téléchargement public n'est encore disponible. Ces pages décrivent la version actuelle.

Ce qu'il fait

  • Exécute des diagnostics en lecture seule pour Windows Update, les périphériques, le stockage, le réseau, l'impression, la sécurité, les applications et les profils, puis rédige un rapport lisible.
  • Propose des réparations encadrées qui ne s'exécutent que si des preuves récentes démontrent le problème exact, puis vérifie le résultat.
  • Couvre la configuration et le renforcement de la sécurité : BitLocker, paramètres de confidentialité, nettoyage de Windows et mise en service d'un nouvel ordinateur.
  • Exécute les diagnostics et l'analyse des rapports localement, sans IA ni compte KillerBench. Les actions sélectionnées, comme les téléchargements et la sauvegarde de clés de récupération dans Entra ID, peuvent contacter des services externes.
  • Utilise le thème actif pour la console, les rapports, les confirmations et les boîtes de dialogue Ouvrir, Enregistrer et Dossier.

Par où commencer

  • Votre premier diagnostic vous guide dans une analyse complète du système.
  • L'espace de travail explique les sections, les panneaux et les raccourcis.
  • Comment les changements restent sûrs explique ce que KillerBench vérifie avant et après chaque changement.
  • Les Sections décrivent chaque outil, regroupé comme dans l'application.
  • Ligne de commande présente pour killerbench-cli chaque commande.
  • Dépannage couvre les actions bloquées, les redémarrages et les demandes interrompues.

Les développeurs souhaitant intégrer les diagnostics à leurs propres outils peuvent consulter le Guide développeur de l'Engine.
