About

KillerBench is a Windows diagnosis, repair and maintenance workbench by Steve the Killer, part of the Killer Tools family. Version 1.0.0 is Unreleased. Its desktop app, Engine and CLI share diagnostic evidence and supported repair workflows.

Availability and scope

No public KillerBench download or Engine package is available yet. Download and setup describes the current Windows x64 target and Desktop Runtime requirements. Native repair validation is still in progress; the presence of a tool is not proof that every failure, interruption or Windows configuration has been tested.

Privacy and external services

Diagnostics and log analysis run locally without an AI service or KillerBench account. Journals and retained evidence use the local account's %LOCALAPPDATA%\KillerBench folders. Selected actions can contact Windows Update, software download services, directories or other named destinations. The startup update check contacts GitHub, and knowledge updates and the MCP installer page contact their configured services. An AI client using MCP may receive the returned reference result.

This website stores theme and accent choices in the browser's local storage. Its guides do not run a diagnosis on your computer. Raw logs, imported files and exported evidence can contain computer names, accounts, paths or sensitive source text. Review them before sharing; do not include recovery keys, credentials or customer data in a public report.

Support

Project information is available in the public repository. Use the contact information published on the author's website for support; include the app version, Windows build, exact tool, expected result and observed result. Review and redact evidence before sending it, and use an approved private channel for customer information. Keep journals for an uncertain repair outcome.
