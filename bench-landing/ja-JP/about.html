このアプリについて

KillerBench は、Steve the Killer が作成した Windows の診断・修復・メンテナンス用ワークベンチで、Killer Tools ファミリー の一部です。バージョン 1.0.0 は未リリースです。デスクトップ アプリ、Engine、CLI は、診断の証拠と対応する修復のワークフローを共有しています。

提供状況と範囲

公開されている KillerBench のダウンロードや Engine パッケージはまだありません。ダウンロードとセットアップ では、現在の Windows x64 の対象と Desktop Runtime の要件を説明しています。ネイティブ修復の検証はまだ進行中です。ツールが存在することは、あらゆる障害、中断、Windows の構成がテスト済みであることの証明にはなりません。

公開されている KillerBench リポジトリ では、現在プロジェクト情報を提供しています。完全な実装はそこでは公開されていません。これらの開発者ガイドは許可されたソースのチェックアウトを前提としたもので、公開ソースのダウンロードを提供するものではありません。

プライバシーと外部サービス

診断とログ分析は、AI サービスや KillerBench アカウントなしでローカルに実行されます。ジャーナルと保持された証拠は、ローカル アカウントの %LOCALAPPDATA%\KillerBench フォルダーを使用します。選択した操作は、Windows Update、ソフトウェアのダウンロード サービス、ディレクトリ、その他の指定された接続先に接続する場合があります。起動時の更新確認は GitHub に接続し、ナレッジの更新と MCP インストーラーのページは、それぞれ構成されたサービスに接続します。MCP を使用する AI クライアントは、返された参照結果を受け取る場合があります。

この Web サイトは、テーマとアクセント カラーの選択をブラウザーのローカル ストレージに保存します。ガイドがお使いのコンピューターで診断を実行することはありません。生のログ、インポートしたファイル、エクスポートした証拠には、コンピューター名、アカウント、パス、機密性のあるソース テキストが含まれる可能性があります。共有する前に確認し、公開レポートには回復キー、資格情報、顧客データを含めないでください。

サポート

プロジェクト情報は公開リポジトリで確認できます。サポートについては、作者の Web サイト に掲載されている連絡先を使用してください。その際は、アプリのバージョン、Windows のビルド、使用したツール、期待した結果、実際の結果をお知らせください。送信する前に証拠を確認して機密部分を削除し、顧客情報には承認された非公開の連絡手段を使用してください。結果が不確かな修復については、ジャーナルを保持してください。
