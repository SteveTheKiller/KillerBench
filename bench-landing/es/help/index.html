Ayuda de KillerBench

Las guías detalladas enlazadas desde esta página están en inglés.

KillerBench es un banco de diagnóstico y reparación de Windows para técnicos. Primero comprueba el ordenador, explica lo que encontró con las evidencias de cada hallazgo y solo cambia Windows cuando eliges una reparación concreta y la confirmas.

KillerBench está en desarrollo. Todavía no hay una descarga pública. Estas páginas describen la compilación actual.

Qué hace

  • Ejecuta diagnósticos de solo lectura en Windows Update, dispositivos, almacenamiento, redes, impresión, seguridad, aplicaciones y perfiles, y después crea un informe legible.
  • Ofrece reparaciones protegidas que solo se ejecutan cuando las evidencias recientes demuestran el problema exacto y verifica el resultado después.
  • Cubre tareas de configuración y refuerzo de seguridad, como BitLocker, ajustes de privacidad, limpieza de Windows y puesta en marcha de un ordenador nuevo.
  • Ejecuta diagnósticos y análisis de informes localmente sin IA ni una cuenta de KillerBench. Las acciones seleccionadas, como las descargas y la copia de seguridad de claves de recuperación en Entra ID, pueden contactar con servicios externos.
  • Usa el tema activo de la aplicación para la consola, los informes, las confirmaciones y los diálogos Abrir, Guardar y Carpeta.

Por dónde empezar

  • Descarga y configuración

  • Cómo se protegen los cambios explica qué comprueba KillerBench antes y después de cualquier cambio.
  • Guías paso a paso explican paso a paso las tareas habituales.
  • Las Secciones describen cada herramienta, agrupadas igual que en la aplicación.
  • Línea de comandos enumera para killerbench-cli cada comando.
  • Solución de problemas cubre acciones bloqueadas, reinicios y solicitudes interrumpidas.
