工具台内部

02 / 先诊断

十一个分区，一种习惯

诊断、修复、更新、设备、网络、应用、维护、初始配置、安全、BitLocker 和隐私。每个工具都会先读取数据，再提供建议；全系统扫描则为需要关注的事项排定优先级。

03 / 受控修复

只修复已确认的问题

只有新的证据准确对应具体问题时，才会提供修复。修复需要您确认，在运行前立即重新检查所有条件，并重新读取结果后才会报告已验证。

04 / 可追溯的证据

没有黑箱

每项发现都链接到相应的事件、日志行或设置。不完整的证据绝不会被报告为系统健康，历史记录仍是历史记录。将报告直接导出到工单。

05 / BITLOCKER 和 TPM

加密无需猜测

检查保护器，将恢复密码备份到文件、Active Directory 或 Entra ID，加密 Windows 和数据驱动器，启用自动解锁，并准备 TPM，且绝不清除 TPM。

06 / 隐私与精简

让笔记本电脑更合您心意

检查并更改隐私设置、应用权限和云搜索，然后精简 Windows。由策略或设备管理控制的设置会保持不变。

07 / 中断恢复

重试前先检查

使用日志的修复会在执行前记录待处理请求。如果请求中断，恢复流程会检查发生了什么，而不会自动重复变更。

08 / 本地诊断

无需 AI

诊断与报告分析在本地运行，无需 AI 服务或 KillerBench 账户。您选择的操作，例如下载或将恢复密钥备份到 Entra ID，可能连接到相应目标。同一个 Engine 为桌面应用和命令行提供支持。
