KillerBench 帮助

本页链接的详细指南以英语提供。

KillerBench 是面向技术人员的 Windows 诊断与修复工具台。它先检查电脑，说明发现的情况及每项发现背后的证据，只有在您选择并确认某项具体修复后才会更改 Windows。

KillerBench 正在开发中。目前尚未提供公开下载。这些页面描述当前构建。

它能做什么

  • 对 Windows Update、设备、存储、网络、打印、安全、应用及用户配置文件运行只读诊断，然后生成可读报告。
  • 提供受控修复，只有新的证据确认具体问题时才会运行，并在执行后验证结果。
  • 涵盖设置与安全强化工作，例如 BitLocker、隐私设置、精简 Windows 和新电脑的初始配置。
  • 在本地运行诊断与报告分析，无需 AI 或 KillerBench 账户。所选操作，例如下载和将恢复密钥备份到 Entra ID，可能连接外部服务。
  • 控制台、报告、确认提示，以及打开、保存和文件夹对话框都使用当前应用主题。

从何处开始

  • 您的首次诊断 逐步介绍全系统扫描。
  • 工作区 说明分区、面板与快捷键。
  • 如何确保变更安全 说明 KillerBench 在任何变更前后会检查哪些条件。
  • 这些 分区 页面介绍了每个工具，分组方式与应用相同。
  • 命令行 列出了所有 killerbench-cli 命令。
  • 故障排查 涵盖被阻止的操作、重启和中断的请求。
