KillerBench.Engine

Подробные руководства, ссылки на которые приведены здесь, доступны на английском.

KillerBench.Engine представляет собой библиотеку диагностики и исправления проблем Windows для приложений, которым нужны структурированные данные вместо набора непрозрачных скриптов. Она используется в настольных инструментах и командной строке KillerBench и может быть встроена в другое приложение .NET.

Что он предоставляет

  • Диагностические процедуры с определенными границами для обслуживания Windows, устройств, хранилищ, сетей, печати, безопасности, приложений, профилей и других областей системы
  • Типизированные данные с явно указанными состояниями: полные, неполные, неизвестные и исторические
  • Сценарии исправления, требующие точных актуальных данных перед запуском
  • Надежно сохраняемые журналы для проверки исправлений и восстановления прерванных операций
  • Обратные вызовы прогресса для отображения текущей активности, например обслуживания системы
  • Текст, JSON, HTML и структурированные результаты .NET для отчетов и интеграций
  • Версионируемые пакеты знаний с кодами ошибок, идентификаторами оборудования, производителями и ссылками на справочные материалы

Возможность проследить каждый результат

Каждое обнаруженное состояние связано с подтверждающими его данными. События прошлого остаются событиями прошлого. Отсутствие данных не означает, что система исправна. Сбой поставщика данных не выдается за пустой результат. Engine указывает границы проверки, чтобы приложение могло объяснить, что известно, а что остается неизвестным.

Диагностика прежде всего

Большинство операций Engine только считывают данные. Возможности исправления намеренно уже возможностей диагностики. Для исправления нужны поддерживаемый сценарий, свежие данные о допустимости, явное разрешение приложения, надежно сохраненная запись подготовки, ограниченное системное действие и проверка результата.

Полное сканирование системы выполняет только диагностику, даже если в отдельной процедуре включено автоматическое исправление. Сохраненные снимки и события прошлого никогда не разрешают исправление. Проверка системных исправлений ограничена сохраненными данными испытаний на одноразовых компьютерах Windows, указанными в файле репозитория VM-VALIDATION.md.

Настольное приложение

Настольная оболочка отображает результаты Engine в представлениях «Необработанный вывод» и «Читаемый отчёт». Подтверждения и диалоги открытия, сохранения и выбора папки используют активную тему приложения. Эти элементы принадлежат настольному приложению. Встраивающее приложение должно предоставить свой интерфейс проверки и разрешения действий, сохранив требования Engine к данным, предварительным условиям, журналированию и проверке.

Текущее состояние

Engine предназначен для .NET 10 и Windows. Он активно разрабатывается и сейчас подключается через ссылку на проект внутри репозитория KillerBench. Публичный пакет еще не выпущен.

Выберите руководство

  • Начало работы показывает первую процедуру без внесения изменений.
  • Диагностические процедуры объясняет отдельные проверки и полное сканирование системы.
  • Данные и результаты объясняет состояния, журналы, прогресс и отчеты.
  • Исправления и безопасность описывает требования к данным и модель восстановления.
  • Руководство по CLI рассматривает поиск команд, текстовый вывод и вывод JSON.
  • Руководство по API описывает основные публичные точки входа.
  • Архитектура объясняет границы Engine и внутренние уровни.
  • Пакеты знаний рассматривает обновляемые справочные данные.
